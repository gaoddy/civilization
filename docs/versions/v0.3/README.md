# v0.3

> 状态：规划中

本文是 v0.3 的版本入口，描述版本主题、相对 v0.2 的能力增量与文档导航；不重复 v0.1、v0.2 的产品基线。

## 主题

在 v0.2 的首版上线之上扩展玩法与商业化：场景、大决战、赛季、商业化、好友榜与好友小队，以及陨落、遗嘱与英雄坐镇。

## 相对 v0.2 的增量

| 内容 | 范围 |
| --- | --- |
| 卡池与英雄卡 | +20 随从（高血人物与植物补强）、+2 英雄卡 |
| 场景 | 8 个战场从扩展层转为默认开启，可单独开关 |
| 大决战 | 10 卡位模式从配置开关转为可玩模式，可单独开关 |
| 赛季 | 赛季周期、积分软重置与卡牌轮换 |
| 商业化 | 外观与英雄卡选择位；不卖战力 |
| 好友 | 好友榜与 2–4 人好友小队匹配 |
| 陨落、遗嘱与英雄坐镇 | 三个扩展项可单独开关 |
