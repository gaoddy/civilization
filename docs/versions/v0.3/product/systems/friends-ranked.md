# 好友榜与好友小队

> 依赖：[好友](../../../../current/product/systems/friends.md)、[天梯与匹配](../../../v0.2/product/systems/ranked-and-matchmaking.md)
> 状态：方案未实施
> 版本：待定（原计划 v0.3 增量）

本文描述好友榜与 2–4 人好友小队匹配；实现需求在需求总表中为「待定」。v0.1 的好友关系与 v0.2 的天梯积分规则不在本文重复。

## 1. 好友小队

- 好友可组成 2–4 人小队一起排队；小队内最高分与最低分相差不超过 400 分。
- 小队按成员平均积分进入匹配池；一局最多出现一个小队，其余座位为单排玩家。
- 超过 4 人、队内分差超过 400 分，或当前已有其他小队在匹配时，不能发起小队排队。
- 好友同局的积分计算与陌生人局完全一致，不因好友关系调整预期胜率或名次分。
- 小队成员仍各自独立排名、独立计分，不共享名次。
- 小队在对局结束后保留小队关系，由队长决定是否再次匹配。

## 2. 好友榜

| 榜单 | 内容 | 更新 |
| --- | --- | --- |
| 好友榜 | 好友内按积分降序，显示段位与积分，离线好友同样展示 | 实时 |

- 好友榜只对本人可见，展示好友的昵称、段位与积分。
- 个人主页的最近 10 局仍只对本人与好友可见。

## 3. 状态与边界

| 场景 | 表现 |
| --- | --- |
| 未登录 | 好友榜与小队入口不可用，提示先登录 |
| 无好友 | 好友榜显示空状态 |
| 已有其他小队在匹配 | 不能发起小队排队，提示原因 |
| 队内分差超过 400 分 | 不能发起小队排队，提示分差上限 |

## 4. 验收标准

1. 2–4 人好友小队可以进入同一局并分别计分；5 人小队不能排队。
2. 队内分差超过 400 分时不能发起小队排队。
3. 一局最多出现一个小队，其余座位为单排玩家。
4. 好友榜按积分降序展示好友的段位与积分，离线好友同样展示。
