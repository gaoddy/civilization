## 英雄卡

以下 32 张卡标记为 `is_hero`，开局可从其中选一张作为英雄；它们同时也是普通随从，可在商店购买。技能就是卡 `skills` 里列出的技能，没有前缀区别：选为英雄时获得全部技能，买到同名卡也同样获得。英雄候选按本局启用的 5 个玩法过滤，规则见[卡牌规范与数据](../card-system.md) §2.1。
