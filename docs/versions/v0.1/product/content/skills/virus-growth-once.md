# 培养

## 属性

| 属性 | 值 |
| --- | --- |
| id | virus-growth-once |
| 关键词 | 无 |
| 模板 | activate-growth-single-playstyle |
| 费用 | 1 |

## 效果

使一个友方病毒随从获得一次成长

## 设计说明

定位：病毒流的低费单体成长，用于补足传染体系的身材。
作用对象：己方一个病毒随从；场上没有病毒时不可用。
