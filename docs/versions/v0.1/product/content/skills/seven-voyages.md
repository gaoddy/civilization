# 七下西洋

## 属性

| 属性 | 值 |
| --- | --- |
| id | seven-voyages |
| 关键词 | 无 |
| 模板 | activate-seven-voyages |
| 费用 | 3 |
| 每回合次数 | 1 |

## 效果

随机确定航程 n（1 至 7）。此后每个航行回合结束时按当回合战绩结算：胜利或平局取棋盘占位数与空位数中的较大者，失败取较小者，累计至航程结束；航程结束后的招募阶段开始时，累计金币一次性到账。

## 设计说明

定位：用 3 金买一段 7 回合以内的长线收益，收益由每回合的棋盘占位与胜负决定，鼓励在航程期间保持场面。
口径：激活回合计为第 1 个航行回合；占位数取该回合战斗开始前的己方棋盘随从数，战斗内召唤不计入；平局包括双方同回合清场与无伤害僵局。
平衡边界：50% 胜率下任意阵容每回合约 3.5 金，7 回合理论上限 49 金；空场平局取 7 金，需真人局观察是否出现互刷平局。
使用建议：铺场稳定后再启航；航程期间占位越偏离一半，胜负带来的收益差越大。
