# battlecry-all-biology-growth-once

## 属性

| 属性 | 值 |
| --- | --- |
| id | battlecry-all-biology-growth-once |

| 确定性替换 | 不适用 |

## 效果

## 设计说明

定位：动物流的群体成长，入场即结算。
口径：只作用于己方动物随从，场上无动物时本次战吼不产生效果。
