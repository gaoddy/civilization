# latent-3

## 属性

| 属性 | 值 |
| --- | --- |
| id | latent-3 |
| 关键词 | 无 |
| 确定性替换 | 不适用 |

## 效果

潜伏：回合开始时，每有 1 层传染获得 +1 攻击力；达到 3 层时对敌方所有随从造成 3 点伤害

## 口径

爆发每局最多触发一次，爆发后移除全部传染层；金色按通用规则整段执行两遍，加攻双倍，爆发仍只触发一次。
