# 卡面名词

> 状态：方案未实施
> 用途：技能模板渲染卡面文案时的名词与关键词文案来源。模板里出现的每个筛选值都必须在这里有条目。

本文只收录卡面使用的写法，不重复分类树的层级名：卡面写「动物」，`taxonomy.md` 写「动物界」，两者分开维护。迁移与新增模板时按现有卡面文案填写，不改写任何文案。

## 4. 关键词文案

| 键 | 文案模板 |
| --- | --- |
| armor | 减伤 {N}：受到伤害时，减免 {N} 点伤害 |
| breed | 繁衍 {N}：回合开始时获得 +{N} 生命 |
| contagion | 传染：造成伤害后，目标每回合 -1 生命 |
| divine_shield | 护盾：抵消一次伤害 |
| evolve | 进化：从 +2/+2、护盾、复生中选择一个 |
| ignore_taunt | 无视嘲讽：攻击时无视敌方嘲讽 |
| poison | 剧毒：造成伤害后，若目标仍存活则将其消灭 |
| reborn | 复生：以 1 点生命复活一次 |
| stealth | 潜行：无法被单体攻击与单体效果选中，造成伤害后打破 |
| taunt | 嘲讽 |
| windfury | 连击：每回合可攻击两次 |
