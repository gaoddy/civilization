# 莱特兄弟

| 属性 | 值 |

| 类型 | 英雄 |

## 效果

使一个友方随从获得无视嘲讽直到回合结束

## 设计说明

定位：给一个随从本回合无视嘲讽，用来越过嘲讽攻击敌方后排。
平衡边界：只持续本场战斗，效果与同星级定向关键词技能一致。
使用建议：对面有嘲讽墙时先给己方最高攻随从，把伤害打到关键目标上。

## 出处

1903 年莱特兄弟在基蒂霍克完成人类首次有动力持续可控飞行。
