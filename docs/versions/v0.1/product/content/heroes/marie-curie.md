# 玛丽·居里

## 简介

战斗开始时稳定造成伤害的被动型化学英雄。

## 设计说明

- 定位：被动输出，战斗开始时稳定造成 2 点伤害。
- 平衡边界：随机目标必须走种子；比赛模式下改为"对最左侧敌方随从造成 2 点伤害"。
- 与其他伤害效果的叠加：先结算英雄被动，再结算战斗。
