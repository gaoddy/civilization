# 莎士比亚

## 属性

| 属性 | 值 |
| --- | --- |
| id | shakespeare |
| 名称 | 莎士比亚 |
| 类型 | 英雄 |
| 玩法 | 哺乳纲 |
| 技能 | battlecry-all-friendly-growth-once |

## 效果

战吼：使你的所有随从获得一次成长

## 设计说明

定位：入场给全队一次成长，铺场阵容的中期爆发点。
平衡边界：群体一次成长按战吼折算 2 点，5/8 加 2 等于 15，未超上限。
使用建议：场上随从越多收益越高，空场打出等于纯 5/8。

## 出处

莎士比亚一生创作 37 部戏剧，《哈姆雷特》《麦克白》等作品塑造了现代英语文学。
