# 阿尔伯特·爱因斯坦

## 简介

让单个随从当回合攻击两次的进攻型物理英雄。

## 设计说明

- 定位：进攻型，用"光速"让一个友方随从当回合攻击两次。
- 平衡边界：只影响 1 个目标、只影响本回合；与既有的「连击」关键词叠加时仍为 2 次，不叠加为 3 次。
- 效果口径：连击只在本次战斗生效，战斗结束即清除。
