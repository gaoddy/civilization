# 托马斯·爱迪生

## 简介

用主动成长推动机械体系滚雪球的工程英雄。

## 设计说明

- 定位：机械体系的主动引擎，把"只能靠装配入场滚雪球"变成"每回合可以主动投入"。
- 平衡边界：7 个机械在场时为 6 次成长，正好等于单回合属性差上限 6；场上没有其他机械时技能不可用（返回 `NO_VALID_TARGET`）。
- 与装配的分工：装配在入场时按 N 结算，随机械数量放大；本技能不依赖入场，只按当前在场的其他机械数量结算。
