# 鲁班

## 属性

| 属性 | 值 |
| --- | --- |
| id | luban |
| 名称 | 鲁班 |
| 类型 | 英雄 |
| 玩法 | 机械 |
| 技能 | mechanism-art |

## 效果

使一个友方机械随从获得一次成长

## 设计说明

定位：机械流的早期主动成长，前期即可提供一次定向成长。
平衡边界：单体一次成长按 1 金每回合 1 次，与「遗传」同档。
使用建议：前期打给已上场的机械随从，把早期身材差拉开。

## 出处

《墨子》等先秦文献多次称道公输般（鲁班）的器械制作技艺。
