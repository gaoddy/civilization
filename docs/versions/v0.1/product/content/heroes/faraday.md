# 迈克尔·法拉第

## 简介

用临时生命值保护核心随从的防御型物理英雄。

## 设计说明

- 定位：保护核心随从，用 +0/+4 换一回合的生存。
- 平衡边界：临时增益在战斗结束清除；不可叠加多次（同一随从重复使用只刷新持续时间，不叠加数值）。
