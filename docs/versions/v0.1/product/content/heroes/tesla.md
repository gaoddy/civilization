# 特斯拉

## 属性

| 属性 | 值 |
| --- | --- |
| id | tesla |
| 名称 | 特斯拉 |
| 类型 | 英雄 |
| 玩法 | 鸟纲、机械 |
| 技能 | alternating-current |

## 效果

使一个友方随从获得无视嘲讽直到回合结束

## 设计说明

- 定位：进攻型，2 金币让一个随从当回合无视嘲讽、优先攻击可被击杀的目标。
- 平衡边界：无视嘲讽按关键词规则不叠加；只能指定己方随从；只影响本回合，战斗结束清除。
- 与爱因斯坦的分工：爱因斯坦给连击（打两次），特斯拉给无视嘲讽（越过嘲讽），分别对应「输出量」与「输出位置」。

## 出处

发明交流电系统与感应电动机，推动交流输电成为主流。
