# 尼古拉·特斯拉

## 简介

用最优攻击绕过嘲讽点杀的进攻型物理英雄。

## 设计说明

- 定位：进攻型，2 金币让一个随从当回合无视嘲讽、优先攻击可被击杀的目标。
- 平衡边界：最优攻击按关键词规则不叠加；只能指定己方随从；只影响本回合，战斗结束清除。
- 与爱因斯坦的分工：爱因斯坦给连击（打两次），特斯拉给最优攻击（选目标），分别对应"输出量"与"输出位置"。
