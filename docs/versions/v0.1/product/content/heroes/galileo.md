# 伽利略·伽利莱

## 简介

每回合首次刷新额外出牌的信息型物理英雄。

## 设计说明

- 定位：观测，给玩家多一个信息位。
- 平衡边界：额外出现的随从只在本回合首次刷新时出现，不占用牌池份数之外的额外资源；比赛模式下固定为"额外出现当前时代 1 星随从"。
