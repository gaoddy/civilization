# 林奈

## 属性

| 属性 | 值 |
| --- | --- |
| id | linnaeus |
| 名称 | 林奈 |
| 类型 | 英雄 |
| 玩法 | 中立 |
| 关联分类 | 关联：哺乳纲、鸟纲、爬行纲、鱼纲、昆虫纲、头足纲、水螅纲 |
| 技能 | battlecry-all-biology-growth-once |

## 效果

战吼：使你的所有动物随从获得一次成长

## 设计说明

定位：生物流的群体成长战吼，把一次入场变成全队收益。
平衡边界：群体一次成长按战吼折算 2 点，与同星级战吼卡一致。
使用建议：生物随从已铺到 2–3 个时再打出，单个生物时收益最低。

## 出处

1735 年《自然系统》建立双名法，为物种分类提供统一命名体系。
