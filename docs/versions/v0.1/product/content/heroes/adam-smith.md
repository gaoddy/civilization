# 亚当·斯密

## 简介

以人类数量为条件的成长型经济学英雄。

## 设计说明

- 定位：人类铺场的奖励型技能，人数越多单次收益越高。
- 平衡边界：最多 2 次成长，等于 2 点属性；条件口径与卡牌「若你控制至少 3 个人类」完全一致。
- 使用建议：与弓箭手、斯巴达勇士、驯火者等低星人类配合，第 3 回合即可稳定吃到两次成长。
- 效果口径：场上没有人类时技能不可用（返回 `NO_VALID_TARGET`）。
