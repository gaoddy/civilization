# 路易·巴斯德

## 简介

用跨回合传染持续削弱敌方的病毒英雄。

## 设计说明

- 定位：病毒体系的被动入口，把传染从"卡面关键词"变成"每场战斗稳定上的一层"。
- 平衡边界：1 层传染使目标每回合开始 −1 生命，跨回合累计；只作用于最左侧一个目标，不扩散。
- 与玛丽·居里的区分：居里是战斗开始时的即时 2 点伤害、随机目标；巴斯德是持续掉血、固定最左侧，两者不重复。
- 效果口径：传染层数写入目标随从，战斗结束不随临时增益清除。
