# 拉瓦锡

## 属性

| 属性 | 值 |
| --- | --- |
| id | lavoisier |
| 名称 | 拉瓦锡 |
| 类型 | 英雄 |
| 玩法 | 中立 |
| 关联分类 | 关联：爬行纲 |
| 技能 | aura-other-plus-0-plus-1 |

## 效果

你的其他随从获得 +0/+1

## 设计说明

定位：不挑玩法的常驻增益，任何阵容都能吃到。
平衡边界：+0/+1 只加生命，不改变攻击曲线，属于防御侧的最小型光环。
使用建议：铺场型阵容后期收益最高，单随从阵容几乎无感。

## 出处

1789 年《化学基本论述》确立质量守恒定律，把化学从定性描述推进到定量科学。
