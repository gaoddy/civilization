# 房间与邀请

> 依赖：[核心规则](../rules/core-rules.md)、[模式](modes.md)、[好友](friends.md)、[联网与技术架构](../../technical/architecture/network-architecture.md)
> 状态：方案未实施

本文描述 v0.1 的成局方式：创建房间、房间码加入、好友邀请加入，以及房间内的准备、开局、退出与断线规则；不描述自动匹配（v0.2）、技术实现与页面视觉。归属版本产品基线的系统规则。

## 1. 定位与范围

- v0.1 不提供自动匹配与公开房间列表；所有对局通过创建房间、房间码加入或好友邀请成局。
- 房间局不计入天梯；v0.1 没有积分、段位与排行榜。
- 房间支持会战模式，房主可选择场景与陨落开关。
- 页面与视觉见 UI 设计文档，本文只定义规则与状态。

## 2. 创建房间

- 登录后可创建房间，创建者成为房主。
- 创建时选择场景、陨落开关；首版默认场景关、陨落关。
- 房间创建后生成 6 位数字房间码，房主可复制分享。
- 房间容量为 8 人；房间人数不足 8 人时不能开局。
- 房主可以解散房间；解散后所有成员回到主界面，房间码立即失效。

## 3. 加入房间

| 方式 | 规则 |
| --- | --- |
| 房间码 | 输入完整的 6 位房间码加入；房间码错误、房间已满或对局已开始时加入失败 |
| 好友邀请 | 收到好友邀请后点击接受加入；邀请 60 秒内未响应自动失效 |

- 加入成功后进入房间等待区，显示当前人数与开关。
- 房间满 8 人后不再接受加入。
- 对局已经开始时，新玩家不能加入；对局结束后房间恢复到可加入状态。
- 首版不做公开房间列表、随机加入与推荐房间。

## 4. 准备与开局

- 每位成员（含房主）在等待区点击准备。
- 8 人全部准备后，房主可以开始对局；人数不足或有人未准备时，开局按钮不可用。
- 开局后房间进入对局状态，未准备的成员不能留在房间。
- 房主开局前可以移除成员；被移除的成员回到主界面。
- 房主离开房间时，房主身份转移给最早加入的剩余成员；没有剩余成员时房间解散。

## 5. 房间内对局

- 会战模式按[核心规则](../rules/core-rules.md)与[模式](modes.md)结算。
- 房间局不改变积分、段位与排行榜；结算页只展示本局名次与对局数据。
- 对局结束后玩家留在房间，房主可以发起下一局；成员可以随时退出房间。
- 首版不做观战；对局中的空位由 AI 托管接管，不补入新玩家。

## 6. 断线与退出

- 断线后可在对局结束前重连，重连回到原座位并恢复当前状态。
- 断线超过 30 秒进入 AI 托管；托管按现有规则继续对局，玩家重连后可随时接管。
- 主动退出对局：已淘汰的玩家按淘汰名次结算；仍在场的玩家按第 8 名结算；房间局不计分，因此不涉及积分变化。
- 服务器维护或对局异常中断时，该局作废，玩家回到主界面。

## 7. 状态与边界

| 场景 | 表现 |
| --- | --- |
| 未登录 | 创建与加入房间不可用，提示先登录 |
| 房间码错误 | 提示房间不存在，停留在输入页 |
| 房间已满 | 加入失败，提示房间已满 |
| 对局已开始 | 加入失败，提示对局已开始 |
| 邀请 60 秒未响应 | 邀请自动失效 |
| 房主解散房间 | 所有成员回到主界面，房间码失效 |
| 房主离开 | 房主转移给最早加入的剩余成员 |
| 人数不足 8 人 | 不能开局，房主可继续等待或解散 |
| 断线 | 显示重连中；30 秒后进入托管 |

## 8. 首版不做

- 不做自动匹配、公开房间列表、随机加入与快速开始。
- 不做跨房间邀请链接与二维码。
- 不做观战、赛事、战队与语音。
- 不做房间局积分、段位与排行榜。

## 9. 验收标准

1. 登录后可以创建房间并得到 6 位房间码。
2. 输入正确的房间码可以加入房间；错误房间码、已满房间与已开局房间加入失败。
3. 好友邀请 60 秒未响应后自动失效。
4. 8 人全部准备后房主可以开局；缺人或有人未准备时不能开局。
5. 房主离开后房主身份转移给最早加入的剩余成员。
6. 对局结束后玩家留在房间，房主可以发起下一局。
7. 断线 30 秒后进入托管，重连后可以接管。
8. 房间局结算页不展示积分与段位变化。
