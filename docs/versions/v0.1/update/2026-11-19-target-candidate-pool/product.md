# 目标候选下发

> 状态：已确认
> 相对版本基线的增量：修改三处选目标时的候选来源与交互；修改三张「复制手牌随从」卡为玩家选择。本文覆盖 [手牌拖拽出牌与目标选择](../2026-11-16-hand-drag-and-target/product.md) §4 的落点规则与 §5 的候选来源，其余条款不变。

## 1. 范围

- 包含：
  - 需要指定单一目标的战吼、效果牌与主动技能，只能从服务端给出的合法候选中选择。
  - 候选带区域：手牌、商店、我方棋盘。
  - 达·芬奇、鹦鹉、印刷术三张卡改为由玩家选择手牌中的一张随从牌复制。
- 不包含：
  - 敌方目标：招募阶段仍不能指定敌方随从。
  - 以商店为目标的卡牌与筛选规则：本版没有这类卡。
  - 卡牌数值、复制后的属性口径与三张卡以外的效果。

## 2. 候选来源与区域

- 需要目标时，客户端只展示服务端给出的候选，不自行从棋盘、手牌或商店推导。
- 每条候选带区域与实例标识，区域取「手牌」「商店」「我方棋盘」。
- 客户端不补齐、不剔除候选；服务端没给的牌不能作为目标提交，提交后返回 `NO_VALID_TARGET`。
- 候选随视图更新：买牌、卖牌、出牌、刷新商店、回合推进、断线重连后，均以最新一次视图为准。
- 候选只发给本人，其他玩家看不到本座位的手牌候选、商店候选与选择过程。
- 候选展示区域与卡牌名称；手牌与棋盘候选显示随从的当前攻击/生命，商店候选显示费用。
- 本版实际出现候选的区域：
  - 指向友方随从的战吼、效果牌与主动技能：我方棋盘随从。
  - 复制手牌随从类效果：手牌中的随从牌。
  - 商店区域已定义，但本版没有以商店为目标的卡，不出现候选。

## 3. 三处选目标

### 3.1 战吼目标待选

- 随从入场后，若存在合法候选，进入目标待选；候选只列服务端给出的目标。
- 候选包含刚入场的随从自身，口径与基线一致。
- 待选期间阻塞其它招募操作，没有取消与跳过；选定一个后结算战吼。
- 合法候选为空时战吼落空，不进入待选，出牌照常完成。

### 3.2 需要目标的效果牌

- 需要目标的效果牌仍以拖拽落点决定目标：只有落在服务端给出的候选上松手才提交出牌，落点候选即目标。
- 候选可以在我方棋盘、手牌或商店中；拖动时只把候选标为可放置，非候选区域显示禁止光标。
- 松手在非候选区域（棋盘空白、手牌空白、商店空槽、棋盘外等）一律退回手牌，不发意图、不消耗卡牌。
- 候选为空时该牌不可打出，拖拽不开始。
- 落在候选上松手即提交，效果随即结算，不经过二次确认。

### 3.3 需要目标的主动技能

- 技能需要目标且候选非空时，点击技能弹出目标选择浮层；选定后才发出使用意图。
- 取消浮层不发意图，不扣金币、不消耗次数。
- 技能需要目标且候选为空时不可使用：按钮禁用并给出禁用原因，不发意图。
- 不需要目标的技能不弹目标浮层，点击即释放。

## 4. 复制手牌随从

- 达·芬奇、鹦鹉、印刷术的复制目标改为由玩家选择：候选为该时刻手牌中的随从牌，不含效果牌。
- 达·芬奇（主动技能）：候选为空时不可使用；有候选时必须选一张。
- 鹦鹉（战吼）：入场后候选非空则进入目标待选；候选为空则战吼落空，不复制。
- 印刷术（效果牌）：候选为空时不可打出；有候选时选定一张后复制。
- 复制结果为所选牌的副本，进入手牌；所选牌仍留在手牌。副本口径与基线一致（金色牌复制为金色）。
- 手牌已满时副本不进入手牌，效果按基线落空；原牌不受影响。
- 卡面文案保持不变。

## 5. 状态与边界

| 状态 | 表现 |
| --- | --- |
| 目标待选（战吼） | 只能从候选浮层选一个，没有取消与跳过 |
| 效果牌拖拽 | 只把候选标为可放置；非候选落点显示禁止并退回手牌 |
| 主动技能目标浮层 | 可取消；取消不发意图、不扣金币与次数 |
| 候选为空 | 需要目标的牌不可打出；需要目标的主动技能按钮禁用 |
| 视图过期 / 倒计时归零 / 已结束招募 / 离线 | 目标浮层关闭，不发意图 |
| 断线重连 | 服务端重新下发视图，候选随视图恢复 |
| 候选在提交前失效 | 服务端返回 `NO_VALID_TARGET`，客户端提示错误并保留原状态，不自动改选 |

- 同一时刻只显示一个目标浮层；服务端目标待选优先于客户端发起的浮层。
- 候选列表为空时不显示空浮层：效果牌按不可打出处理，主动技能按不可使用处理。

## 6. 验收标准

1. 拖动需要目标的效果牌到某个候选随从上松手，效果作用于该目标，牌离开手牌。
2. 拖动需要目标的效果牌到棋盘空白处松手，牌退回手牌，不发意图。
3. 印刷术拖到手牌中的某张随从牌上松手，复制该牌；拖到手牌空白或其他非候选处，牌退回手牌。
4. 需要目标的效果牌候选为空时，拖拽不开始。
5. 打出鹦鹉后手牌有随从牌，出现目标待选且只列手牌随从；选定后复制该牌，所选牌仍在手牌。
6. 打出鹦鹉后手牌没有随从牌，不出现目标待选，战吼落空。
7. 使用印刷术时有手牌随从，候选只包含手牌随从；选定后复制该牌。
8. 达·芬奇的手牌没有随从牌时按钮禁用；有随从牌时选定一张后复制。
9. 战吼目标待选只列服务端给出的候选，候选包含刚入场的随从自身。
10. 服务端判定不在合法池的目标不会出现在候选里；强行提交返回 `NO_VALID_TARGET`。
11. 断线重连后重新打开目标浮层，候选与重连前一致。
