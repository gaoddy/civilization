# 发现与进化待选改为卡片行

> 状态：已确认
> 需求归属：v0.1
> 相对版本基线的增量：
>
> - 修改：发现待选不再使用纵向文字按钮，改为全屏压暗 + 居中一排候选卡面，点击卡面直接选中。
> - 修改：进化待选同样改为居中一排同尺寸选项块，点击选项直接选中。
> - 删除：发现与进化待选的纵向文字按钮列表。

## 1. 定位与规模

- **定位与用户**：面向 8 人房间制对局中的全部玩家；发现与进化是对局中的即时选择，需要在有限时间内看清候选卡牌并做出选择。
- **规模目标**：不适用。本次只调整对局页选择浮层的呈现与点击方式，不改变用户规模、并发与部署假设。

## 2. 范围

### 包含

- 对局页发现待选与进化待选的浮层结构、卡面 / 选项块表现与点击选中。
- 对应文案。

### 不包含

- 发现与进化的触发条件、候选池、可选数量与结算规则。
- 目标待选（由瞄准层承接）与其它弹层。
- 悬停详情、图鉴与首局引导的内容。
- 服务端、协议与卡牌数据。

### 增量清单

| 类型 | 内容 |
| --- | --- |
| 新增 | 发现待选的一排候选卡面；进化待选的一排选项块 |
| 修改 | 选择浮层由居中面板内的纵向文字按钮改为全屏压暗 + 居中一排，点击即选中 |
| 删除 | 发现与进化待选的纵向文字按钮列表 |

## 3. 规则

### 3.1 发现待选

- 触发：本人 `pendingChoices` 队首为发现待选，且满足 §3.3 的显示条件。
- 表现：全屏压暗，中央显示一条「发现：选择一张卡牌」提示，提示下方按服务端候选顺序从左到右横排全部候选卡面，不换行、不滚动。
- 卡面与手牌卡面一致：显示费用、时代、卡框、名称、基础攻击与生命，以及介绍；介绍沿用同尺寸手牌卡的字号压缩与省略规则。
- 卡面尺寸与手牌一致：桌面 112×146，iPhone 紧凑尺寸 84×92；卡面间距取现有间距令牌。
- 操作：点击任一卡面发出 `ChooseDiscover`，下标为该卡面在候选列表中的位置（从 0 起）。
- 选中后浮层不在本地立即关闭，等待服务端新视图消费待选后统一关闭；每次点击都按当前位置发出一次 `ChooseDiscover`，重复点击是否被服务端接受沿用现有拒绝与错误提示规则。

### 3.2 进化待选

- 触发：本人 `pendingChoices` 队首为进化待选，且满足 §3.3 的显示条件。
- 表现：全屏压暗，中央显示一条「进化：选择一项」提示，提示下方按服务端选项顺序从左到右横排全部选项块。
- 选项块与发现卡面同尺寸，文字居中显示选项名称（+2/+2、护盾、复生）；选项不是卡牌，不显示费用、时代、卡框、身材与介绍。
- 操作与 §3.1 相同：点击发出 `ChooseDiscover`，下标为该选项在列表中的位置。

### 3.3 显示条件

- 仅在招募阶段、本人未结束招募、视图未过期且倒计时未归零时显示。
- 队首为目标待选时不显示，由瞄准层承接。
- 发现候选或进化选项为空时不显示。
- 战斗阶段与结算阶段不显示；跨回合保留的待选不覆盖战斗演示。

### 3.4 浮层打开时的其它界面

- 浮层打开时关闭图鉴，并隐藏悬停详情；浮层关闭后恢复原有行为。
- 浮层本身拦截点击，避免误触棋盘、商店与手牌。

### 3.5 断线

- 断线时浮层保持当前显示，不做本地关闭；点击卡面或选项不发出意图，顶部状态文本按现有规则提示「未发出」。

## 4. 状态

| 状态 | 触发 | 表现 | 出口 |
| --- | --- | --- | --- |
| 发现待选 | 队首为发现待选且满足显示条件 | 压暗背景 + 提示 + 一排候选卡面 | 点击卡面发出 `ChooseDiscover`；服务端消费待选后关闭 |
| 进化待选 | 队首为进化待选且满足显示条件 | 压暗背景 + 提示 + 一排选项块 | 点击选项发出 `ChooseDiscover`；服务端消费待选后关闭 |
| 目标待选 | 队首为目标待选 | 不显示选择浮层，由瞄准层承接 | 瞄准层完成或放弃 |
| 战斗 / 结算阶段 | 当前阶段不是招募 | 不显示选择浮层 | 回到招募阶段且仍有待选时重新显示 |
| 已结束招募 / 倒计时归零 / 视图过期 | 对应门槛成立 | 不显示选择浮层 | 门槛解除后按待选重新显示 |
| 候选或选项为空 | 服务端下发空列表 | 不显示选择浮层 | 视图更新 |
| 断线 | 连接断开 | 浮层保持，点击不发意图 | 重连后按视图刷新 |

## 5. 验收

- 发现待选时显示全屏压暗、提示与一排候选卡面，顺序与服务端候选一致。
- 发现卡面显示费用、时代、卡框、名称、基础身材与介绍，尺寸与手牌一致。
- 点击任一发现卡面发出 `ChooseDiscover { choice }`，下标与卡面位置一致。
- 进化待选时显示同尺寸选项块，文字为选项名称，点击发出 `ChooseDiscover { choice }`。
- 目标待选、战斗阶段、结算阶段、已结束招募、倒计时归零与视图过期时都不显示选择浮层。
- 浮层打开时图鉴关闭、悬停详情隐藏，点击不会穿透到棋盘、商店或手牌。
- 断线时浮层保持，点击不产生意图，顶部出现「未发出」提示。
