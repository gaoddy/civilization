# 卡牌商店池标记与 Token 合入产品增量

> 状态：已确认
> 需求归属：v0.1
> 类型：数据结构调整（不改变对局规则）

## 1. 新增字段

- 卡牌新增 `in_shop_pool`（布尔，默认 `true`）：是否进入商店卡池。
- 只有 `true` 的卡参与商店槽位抽取、共享牌池计数、三连与发现候选。
- `false` 的卡不可购买、不进共享牌池、不参与三连与发现；可由效果召唤或规则发放。
- 字段不显示在卡面；卡牌文档属性表在 `false` 时增加「进商店卡池：否」行。

## 2. Token 合入卡牌

- 原 `content/tokens/README.md` 的 23 个衍生随从全部转为 `content/cards/<id>.md` 实体文档，删除 Token 注册表。
- 每个 Token 使用与普通卡相同的字段面，`in_shop_pool: false`。
- 默认值：`card_type: minion`；`era: prehistoric`；`is_scholar: false`；`subtype` 按玩法取现有枚举；`level` 按身材取满足「攻击力 ≤ 星级攻击上限且生命值 ≤ 星级生命上限」的最小星级（1/1 为 1 星）；`categories` 由原玩法列转为 `play:`；`skills` 为空；名称沿用注册表。
- 基础细胞原玩法为 `neutral`，合并后不写 `categories`，按中立处理。
- Token 不再有独立 id 命名空间；id 进入卡牌 `id` 唯一性校验。
- Token 仍需非空「## 出处」。

## 3. 生成卡与三连奖励

- `triple-reward` 增加 `in_shop_pool: false`；类型仍是 `effect`。
- 生成卡与衍生物在数据上不再细分，都通过 `in_shop_pool: false` 表达。
- 三连奖励保留“金色从手牌成功入场 → 获得一张 `triple-reward` 奖励牌 → 打出奖励牌”的流程，但奖励效果改为通用技能 `gain-next-level-minion`（模板 `on-play-grant-minion`，效果 `GrantMinion`）：
  - 打出奖励牌后，直接随机获得一张来源星级 +1（6 星封顶）的池内随从，进入手牌。
  - 候选范围为全部 `in_shop_pool: true` 且命中本局启用玩法的该星级随从；不要求共享池仍有剩余。
  - 不登记发现待选、不需要玩家选择、不扣共享池。
  - 手牌已满或没有合格候选时，奖励牌照常消耗，不获得随从。
- 三连奖励的星级仍由合成时的来源卡锁定，与玩家当前时代无关。
- 旧「发现一张本局玩法的随从」技能继续供其它卡牌使用，行为不变。

## 4. 唯一性与统计

- 名称唯一性只约束 `in_shop_pool: true` 的卡；非池卡允许重名（孢子、工蜂等）。
- 卡片总数变为 432（332 随从 + 100 效果）；其中 408 张进商店卡池，24 张不进（23 衍生物 + 1 生成卡）。
- 商店卡池仍为 309 张随从与 99 张效果牌；衍生物不进入。
- 时代、星级、玩法等文档统计按全部 432 张卡重算。

## 5. 召唤参数

- 技能模板的 `token` 参数只指向 `in_shop_pool: false` 的卡，召唤时不扣共享牌池。
- `card` 参数只指向 `in_shop_pool: true` 的卡，召唤时扣共享牌池。
- 规则行为与当前一致。

## 6. 不变

- 商店概率、发现规则、卡牌数值与其余技能效果不变；三连奖励的发放方式按 §3 调整。
- 英雄卡不受影响。
