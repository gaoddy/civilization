# 图鉴：中立分类、随从/效果筛选与卡图预览

> 状态：已确认
> 需求归属：v0.1
> 相对版本基线的增量：卡牌图鉴的分类目录把「现象」改为「中立」，并新增「效果牌」分类；选中任一顶层分类后在其下方展开「全部 / 随从 / 效果」二级筛选；详情预览区不再拼装卡面，改为显示卡面美术大图，无图时显示占位。

## 1. 范围

### 包含

- 大厅图鉴与对局图鉴覆盖层共用的分类目录、二级筛选与详情预览。
- 分类计数随时代、分类、随从/效果三维筛选换算。
- Token 在客户端展示数据中显式标记为随从，参与「随从」筛选。
- 图鉴相关文案与文档。

### 不包含

- 服务端、协议、规则与卡牌数值。
- 科学分类树与卡牌详情中的「现象」名称；「仅在图鉴目录层不显示现象」。
- 为缺少美术的卡牌补图。

## 2. 分类目录

- 顶层顺序：全部、动物界、细菌域、造物界、真菌界、中立、效果牌、植物界、原生生物界、病毒域。
- 「中立」收 `playstyle = neutral` 的全部条目，包含效果牌与中立随从/Token。
- 「效果牌」收 `card_type = effect` 的全部条目；当前 100 张，全部同时属于中立。
- 目录不再显示「现象」；卡牌详情的科学分类仍可显示「现象」。
- 计数规则不变：某个筛选项的计数等于在其它两维筛选下点下去能看到的张数；零计数项禁用。

## 3. 随从 / 效果二级筛选

- 选中「全部」或任一顶层分类后，在该项下方展开二级项：全部、随从、效果。
- 「随从」= 非效果牌（`card_type != effect`，Token 按随从计）；「效果」= `card_type == effect`。
- 二级筛选与时代、顶层分类叠加；切换顶层分类时二级回到「全部」。
- 二级项同样显示计数，零计数时禁用；当前选中项不禁用。

## 4. 详情预览

- 有 `card_face` 美术的卡显示卡面美术大图，按详情宽度等比放大；没有美术的卡显示玩法色底 + 卡名首字占位。
- 名称、类型、科学分类、玩法、关联玩法、时代、费用、原始数值、技能与效果文本保持现有顺序与规则。
- 预览只读，不响应点击。

## 5. 受影响页面与状态

- 大厅图鉴页与对局图鉴覆盖层，入口、返回与场景行为不变。
- 空目录、零计数、翻页、选中被筛掉等既有状态保持现状。
- 无新增加载、错误、权限或离线状态。
