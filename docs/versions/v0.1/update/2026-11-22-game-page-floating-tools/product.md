# 对局页悬浮工具组与状态模态

> 状态：已确认
> 需求归属：v0.1
> 类型：交互调整（布局与状态提示）

## 1. 调整

- 移除对局页顶部整行工具条；图鉴、提示、退出对局改为浮在页面右上角的一组按钮，每枚按钮独立胶囊。
- 移除顶部状态文本；等待视图、断线 / 重连、操作未发出与服务端错误统一改为居中提示模态。
- 提示模态不锁对局：遮罩只压暗，指针与拖拽继续落到下层对局控件；状态显示期间仍可查看与操作棋盘。
- 提示模态都带「知道了」手动关闭。错误与未发出停留 4 秒后自动收起；等待视图、断线与重连保持到状态恢复。
- 连接提示只在连接状态变化时弹出；手动关闭后同一连接状态不重复弹出。错误到时或被阶段 / 回合变化清空时，若仍断线则恢复连接提示。
- 图鉴仍可在断线时打开；提示与退出对局跟随连接状态。

## 2. 不变

- 三个入口的文案、信号与动作不变；图鉴覆盖层、首局引导、选择浮层与拖拽行为不变。
- 对局数据、协议、服务端与规则不变。
- 仅深色主题，不做浅色与多主题检查。

## 3. 验收

1. 对局页不存在顶部整行工具条与状态文本；右上角显示图鉴、提示、退出对局三枚胶囊按钮。
2. 未连接时操作失败弹出「未连接，操作未发出」提示模态，4 秒后收起；仍断线时恢复连接提示。
3. 服务端错误弹出中文文案模态，4 秒后收起；阶段或回合变化时提前收起，协议原文作为次要说明显示。
4. 断线 / 重连与等待视图显示对应提示模态，状态恢复后自动收起；「知道了」可手动关闭。
5. `make client-check`、`make client-smoke` 退出码 0。
