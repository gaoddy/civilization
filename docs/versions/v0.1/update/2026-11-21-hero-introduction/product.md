# 英雄介绍产品增量

> 状态：已确认
> 需求归属：v0.1
> 类型：内容与展示（不改变对局规则）

## 1. 新增字段

- 每张英雄卡新增 `introduction`（字符串，必填），正文新增「## 简介」小节，内容与字段一致。
- 介绍为 1–2 句、40–80 个汉字，写人物身份、核心贡献或代表作，必须可查证，不杜撰。
- 介绍不进入英雄属性表，不影响星级、玩法、技能或对局结算。

## 2. 展示

- 文本 key 为 `card.<id>.introduction`，与英雄名称 `card.<id>.name` 同前缀；服务端生成数据不含展示文本。
- 选英雄浮层：选中候选英雄后，在技能列表上方显示介绍。
- 图鉴详情英雄模式：在名称下方显示介绍。
- 介绍缺失时界面不显示空行；英雄名称与技能展示保持现状。

## 3. 不变

- 32 张英雄卡的身份、玩法、技能与候选规则不变。
- 协议、数据库、生成数据中的英雄字段不变（仍为 `id`、`categories`、`skills`）。
- 商店、牌池、三连、发现与对局流程不变。

## 4. 验收

1. 32 张英雄文档均有非空 `introduction` 与非空「## 简介」，长度在 40–80 个汉字。
2. 文本表包含 32 个 `card.<id>.introduction`，没有重复或缺失。
3. 选英雄浮层与图鉴详情英雄模式均显示介绍；无介绍时不出现空白占位。
4. `make data-check`、`make client-check`、`make client-smoke` 通过。
