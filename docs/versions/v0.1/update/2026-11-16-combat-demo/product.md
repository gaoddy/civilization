# 招募结束后的战斗演示

> 状态：已确认
> 相对版本基线的增量：新增战斗演示窗口与时间记账规则。

## 1. 范围

- 包含：招募结束到下一回合招募开始之间的战斗演示、演示的结束条件、演示耗时对下回合招募时长的影响、演示期间的界面构成。
- 不包含：战斗结算规则本身（见[核心规则](../../product/rules/core-rules.md) §5），演示不改变任何结果。

## 2. 阶段与时长

- 招募结束后进入**战斗演示**，玩家观战双方随从逐次攻防，直到演示播完。
- 每个回合的总时长固定为 **150 秒**，其中招募 90 秒、战斗演示预算 60 秒。
- 演示的实际耗时 T 从下回合招募里抵扣：**下回合招募时长 = 150 − T**。
- 不设招募时长下限：演示超过 60 秒时，下回合招募按 150 − T 计算，可能很短甚至接近 0。
- 演示耗时只影响下回合招募，不影响已有金币、商店内容与其它规则。

## 3. 结束条件

- 演示**不可跳过**，也没有加速选项；只有把动作序列播完才结束。
- 演示结束后立即进入下一步：仍有存活玩家未结算伤害的，按原规则结算；随后开始下一回合招募。
- 对局结束的回合，演示结束后直接进入结算页，不开始新的招募。

## 4. 界面构成

- 演示期间保留**手牌**与**我方棋盘**，两者照常显示当前内容。
- **对手棋盘置于我方棋盘上方**，与招募中区同一纵向流：对手棋盘在上，我方棋盘在下，手牌在最下。
- 商店、刷新、升时代、冻结、英雄技能与结束招募在演示期间隐藏。
- 双方棋盘上的随从都按服务端给出的动作序列逐个播放：攻击、受击伤害、死亡、复生、传染。
- 每次攻防后双方随从的攻防值与存活状态直接取服务端下发的结果，客户端不自行推算。
- 战斗结束后显示胜负横幅与败者受到的伤害。
- 展示中的手牌与我方棋盘是只读展示：演示期间不能拖拽、不能购买或出售。

## 5. 状态与边界

| 状态 | 表现 |
| --- | --- |
| 演示尚未收到动作数据 | 显示等待提示，不播放 |
| 演示播完 | 结束演示，进入下一回合 |
| 断线 | 顶栏提示正在重连；重连后按当前进度继续，不从头重播 |
| 对局在本回合结束 | 演示结束后进入结算页，不开始新招募 |
| 演示耗时超过 60 秒 | 差额从下回合招募中扣除 |

## 6. 验收标准

1. 全员结束招募后进入战斗演示，商店、英雄技能与结束招募按钮消失，手牌与我方棋盘仍在。
2. 对手棋盘显示在我方棋盘上方，双方随从同屏可见。
3. 演示按服务端动作序列播放，双方随从的攻防值与存活状态与服务端下发的结果一致，不出现客户端自行推算的数值。
4. 界面上不存在跳过或加速入口，演示必须播完。
5. 演示结束后进入下一回合招募；若演示耗时 T 秒，下回合招募倒计时为 150 − T 秒。
6. 演示期间断线重连，回到的是当前进度，不从头重播。
7. 本回合对局结束时，演示结束后进入结算页。
