# 图鉴手机布局与滚动加载

> 状态：已确认
> 需求归属：v0.1
> 关系：调整 [2026-11-20-gallery-playstyle-categories](../2026-11-20-gallery-playstyle-categories/product.md) 的目录形态与翻页方式，分类集合与计数规则不变。

## 1. 范围

### 包含

- 大厅「卡牌图鉴」与对局图鉴覆盖层共用的图鉴主体。
- iPhone 基准（960×540）下的分类入口、网格列数、详情宽度与预览尺寸。
- 全部设备的网格加载方式：分页改为滚动加载。

### 不包含

- 分类集合、玩法归属、计数口径与筛选逻辑。
- 卡牌数据、协议、服务端与规则。
- 桌面与 iPad 的左目录位置、详情信息顺序与主题。

## 2. 分类入口

- 手机随从视图不再显示左侧竖列目录；主体上方新增工具栏，左侧为「分类：<当前分类>」按钮，右侧保留「全部 / 随从 / 效果」二级筛选。
- 点「分类」按钮弹出分类面板：两列排布「全部」与 13 个玩法，显示与当前时代、二级筛选换算后的计数；面板覆盖网格，不挤压网格与详情。
- 点面板内任一分类即应用该分类并收起面板；点面板外区域、再点「分类」按钮或按 `Esc` 收起面板，不改变当前选择。
- 分类面板打开时，网格与详情保持原滚动位置与选中；面板收起后按钮文字更新为当前分类。
- 零计数项仍显示并禁用，当前选中项不禁用；切换顶层分类时二级筛选回到「全部」。
- 英雄视图不显示分类按钮与二级筛选，沿用头部英雄分类栏；桌面与 iPad 保留左侧竖列目录。
- 分类面板的节点与交互不进入桌面与 iPad。

## 3. 网格与加载

- 手机网格改为 6 列，卡面仍为 112×146，列间距 `space-md`；桌面与 iPad 保持 6 列、列间距 `space-lg`。
- 所有设备取消「上一页 / 页码 / 下一页」，改为纵向滚动加载：滚动到接近底部时自动加载下一批，加载后保持当前滚动位置与选中。
- 每批张数：桌面与 iPad 18 张，手机 12 张；首批内容不足一屏时自动继续加载，直到填满一屏或全部加载完。
- 网格底部显示加载状态：未加载完为「已显示 N / M 张 · 继续下滑加载」，全部加载完为「已显示 M / M 张 · 已全部加载」。
- 改时代、分类、二级筛选、切换视图或重进图鉴时，回到首批、滚动回顶部并选中结果首张；刷新后仍只构建已加载批次的卡面。
- 空结果仍显示「没有符合条件的卡牌」，不显示加载状态。
- 选中卡不在筛选结果内时仍自动改为结果首张。

## 4. 详情

- 手机常驻详情宽度压缩为 176，内边距 `space-md`；预览卡面宽度 128，高度按 112:146 等比计算。
- 详情内容顺序、省略规则与滚动方式不变；详情区整体完整落在内容框内，底部内容可滚动到可见区域。
- 桌面与 iPad 详情保持宽 280、预览 200。

## 5. 状态与适配

| 状态 | 表现 |
| --- | --- |
| 分类面板打开 | 面板覆盖网格与详情，背景遮罩；当前分类高亮；点外部或再点按钮收起 |
| 零计数分类 | 面板内显示并禁用，选中项除外 |
| 加载更多 | 滚到底部追加下一批，底部状态文案更新 |
| 全部加载完 | 底部显示「已全部加载」，继续滚动无变化 |
| 空结果 | 网格区显示空态，详情显示占位，不显示加载状态 |
| 英雄视图 | 无分类按钮与二级筛选，网格与详情按同一滚动加载规则 |
| 视图切换 / 筛选变化 | 回到首批与顶部，选中结果首张 |

- 手机其余页面结构、安全区、触控命中与桌面保持一致；桌面与 iPad 除加载方式外布局不变。

## 6. 验收标准

- 960×540 下随从视图：分类按钮可打开面板并看到全部 14 项；页面无纵向溢出，详情底部可达。
- 手机网格为 6 列；桌面与 iPad 为 6 列。
- 全部设备没有分页按钮；滚动到底部后卡面数量增加，重复滚动直至「已全部加载」。
- 手机详情宽 176、预览 128；桌面详情宽 280、预览 200。
- 改筛选后滚动回顶部并选中首张。
- 英雄视图不出现分类按钮与二级筛选。
