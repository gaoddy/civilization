# 图鉴分类目录改为玩法分类

> 状态：已确认
> 需求归属：v0.1
> 相对版本基线的增量：卡牌图鉴的分类目录由科学分类根改为 13 个玩法，末尾追加「中立」；效果牌不再作为顶层分类；带 `play:` 关联玩法的卡额外计入对应玩法分类；科学分类只在卡牌详情中展示。
> 关系：替代 [2026-11-20-effect-science-taxonomy](../2026-11-20-effect-science-taxonomy/product.md) 中图鉴目录部分；效果牌的科学分类数据保持不变。

## 1. 范围

### 包含

- 大厅图鉴与对局图鉴覆盖层共用的分类目录。
- 顶层分类、计数、选中与二级「随从 / 效果」筛选的联动。
- 图鉴相关文案与文档。

### 不包含

- 卡牌科学分类数据、玩法数据与关联分类数据。
- 卡牌详情中的科学分类路径。
- 服务端、协议与规则。

## 2. 分类目录

- 顶层顺序固定为 13 个玩法：哺乳纲、鸟纲、爬行纲、鱼纲、昆虫纲、头足纲、水螅纲、植物界、真菌界、细菌域、原生生物界、病毒、机械。
- 末尾追加「中立」；「效果牌」不再作为顶层分类。
- 科学分类根（动物界、造物、科学、人文、社会等）不再出现在目录。

## 3. 卡片归属

- 卡牌按自身 `playstyle` 归入对应玩法。
- `specialty` 中带 `play:<玩法>` 的卡（学者擅长、中立关联、效果牌定向）额外计入该玩法分类。
- `playstyle = neutral` 的卡同时计入「中立」。
- 一张卡可同时命中多个玩法分类与「中立」，计数按各自规则累加。

## 4. 图鉴行为

- 二级「全部 / 随从 / 效果」筛选不变；效果牌通过该二级项查看。
- 计数、零计数禁用、选中被筛掉、翻页与详情行为不变。
- 卡牌详情的科学分类、玩法与关联分类展示不变。

## 5. 验收标准

- 目录显示 13 个玩法与「中立」，不含「效果牌」与科学分类根。
- 全量 432 张下：哺乳纲 100、机械 57、中立 178；中立下随从 78、效果 100。
- 未来章下鱼纲计数为 0 并禁用；未来 + 哺乳纲 11 张。
- 效果牌按 `play:` 归入对应玩法，同时仍计入「中立」。
