# 冻结后可再次按下解冻（产品）

> 状态：已确认（2026-11-20）
> 适用版本：v0.1
> 相对版本基线的增量：冻结由单向操作改为可逆操作；商店存在冻结槽位时，再按一次冻结按钮解冻全部已冻结槽位，按钮 tooltip 同步显示「解冻」。

## 1. 定位与用户

面向对局招募阶段的全部玩家。玩家误冻结商店或改变主意时，当前只能靠手动刷新或升时代清除冻结，前者消耗金币，后者改变商店内容。本次让玩家在不刷新、不花钱的前提下撤销冻结。

## 2. 范围

### 包含

- 商店存在冻结槽位时，再按冻结按钮解冻全部已冻结槽位。
- 冻结按钮的 tooltip 按当前状态显示「冻结」或「解冻」。

### 不包含

- 不改变冻结槽位保留下回合、手动刷新与升时代清除冻结的既有规则。
- 不新增单卡冻结或解冻入口；界面只操作整店。
- 不改变冻结蒙层、冰晶与「冻」字的视觉表现。
- 不改变冻结与解冻的可用性门控。

## 3. 功能规则

1. 招募阶段，商店没有冻结槽位时，按冻结按钮冻结全部非空槽位，与当前行为一致。
2. 招募阶段，商店存在至少一个冻结槽位时，按冻结按钮解冻全部已冻结槽位；未冻结槽位内容不变，不重抽、不消耗金币。
3. 解冻后，被解冻槽位在本回合与下回合都不再保留；下回合开始时按正常规则重抽。
4. 冻结按钮的激活态继续按「商店存在冻结槽位」判断：解冻全部后按钮恢复未激活。
5. 冻结与解冻都只对非空槽位生效；空槽位跳过，不因空槽失败。
6. 已结束招募、非招募阶段、断线与目标待选等阻塞状态下，冻结与解冻按钮保持禁用且不发送意图。

## 4. 页面与交互

- 冻结按钮（雪花图标）的位置、尺寸与可用性门控不变。
- 商店存在冻结槽位时按钮保持高亮，tooltip 显示「解冻」；不存在冻结槽位时 tooltip 显示「冻结」。
- 按下后以服务端视图为准刷新：解冻成功时冻结蒙层、冰晶与「冻」字立即消失，按钮取消高亮。

## 5. 状态与边界

| 状态 | 表现 |
| --- | --- |
| 无冻结槽位 | 按下冻结全部非空槽位 |
| 存在冻结槽位 | 按下解冻全部已冻结槽位 |
| 部分槽位冻结 | 视为存在冻结，按下解冻全部已冻结槽位；未冻结槽位不变 |
| 商店含空槽 | 空槽跳过；不因空槽失败 |
| 已结束招募 | 冻结与解冻按钮禁用 |
| 非招募阶段 | 冻结与解冻按钮不可见或禁用，按现有规则 |
| 断线 / 目标待选 | 按既有阻塞规则禁用，不发送意图 |

## 6. 明确不做

- 不做滑动、长按或二次确认来单独解冻某个槽位。
- 不引入解冻费用或次数限制。
- 不改变下回合开始保留冻结、手动刷新与升时代清除冻结的规则。

## 7. 验收标准

1. 无冻结时按一次冻结：全部非空槽位带冻结标记与蒙层，按钮高亮，tooltip 为「解冻」。
2. 有冻结时再按一次：全部冻结标记清除，蒙层、「冻」字与按钮高亮消失，金币与商店内容不变，tooltip 恢复「冻结」。
3. 部分冻结时再按一次：所有冻结标记清除，未冻结槽位不变。
4. 解冻后进入下一回合：原冻结槽位正常重抽，不再保留。
5. 已结束招募、战斗阶段、断线和目标待选期间按钮禁用且不发送冻结或解冻意图。
