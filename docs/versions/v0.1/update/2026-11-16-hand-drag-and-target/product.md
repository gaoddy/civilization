# 手牌拖拽出牌与目标选择

> 状态：已确认
> 相对版本基线的增量：修改 `PlayCard` 的操作方式与目标选择时机。

## 1. 范围

- 包含：手牌出牌改为拖拽、随从可落在指定站位、效果牌按落点决定释放与目标、随从战吼改为先入场再选目标。
- 不包含：购买、刷新、升时代、冻结、出售、左右移位、英雄技能的操作方式保持不变。

## 2. 出牌方式

- 手牌不再响应点击出牌，**拖拽是唯一的出牌方式**。
- 拖拽中卡牌跟随指针；松手位置决定这次出牌的结果。
- 松手时落在无效区域一律视为取消：卡牌回到手牌原位，不提示错误、不发意图。

## 3. 随从牌

- 落在我方棋盘上松手即出牌，**落点决定插入位置**：随从插入指针所指的槽位，原槽位及其右侧的随从依次右移一位。
- 落在我方棋盘以外的任何区域松手：取消。
- 棋盘已满（7 个随从）时没有可插入的落点，棋盘区域不接收随从牌，松手即取消。
- 落点下标超出当前随从数：取消，不发意图。
- 随从入场后，若其战吼需要指定单一目标，按 §5 处理。

## 4. 效果牌

| 效果牌 | 有效落点 | 其它落点 |
| --- | --- | --- |
| 需要指定单一目标 | 我方棋盘上的**随从牌**，该随从为目标 | 取消 |
| 不需要目标 | 我方棋盘任意位置 | 取消 |

- 需要目标的效果牌落在棋盘空白处、手牌区、商店、积分榜、右栏等任何位置，都取消。
- 需要目标但棋盘上没有随从时，牌在任何位置松手都取消。
- 效果牌落在随从牌上松手即释放，效果立即结算，不进入待选。

## 5. 战吼目标：先入场再选目标

- 需要指定单一目标的随从战吼，**不阻塞出牌**：随从先正常进入棋盘（按 §3 的落点），随后弹出「选择目标」。
- 合法目标池是**随从入场后**我方棋盘上的全部随从，包含刚入场的这个随从。
- 目标待选与发现、进化共用同一条待选队列，按先到先处理排序；玩家选定目标后，该随从的战吼才结算。
- 目标待选存在期间**阻塞招募操作**：购买、刷新、升时代、出售、左右移位、继续出牌、拖拽与结束招募全部不可用，直到选定目标。
- 目标待选不提供取消：合法目标池非空时必须选定一个。
- 倒计时归零时目标待选作废，该随从的战吼落空；服务端随后推进阶段，与其它待选的处理一致。
- 合法目标池为空时（入场后棋盘上没有任何合法目标），战吼落空，不弹出目标选择，出牌照常完成。

## 6. 状态与边界

| 状态 | 表现 |
| --- | --- |
| 视图过期 / 倒计时归零 / 已结束招募 / 离线 | 手牌不可拖动，拖拽不产生意图 |
| 战吼目标待选 | 招募操作全部不可用，只能选定目标 |
| 拖拽中指针离开游戏窗口 | 按取消处理 |
| 拖拽中收到视图更新（rebuild） | 视为取消，不补发意图 |

- 每次拖动只产生最多一条意图。

## 7. 验收标准

1. 点击手牌不再出牌；拖动随从牌到棋盘第 2 与第 3 张之间松手，随从出现在该位置，原第 3 张及右侧依次右移。
2. 拖动随从牌到棋盘以外区域松手，手牌数量不变、棋盘不变、状态行无错误提示。
3. 拖动需要目标的效果牌到某个随从上松手，效果作用于该随从，牌离开手牌。
4. 拖动需要目标的效果牌到棋盘空白处松手，牌留在手牌。
5. 拖动不需要目标的效果牌到棋盘空白处松手，效果结算，牌离开手牌。
6. 拖动需要战吼目标的随从到棋盘，随从立即出现且棋盘随从数 +1，随后出现「选择目标」；选定后战吼生效，目标池包含刚入场的随从。
7. 棋盘已有 7 个随从时，随从牌在任何位置松手都不改变手牌与棋盘。
