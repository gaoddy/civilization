# 首局引导默认关闭

> 状态：已确认
> 需求归属：v0.1
> 类型：交互调整（首局引导不再自动展示）

## 1. 调整

- 进入对局时不再自动展示首局引导；顶部工具条「提示」按钮保持可用，点击后从当前阶段对应的步骤开始展示。
- 首次进入与再次进入表现一致：都只有点击「提示」才出现。
- 移除「本机首次」判定：不再读写本机 `seen` 记录，也不再因断线重连导致场景重建而自动恢复引导。
- 引导内容、步骤顺序、阶段门控、非阻塞高亮与输入穿透不变。

## 2. 不变

- 「提示」「跳过」「下一步」「完成」的文案与点击行为不变；手动打开后仍按步骤顺序推进，不再按手牌/棋盘条件跳步。
- 引导覆盖层不拦截对局输入，「跳过」与「完成」只关闭引导。
- 结算页、房间页与大厅不挂载引导。

## 3. 验收

1. 进入对局不自动显示引导；点击顶部「提示」后从第 1 步开始展示，战斗阶段从战斗步骤开始。
2. 关闭引导后再次进入对局仍不自动显示。
3. `make client-smoke` 全部场景通过，`ui_smoke_guide` 覆盖默认关闭、手动打开、「下一步」「跳过」与输入穿透。
4. `make client-check`、`python3 scripts/validate_docs.py`、`python3 scripts/check-runbooks.py` 退出码 0。
