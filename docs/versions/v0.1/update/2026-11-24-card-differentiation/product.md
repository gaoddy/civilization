# 卡池差异化

版本：v0.1
日期：2026-11-24

本文只写相对 v0.1 当前基线的增量。基线见 `docs/current/product/content/card-system.md` 与 `docs/current/product/systems/economy-and-numbers.md`。

## 1. 背景与目标

当前卡池中，同玩法同星级的多张随从身材与技能雷同，选卡缺乏差别：哺乳纲 96 张随从里 81 张与同玩法同星卡身材重复（84%），2 星 3/3 出现 16 次；同玩法同星级技能集完全重复的占比为植物界 41%、哺乳纲 24%、病毒 24%。效果牌重复度低（99 张仅 3 组），不在本次范围。

目标：

1. 同玩法同星级同一身材的进池随从不超过 2 张。
2. 同玩法同星级技能集完全相同的进池随从不超过 1 张（关键词类技能除外）。
3. 各玩法攻血比更贴近目标带中点，玩法身份更清晰。
4. 不改经济、牌池份数、玩法归属、卡牌总数与技能机制。

## 2. 产品规则增量

本需求的增量类型：**修改**星级数值区间；**新增**卡池分布约束与永久嘲讽授予效果；**修改**部分卡牌的身材与技能引用；**删除**无（不删卡、不删技能）。卡牌总数、玩法归属与技能机制不增不减。

术语：**身材**指一张随从的攻击力与生命值组合，写作「攻击力/生命值」（如 3/3）；**总身材**指攻击力与生命值之和。

### 2.1 星级数值区间（修改）

放宽 1–5 星的攻击力与生命值区间；参考白板与「攻 + 血 + 关键词折算 ≤ 白板 + 4」的强度上限不变。

| 星级 | 攻击力区间（新） | 生命值区间（新） |
| --- | --- | --- |
| 1 | 1–3 | 2–5 |
| 2 | 2–4 | 3–6 |
| 3 | 3–6 | 4–8 |
| 4 | 4–8 | 6–10 |
| 5 | 6–10 | 8–13 |
| 6 | 8–12（不变） | 10–16（不变） |
| 7 | 10–15（不变） | 14–20（不变） |

- 攻击力为 0 的随从仍取同星级生命上限 × 1.3，校验口径为 `|生命值 − 上限 × 1.3| ≤ 1`。
- 放宽区间只增加可选形状，不提高单卡强度上限。

### 2.2 卡池分布约束（新增）

1. **攻击力 > 0** 的进池随从中，同一「玩法 + 星级 + 攻击力 + 生命值」组合最多 2 张；多玩法归属的卡在每条 `play:` 下分别计数。
2. 进池随从中，同一「玩法 + 星级 + 效果技能集合」最多 1 张。效果技能集合指技能列表中剔除关键词类技能（嘲讽、播种、传染、复生、剧毒、减伤、潜行、连击、护盾、无视嘲讽、繁衍、装配）后剩下的部分；两张卡效果技能集合相同即视为重复，关键词技能允许跨卡复用。
3. 效果技能集合为空的卡（只带关键词技能）：同一「玩法 + 星级 + 身材 + 完整技能列表」最多 1 张，避免两张卡只能靠关键词区分。
4. 攻击力为 0 的随从豁免第 1 条身材约束（攻 0 是固定身份，生命由规则派生）；同一「玩法 + 星级 + 完整技能列表」最多 1 张，生命值在可选档位内分摊。
5. 攻击力 > 0 随从的每玩法每星级平均总身材相对当前变化不超过 ±1；攻击力为 0 的随从不计入本项。

### 2.3 技能差异化（修改）

- 不新增技能机制，只调整卡牌对既有技能与技能实例的引用。
- 同玩法同星级的加成、战吼、光环类效果改为玩法限定变体或不同参数实例（数值档位、选择器、目标分类不同即为不同技能）。
- 效果牌只修正既有 3 组完全重复的「星级 + 费用 + 技能集」组合。
- 新增永久嘲讽授予（既有机制、新技能实例）：使一个友方随从永久获得嘲讽的战吼或主动效果，以及「你的某玩法随从获得嘲讽」的光环；分配到爬行纲、水螅纲、机械、植物界各 1 张。嘲讽自原始时代起解锁，光环不计关键词折算。

### 2.4 不改变的内容

- 卡牌总数、玩法归属、英雄池、关键词体系与时代解锁、技能数量上限。
- 金币曲线、升时代费用、商店概率、牌池份数、伤害曲线、三连与发现规则。
- 效果牌数量、费用分布与星级分布。
- 客户端页面结构、交互与文案来源机制。

## 3. 影响范围

| 项 | 影响 |
| --- | --- |
| 商店与刷新 | 展示新的身材与技能，无新增状态 |
| 图鉴与卡牌详情 | 属性表、效果文本、设计说明随数据更新 |
| 对局结算 | 数值与技能实例变化，规则引擎不改 |
| 平衡文档与模拟 | 攻血比、身材表、技能密度、1000 局结果需复算 |
| 数值规则文档 | 区间表与分布规则更新 |

无新增页面、入口、加载/空/错误/无权限/离线状态。卡池数据对所有玩家相同，无角色权限差异，也不存在越权路径。

## 4. 验收标准

1. 攻击力 > 0 的同玩法同星级同身材 ≤ 2 张；同玩法同星级效果技能集不重复；攻 0 卡完整技能集不重复。
2. 13 个玩法攻血比落在目标带（±0.04），玩法间极差 ≥ 0.20。
3. 无卡牌超出「白板 + 4」上限；攻击力 > 0 随从的每玩法每星级平均总身材变化 ≤ ±1。
4. 1000 局模拟：平均回合 20，13 个玩法都有夺冠，哺乳纲夺冠率不高于当前 371‰ + 5‰。
5. 卡牌文档、生成数据与文本表一致，校验命令全部通过。

## 5. 待确认事项

无。技能机制方向不在本需求内实施，只记录在技术方案中。
