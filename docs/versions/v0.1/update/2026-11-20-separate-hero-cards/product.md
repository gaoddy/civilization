# 英雄卡独立为单独卡牌

> 状态：已确认
> 需求归属：v0.1
> 相对版本基线的增量：
>
> - 新增：独立英雄卡牌类型、独立英雄卡池、图鉴「英雄」分区。
> - 修改：原 32 张带英雄资格标记的随从卡改为普通随从卡；对局英雄行与英雄详情的展示字段。
> - 删除：随从卡上的「英雄资格」标记，以及「英雄卡同时是普通随从、可被购买」的旧口径。
>
> 关系：替代[卡牌系统](../../product/content/card-system.md) §2.1 中「英雄不是独立实体」的表述；候选分配规则沿用 [2026-11-17-hero-pick-redesign](../2026-11-17-hero-pick-redesign/product.md)。

## 1. 范围

### 包含

- 英雄卡的内容定义、数量与字段范围。
- 原 32 张英雄随从卡的归类调整。
- 选英雄候选规则、对局英雄行与英雄详情的展示口径。
- 大厅图鉴的英雄分区与计数。

### 不包含

- 候选分配算法、候选数量、候选可见性调整。
- 英雄技能数值与效果调整。
- 普通随从、效果牌的内容与分布调整。
- 协议字段改名与新增。

## 2. 卡牌归类

- 卡牌类型新增「英雄」；英雄是独立实体，不再用普通随从卡上的布尔标记区分。
- 原 32 张标记为英雄的随从卡全部转为普通随从卡：删除英雄资格标记，保留名称、星级、攻击力、生命值、时代、科学分类、技能与可购买行为；它们继续作为普通随从进入牌池、商店、三连与发现。
- 新建 32 张英雄卡，与原 32 张随从卡一一对应：id 与显示名相同，玩法与关联玩法相同，技能相同。
- 英雄卡只保留身份与技能信息：id、显示名、玩法、关联玩法、技能；不含星级、攻击力、生命值、时代与科学分类。
- 英雄卡与普通随从卡分属不同卡池。跨池同名、同 id 合法；引擎按用途只读取对应卡池，不得把英雄卡当作随从卡，也不得把随从卡当作英雄卡。
- 同名唯一性仍按随从池、效果牌池、英雄池分别生效；英雄卡与普通随从卡可以同名。

## 3. 选英雄

- 候选规则不变：每名玩家 4 张候选，按本局启用的 5 个玩法过滤；同一房间优先互不重复；候选不足时允许跨玩家重复并缩减每人候选数；候选池为空时回退到全部英雄卡抽取；断线重连不重新分配。
- 只有英雄卡能作为候选与被选中；选择普通随从卡或效果牌卡被拒绝。
- 英雄身份授予该英雄卡的全部技能；主动与被动技能行为不变。
- 英雄卡不进入商店、牌池、手牌、战场，不参与三连、发现与购买；选择英雄不消耗牌池份数。
- 候选只对本人可见；其他玩家只能看到「已确认 / 未确认」，与现状一致。
- 所有玩家都可以在大厅图鉴查看英雄分区；英雄卡不因未选为英雄而隐藏。

## 4. 展示

- 选英雄页：候选卡面继续显示玩法封面、首字水印与名字；技能浮层不变。
- 对局英雄行：卡面显示玩法封面、名字、当前生命与生命上限，以及玩家当前时代；不再显示来自英雄卡的攻击力。
- 英雄详情：显示玩法、关联玩法与英雄技能；不再显示科学分类与时代。
- 图鉴新增顶层「英雄」分区，收录 32 张英雄卡，与 13 个玩法分类及「中立」并列；英雄分区使用现有卡面、翻页、空态与常驻详情，不参与玩法分类与随从 / 效果二级筛选。
- 普通图鉴分区不含英雄卡，仍为 432 项。
- 英雄卡详情显示玩法、关联玩法与技能文本；不显示星级、攻击力、生命值、时代与科学分类。

## 5. 状态与边界

- 英雄分区无卡时显示现有空态文案；有卡时按本地化名称升序排列。
- 普通图鉴的加载、空、翻页、筛选与详情状态不变。
- 候选未下发时选英雄页仍显示「正在分配英雄…」并禁用确认；未连接时仍提示「未连接服务器」。
- 英雄卡与随从卡同名时，图鉴分区、选英雄页与对局展示都按各自卡池取数，不互相覆盖。

## 6. 影响

- 内容：新增 32 份英雄卡内容；32 份原随从卡删除英雄资格标记，其余内容不变。
- 图鉴：新增 32 项英雄分区；普通图鉴 432 项不变。
- 对局：英雄行不再显示攻击力；英雄详情减少科学分类与时代两行。
- 不改变：产品定位与用户、用户规模、客户端平台、候选分配、候选数量、英雄技能数值、普通卡池数量与分布、协议字段名。
- 体验要求：不新增加载、动效或响应时延要求，交互反馈沿用现有页面。

## 7. 验收

- 32 张原卡不再是英雄，仍可作为普通随从购买与结算，牌池与商店行为不变。
- 32 张英雄卡只出现在选英雄与英雄展示中，不能购买、不进入牌池、不参与三连与发现。
- 同 id 的英雄卡与随从卡互不覆盖：选英雄取英雄卡，商店与图鉴普通分区取随从卡。
- 图鉴英雄分区 32 张，普通分区 432 项。
- 断线重连、多人选择同一英雄、候选不足回退等既有行为不变。
