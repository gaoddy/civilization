# 客户端卡牌数据改为服务端下发

## 背景

客户端当前的卡牌展示数据（卡名之外的数值、技能、分类树与美术索引）以生成 JSON 随客户端包发布；服务端规则引擎使用同一份文档生成的另一套 JSON。数据只随客户端发版更新，服务端无法在不发版的情况下调整展示数据。

## 增量

### 新增

- 客户端启动时从服务端下载卡牌展示数据，下载结果写入本地缓存；包内不再包含卡牌展示数据。
- 下载内容带内容版本；客户端缓存版本与服务端一致时不重复下载。
- 首次启动或缓存缺失时，客户端必须联网获取数据后才能展示卡牌内容。

### 修改

- 图鉴页、选人页的数据来源改为「服务端下发 + 本地缓存」。
- 未取得数据时，图鉴页显示加载状态；失败时显示失败提示与重试入口。
- 选人页在数据未就绪时显示「内容未就绪」提示；数据到达后自动刷新候选卡。

### 删除

- 客户端包内的卡牌展示数据生成物（`cards.json`、`heroes.json`、`skills.json`、`taxonomy.json`）。

## 不受影响

- 卡名、技能文案、时代名等文本仍随客户端发布，通过本地文本表提供；服务端新增内容若缺少对应文本，界面回退显示实体 id。
- 对局规则、结算与卡牌数值判定仍在服务端，客户端只做展示。
- 美术资源随客户端发布，美术索引不参与下发。

## 状态与异常

- **加载**：图鉴页显示「内容加载中」；选人页显示「内容未就绪」。
- **失败**：图鉴页显示「内容加载失败」与「重试」按钮；选人页保留提示，卡名回退为 id。
- **离线**：有缓存时使用缓存内容并正常展示；无缓存时按失败状态处理。
- **版本升级**：服务端内容版本变化后，客户端下次启动重新下载并覆盖缓存。

## 验收

1. 客户端包内不存在卡牌展示数据 JSON，首次启动可从服务端获取数据并正常打开图鉴。
2. 断网重启且本地有缓存时，图鉴可正常展示。
3. 无缓存且请求失败时，图鉴显示失败提示，点击重试可重新请求。
4. 服务端内容版本变化后，客户端重新下载并展示新内容。
5. 选人页在数据到达后自动刷新候选卡。
