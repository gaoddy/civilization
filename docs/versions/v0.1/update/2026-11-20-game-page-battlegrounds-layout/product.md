# 对局页酒馆战棋结构改版

> 状态：已确认
> 需求归属：v0.1
> 相对版本基线的增量：对局页移除右侧操作栏，改为酒馆战棋的舞台结构；商店与图标操作回到顶部中央，自己英雄改为 64×84 英雄卡放在我方棋盘下方、手牌上方，手牌贴到页面最底；商店或对手棋盘与我方棋盘之间增加河道行，回合数在河道中央、倒计时在右端；战斗阶段在顶部中央恢复对手英雄。本轮不引入图片与字体资源，只固定后续美术要用的槽位。

## 1. 定位与规模

- **定位与用户**：面向 8 人房间制对局中的全部玩家；页面承担对局的招募、战斗与结算前展示，目标是让玩家在 20–30 分钟一局内持续看清自己的商店、棋盘、手牌与对手。
- **规模目标**：不适用。本次只调整对局页结构，不改变用户规模、并发与部署假设；规模口径沿用版本基线。

## 2. 范围

### 包含

- 对局页的页面骨架与区块归属：左排名栏、中央舞台（含河道行）、顶部工具区。
- 商店、售货员、商店操作图标、自己英雄卡、手牌、回合与结束招募的位置与表现。
- 战斗阶段顶部对手英雄的展示。
- 为后续美术资源预留固定的头像、售货员、卡面与背景槽位。

### 不包含

- 服务端、协议、规则、伤害公式、配对与卡牌数据。
- 招募阶段显示下一位对手；服务端在招募阶段不产生配对，本轮不做预告。
- 移动端适配、浅色主题、图片与字体资源本身。
- 图鉴、首局引导、选择浮层、详情层、战报的内容与规则；本轮只调整它们的锚点位置。
- 新手引导的步骤与文案。

### 增量清单

| 类型 | 内容 |
| --- | --- |
| 新增 | 战斗阶段顶部对手英雄展示；分隔商店或对手棋盘与我方棋盘的河道行；顶部工具区 |
| 修改 | 商店与售货员移到顶部中央，商店操作改为图标；自己英雄改为 64×84 英雄卡并移到棋盘下方、手牌上方；手牌去掉面板与标题并贴到最底；回合数移到河道中央、倒计时移到右端；状态文本移到顶部 |
| 删除 | 右侧操作栏；手牌面板底框与「手牌」标题；页面底部状态行 |

## 3. 页面骨架

- **入口**：房间页在开局后进入；重连收到对局视图后也会进入。
- **返回**：对局结束进入结算页；顶部「退出对局」发出退出房间，清空房间并回大厅；认证类错误回登录；不在房间或房间不存在时回大厅。

对局页分为三个区域：

1. **左排名栏**：宽 88，8 行座位，保持现状。
2. **中央舞台**：占据左排名栏右侧的全部宽度，自上而下为商店或对手棋盘、河道、我方棋盘、自己英雄与手牌。
3. **顶部工具区**：左侧状态文本，右侧图鉴、提示、退出对局。

对局页不再有右侧操作栏。原右栏的售货员、商店操作、回合与倒计时、英雄与属性、工具入口按第 4–8 节归位。

### 3.1 左排名栏（保持）

- 8 行座位，每行 44 头像、名次角标与血量条。
- 按服务端 `rank` 升序排列；`rank` 为空时排最后，同位置按座位号。
- 点击座位展开该玩家的战报，同一时刻只展开一行；已淘汰座位压暗但保留名次，仍可点击。
- 悬停座位显示座位详情。
- 以上规则与改版前一致，不因本次结构调整而变化。

### 3.2 中央舞台

招募阶段自上而下：

1. **商店操作行**：升时代图标在售货员左侧，刷新与冻结图标在售货员右侧；图标 40×40，费用角标在图标右上角。
2. **商店**：6 个槽位单行居中。
3. **河道行**：分隔商店与我方棋盘；中央显示回合数，右端显示倒计时与结束招募。
4. **我方棋盘**：7 个槽位单行，可拖拽换位与出售。
5. **自己英雄行**：64×84 英雄卡居中，名字、时代、攻击与生命在卡内；金币与英雄技能图标在卡右侧。
6. **手牌行**：位于页面最底部。

战斗阶段自上而下：

1. **对手英雄**：头像、名字、生命与名次；幽灵战显示幽灵归属者并标注「幽灵」，不显示血量条。
2. **对手随从行**。
3. **河道行**：分隔对手棋盘与我方棋盘；中央显示回合数，播完后在同一位置显示结果横幅；右端显示「战斗中」。
4. **我方随从行**。
5. **自己英雄行**：英雄卡与招募阶段一致，英雄技能图标隐藏。
6. **手牌行**（只读，位于页面最底部）。

- 商店在战斗阶段隐藏，其位置由对手英雄与对手随从行占用；战斗结束回到招募后恢复。
- 招募阶段不显示对手，也不显示对手占位。

### 3.3 河道行

- 河道是商店或对手棋盘与我方棋盘之间的一条横向分隔带，宽度与中央舞台一致。
- 中央显示当前回合数；右端显示剩余秒数。
- 招募阶段：中央只显示「第 N 回合」；右端倒计时在鼠标悬停时翻成「结束招募」，点击发出结束招募；移出恢复剩余秒数。该交互与改版前一致。
- 倒计时归零后右端显示「等待结算」，并禁用招募操作。
- 战斗阶段：中央始终显示「第 N 回合」；演示播完后在同一位置追加结果，文案为「第 N 回合 · 胜利/平局 · 对 … 造成 N 点伤害」；右端显示「战斗中」，不可点击。
- 河道不拦截我方棋盘的拖拽与商店的出售落点；指针经过河道不改变拖拽状态。

### 3.4 顶部工具区

- 左侧显示连接与错误状态文本，页面底部不再有独立状态行。
- 右侧为图鉴、提示、退出对局三个入口，对局阶段始终可用。

## 4. 商店与售货员

- 商店 6 个槽位单行，居中于中央舞台顶部；卡面保持 112×146。
- 费用角标、时代角标、冻结蒙层与「冻」字、点击购买、不可购买时的整卡透明度全部保持。
- 售货员为商店操作行中央的小像，尺寸 64×64；悬停详情保持。
- 升时代图标位于售货员左侧；刷新与冻结图标位于售货员右侧；三个图标均为 40×40 图标按钮，费用角标在图标右上角，冻结免费不显示费用角标。
- 图标语义固定：升时代为向上箭头，刷新为环形箭头，冻结为雪花；图标按钮保留中文 tooltip、可用性、禁用原因与禁用态；冻结激活时图标高亮。
- 出售落点仍是商店面板：棋盘随从拖入商店时整块高亮，松手出售，返还金额提示保持。

## 5. 英雄与属性

- 自己英雄位于中央舞台底部，在手牌行上方并居中：英雄卡 64×84，与普通卡 112×146 同比例缩小。
- 英雄卡内自上而下为封面、名字行与底部数值行：名字单独一行；底部左侧为攻击，右侧为生命，时代在两者中间；攻击取英雄卡攻击，生命显示「当前/上限」。
- 英雄卡右侧为金币与英雄技能图标；技能图标 40×40，费用角标在右上角，剩余次数角标在左上角；默认 1 次不显示数字，0 次整枚置灰并禁用，2 次及以上显示数字。
- 英雄技能的可用性、剩余次数与禁用原因保持；战斗阶段技能图标隐藏（沿用改版前行为），英雄卡保留。
- 自己已淘汰时，英雄位置显示「已淘汰 · 观战中」，操作禁用。
- 战斗阶段对手英雄位于中央舞台顶部并居中：显示头像 64×64、名字、生命与名次；幽灵战显示「幽灵」角标且不显示血量条；对手英雄的技能说明通过悬停详情查看，顶部不放技能按钮。

## 6. 手牌

- 位于中央舞台最底部、自己英雄行下方；没有面板底框，也没有「手牌」标题。
- 最多 10 张单行居中，相邻卡重叠排列；悬停置顶并以底边中点为轴放大 1.12。
- 战斗阶段手牌只读，悬停查看保持。
- 空手牌时显示一行「手牌为空」，不显示空面板。

## 7. 棋盘与战斗演示

- 招募阶段：我方棋盘位于河道下方、自己英雄行上方；7 个槽位单行；空位以「空位」占位；拖拽换位与出售规则不变。
- 战斗阶段：对手随从行在河道上方，我方随从行在河道下方；结果横幅在河道中部预留位置出现，不在两行之间新增一行。
- 战斗演示期间手牌只读；商店与商店操作隐藏；自己英雄行与河道行保留。
- 演示播完后结果横幅在河道预留区域内出现，上下两行不移动。

## 8. 工具与状态

- 图鉴、提示、退出对局固定在顶部工具区右侧，对局阶段始终可用。
- 状态文本固定在顶部工具区左侧，显示等待视图、未连接、错误等状态。
- 错误去向、离线重连与视图过期门控保持改版前规则。

## 9. 美术资源接口（后续版本）

- 本轮不引入图片与字体资源；页面为后续美术版本预留固定槽位：背景（全屏）、自己英雄卡（64×84）、售货员与对手英雄头像（64×64）、卡面插画（112×146 卡面内）、操作图标（40×40：升时代/刷新/冻结/英雄技能）、工具图标（按钮文字左侧）。
- 槽位的显示尺寸、位置与锚点在本轮固定；后续美术版本只替换槽位内容，不改变布局。
- 操作图标本轮以矢量图形绘制，不使用图片；图标上的费用与次数角标是布局内的独立角标，不随图标贴图变化。

## 10. 状态清单

| 状态 | 表现 | 出口 |
| --- | --- | --- |
| 加载中 | 顶部状态文本「等待对局状态…」 | 收到视图后恢复 |
| 空棋盘 | 按容量显示「空位」槽 | 从手牌打出随从 |
| 空商店槽 | 显示「空槽」且不响应点击 | 刷新商店 |
| 空手牌 | 手牌区显示「手牌为空」 | 购买或发现获得 |
| 手牌悬停 | 该卡置顶并放大 1.12，邻卡与顺序不动 | 指针移出或开始拖拽 |
| 目标待选 | 选择浮层只列服务端候选；购买、刷新、升时代、冻结、结束招募、英雄技能、出售、换位与拖拽全部禁用 | 选中候选后发出目标选择 |
| 战斗动作未到 | 对手行显示「等待战斗动作…」，横幅隐藏 | 收到战斗结果后恢复 |
| 战斗演示中 | 双方随从按动作逐步更新；商店与商店操作隐藏；手牌只读；河道右端显示「战斗中」 | 动作播完并经过横幅停留 |
| 演示播完 | 结果横幅在预留区域内出现，页面发送一次战斗已播完 | 服务端推进到下一回合招募 |
| 幽灵战 | 顶部对手英雄显示幽灵归属者，带「幽灵」角标，不显示血量条 | 服务端推进到下一回合招募 |
| 自身已淘汰 | 底部英雄行显示「已淘汰 · 观战中」 | 对局结束 |
| 战报为空 | 展开块显示「无战报」 | 收到该座位参与的战报 |
| 座位已淘汰 | 座位行压暗，名次保留，仍可点击 | 对局结束 |
| 错误 | 顶部状态文本显示中文文案，tooltip 为协议原文 | 按错误码留页、回大厅或回登录 |
| 无权限 | 页面不按角色隐藏操作，越权请求由服务端拒绝 | 按错误状态处理 |
| 离线 | 顶部状态文本「未连接 · 正在重连」；操作提示「未连接，操作未发出」 | 自动重连并收到快照后恢复 |
| 视图过期 | 全部操作禁用 | 收到新回合视图 |
| 倒计时归零 | 河道右端显示「等待结算」，全部招募操作禁用 | 服务端推进阶段 |
| 已结束招募 | 只读；河道右端显示已结束 | 服务端推进阶段 |
| 图鉴覆盖层打开 | 全屏图鉴盖住页面，对局数据照常刷新 | 点「返回对局」或 Esc 收起 |
| 首局引导 | 底部提示条与目标高亮显示，不拦截输入 | 点「下一步」推进，「跳过」或「完成」结束 |
| 引导阶段不匹配 | 隐藏引导但保留当前步骤 | 阶段切回后恢复 |
| 手动重看 | 从第 1 步开始显示，不读写本地已看记录 | 点「跳过」或「完成」收起 |
| 主动退出 | 顶部「退出对局」发送退出房间；服务端按弃权结算 | 清空房间并回大厅 |
| 达到上限 | 商店 6 槽、棋盘 7 槽固定，空位占位 | 服务端判定手牌与棋盘上限并给出拒绝原因 |

## 11. 角色与权限

- 对局内所有玩家使用同一套页面，没有按角色区分的操作。
- 越权请求由服务端拒绝，页面按错误状态展示，不本地隐藏操作。

## 12. 数据与字段

- 不新增服务端下发的数据，全部沿用现有对局数据。
- 展示规则：生命为「当前/上限」；时代显示中文名称；金币为整数；回合数为整数；河道中央显示回合数，右端显示剩余秒数；对手显示名字与名次；幽灵战显示「幽灵」角标。
- 自己英雄卡的名字与攻击取当前英雄卡；时代取本局玩家当前时代，生命取玩家当前生命与上限；英雄技能费用取客户端技能表中该技能的费用，剩余次数取服务端下发的英雄技能数据。
- 招募阶段服务端不提供对手数据，顶部不显示对手占位、名字或预告。
- 所有可用性只取服务端下发的可用标记与禁用原因，页面不做本地推导。

## 13. 体验要求

- 操作发出后不等待本地确认，界面以下一条服务端视图为准；视图未变化前按钮保持原状态。
- 发送失败时在顶部状态区显示「未连接，操作未发出」，不静默丢弃。
- 本次不新增动效、加载动画或过渡；现有战斗演示的节奏与停留时间不变。
- 所有操作控件有中文文本；主要操作可用键盘完成，焦点可见。

## 14. 验收标准

1. 对局页任一阶段都不存在右侧操作栏，也不出现原右栏的三段面板。
2. 招募阶段中央舞台自上而下为：商店操作行（升时代图标—售货员—刷新/冻结图标）、商店 6 槽、河道行、我方棋盘、自己英雄行、手牌行。
3. 战斗阶段中央舞台自上而下为：对手英雄、对手随从行、河道行（中央为回合数与结果横幅）、我方随从行、自己英雄行、手牌行；商店与商店操作不可见。
4. 河道行中央显示回合数；右端在招募阶段显示剩余秒数，悬停翻成「结束招募」，点击一次发出结束招募；战斗阶段中央在播完后追加结果，右端显示「战斗中」且不可点击；倒计时归零显示「等待结算」且禁用。
5. 手牌没有面板与标题，位于页面最底部；10 张保持单行；悬停放大 1.12；空手牌显示「手牌为空」。
6. 自己英雄行位于我方棋盘下方、手牌行上方并居中；英雄卡 64×84，名字单独一行，底部左侧攻击、中间时代、右侧生命；金币与英雄技能图标在卡右侧；技能图标费用角标在右上、次数角标在左上，默认 1 次不显示数字、0 次置灰。
7. 战斗阶段顶部显示对手英雄的头像、名字、生命与名次；幽灵战显示「幽灵」角标且没有血量条。
8. 图鉴、提示、退出对局在顶部工具区右侧；状态文本在左侧；页面底部没有独立状态行。
9. 左排名栏的 8 行座位、名次、战报展开、座位详情与淘汰压暗规则与改版前一致。
10. 商店购买、刷新、升时代、冻结、出售、拖拽换位、结束招募与英雄技能的全部可用性、禁用原因与 tooltip 与改版前一致；图标按钮的 tooltip 必须说明操作含义与费用/次数。
11. 图鉴、首局引导、选择浮层、详情层、战斗演示与战报的规则与改版前一致，只改变位置与锚点。
12. 1280×720 下 7 张棋盘卡与 10 张手牌均单行显示，不换行、不裁切。
