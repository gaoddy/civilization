# 对局页改版与幽灵战

> 状态：已确认
> 相对版本基线的增量：对局页信息结构重排、局内名次公开、全对局战报、落单座位改为对战随机出局者的幽灵、双方同回合清场改判平局、效果牌补时代、商店卡增加费用与时代角标。

## 1. 范围

- 包含：对局页的顶栏、积分榜、右侧面板、战斗视图、商店卡与冻结的表现；局内名次、战报历史、生命上限三类数据下发；效果牌时代；落单座位对战幽灵的规则；双方同回合清场的胜负判定。
- 不包含：商店抽取、英雄技能、结束招募、伤害公式、配对洗牌算法、战斗模拟算法、移动端适配。

## 2. 页面信息结构

- 顶栏整条移除。生命、时代、金币只在自己英雄介绍里出现一次。
- 左栏积分榜只保留头像、名次角标与血量条，不显示名字、时代、随从数与文本化血量，不显示「积分榜」小标题。
- 点击座位行在该行下方展开这名玩家参与过的战报，同一时刻只展开一个；展开状态在视图刷新后保持。
- 已淘汰座位继续显示名次数字，整行压暗，仍可展开战报。
- 右栏顶部按阶段切换身份：招募阶段显示售货员，战斗阶段显示对手英雄。
- 右栏中部显示回合数与剩余时间；底部显示英雄技能、结束招募与自己英雄介绍。
- 战斗视图中区只剩「对手随从 / 结果横幅 / 我方随从」，两侧英雄条删除。
- 事件流（购买、刷新、升时代、三连、伤害、淘汰）不再以文字呈现。

## 3. 名次公开

- 名次由服务端计算并在局内公开，客户端不做任何排序推导。
- 存活者按「生命 → 上战胜者 → 累计伤害 → 座位」排序；已淘汰者占尾部名次。
- 对局结束后名次与最终名次一致。

## 4. 战报

- 战报由服务端下发并全对局公开，重连不丢。
- 只保留最近 5 个回合的战斗。
- 一条战报记录回合数、参战玩家、胜负与伤害；幽灵战只有对战方一名参战玩家。

## 5. 落单座位：对战幽灵

- 存活玩家为奇数时，落单座位对战**一名随机出局者的最终阵容**（幽灵），不再对战自己的镜像。
- 落单座位**必有对战**：奇数人数时一定产生配对与战报，不存在「本回合不战」。
- 幽灵按这名玩家出局时的阵容参战：保留成长与永久增益，保留它自己的光环效果；不结算英雄被动、不产生手牌、不改动牌池与对局棋盘。
- **输给幽灵正常扣血**，伤害按「败者时代 + 幽灵存活随从星级」计算并夹在同一条上下限内。
- **赢下幽灵计入胜者**，参与「上战胜者」的名次比较；不累计造成伤害。
- 幽灵归属从全部出局者里随机抽取，每回合抽一次，可能连续抽到同一名。
- 没有任何出局者时幽灵为空阵容，落单座位照常对战并产生战报——真实对局不可达。
- 与同一幽灵不设「3 回合内不重复」限制。

## 6. 双方同回合清场判平局

- 真实对战与幽灵战同一口径：双方同回合清场即判**平局**，双方都不扣血、都不计入「上战胜者」，战报显示双方均无胜者、伤害为 0。
- 不再按「生命 → 累计伤害 → 座位」在互清时分出胜者；这三项仍用于第 20 回合的排名与「战斗超过 200 次行动」的平局判定。
- 平局不改变下一次战斗的先手，先手沿用上一场的真实胜者。

## 7. 效果牌时代

- 效果牌与随从牌一样必须有时代字段，按「出处」的历史年代归入七个时代。
- 效果牌时代只用于展示，不参与商店抽取与任何判定。

## 8. 商店卡角标与冻结

- 商店卡左上角显示购买费用，右上角显示时代。
- 冻结用整卡蒙层 + 冰晶纹理表达，并在右下角保留「冻」字，不靠颜色单独传达。

## 9. 验收标准

1. 对局页不存在顶栏；生命、时代、金币只在右侧自己英雄介绍里各出现一次文本。
2. 左栏 8 行，每行是头像 + 名次角标 + 血量条，无名字与血量数字；已淘汰行名次仍在且整行压暗。
3. 点击座位行展开战报，同屏只有一块；再点收起；刷新回合后展开的仍是同一座位；无条目时显示「无战报」。
4. 右栏顶部在招募阶段显示售货员，战斗阶段显示对手英雄；幽灵战显示幽灵归属者的英雄并标注「幽灵」，不显示血量条。
5. 右栏中部显示回合数与剩余时间。
6. 战斗视图不存在双方英雄条。
7. 商店卡左上角是费用、右上角是时代；冻结卡有蒙层与「冻」字。
8. 存活为奇数时，落单座位对战一名随机出局者的最终阵容，必有对战；输了扣血、赢了计入胜者；观战者能看到这名玩家的阵容与结果。
9. 双方同回合清场的一律判平局：任何一方都不扣血，战报与战斗横幅显示平局、伤害 0，下一场先手不变。
10. 效果牌详情显示时代；校验脚本对效果牌时代缺失报错。
