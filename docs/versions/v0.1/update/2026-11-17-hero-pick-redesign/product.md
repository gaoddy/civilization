# 英雄候选分配与选英雄页

> 状态：已确认
> 相对版本基线的增量：开局前的英雄由「13 张任选」改为「每人从本人 4 张候选中选一张」；选英雄页改版；英雄卡扩到 32 张。

## 1. 范围

- 包含：英雄卡数量与牌池关系、候选分配规则与保留范围、候选可见性、选英雄页的信息结构与状态、确认语义。
- 不包含：邀请与分享房间码入口（后续版本）、对局内英雄小卡展示、自动匹配与天梯。

## 2. 规则

- 英雄卡共 32 张，仍为 `is_hero: true` 的普通随从卡，进牌池、可被任何玩家购买；选为英雄时获得该卡全部技能，买到同名卡同样获得。
- 开局前每名玩家获得一组候选英雄，当前固定 4 张（服务端常量 `CANDIDATE_COUNT`，允许后续按版本调整）。
- 同一房间内各玩家的候选互不重复：服务端把全部英雄卡按 id 升序后以房间种子洗牌，按进房顺序每 4 张切给一人。
- 候选在玩家首次进入房间时确定；宽限期内断线重连、或座位未被释放前重进，都取回同一组候选，不重抽。
- 玩家只能从自己的候选中选择；选择列表外的卡被拒绝（`INVALID_CHOICE`）。
- 候选对本人可见，对其他玩家不可见；其他玩家只看到「已确认 / 未确认」。

## 3. 界面与状态

- 选英雄页不显示房间码，也没有离开房间入口。
- 顶部只显示其他玩家的名字与确认状态。
- 底部列出本人候选英雄卡：卡面为部落色封面铺满 + 居中首字水印 + 底部居中名字，点击进入选中态（同时只允许一张）。
- 选中后弹出该英雄的技能浮层；取消选中或改选另一张时随之关闭或换内容。
- 点「确认」一次完成「选择英雄 + 准备」。确认后该卡保持高亮、按钮显示「已确认」并禁用，其余候选卡不可再点，不可改选。
- 候选尚未下发时底部显示「正在分配英雄…」并禁用确认；未连接时状态行提示「未连接服务器」并禁用确认。

## 4. 影响

- 8 人局需要 32 张互不重复的英雄卡，英雄卡从 13 张扩到 32 张，总卡数 239（随从 203 / 效果 36），技能 131。
- 大厅断线改为宽限期保留（与对局内同为 30 秒），网络抖动不再丢失座位与候选；主动离开仍立即释放。
- 客户端选英雄页不再渲染全部英雄，也不再显示房间码。
