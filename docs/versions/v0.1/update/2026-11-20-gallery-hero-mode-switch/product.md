# 图鉴随从 / 英雄视图切换

> 状态：已确认
> 需求归属：v0.1
> 相对版本基线的增量：
>
> - 修改：图鉴的「英雄」不再作为左侧分类，改为标题左侧的「随从 / 英雄」视图切换。
> - 调整：英雄视图隐藏左侧分类目录，英雄分类改为顶部居中的单选栏。
>
> 关系：替代[英雄卡独立为单独卡牌](../2026-11-20-separate-hero-cards/product.md)中「图鉴新增顶层英雄分区」的交互表述。

## 1. 范围

### 包含

- 大厅图鉴页与对局图鉴覆盖层的视图切换、英雄分类栏与左侧目录显示规则。
- 图鉴相关文案。

### 不包含

- 卡池范围、卡牌数据、服务端与规则。
- 随从视图的时代、玩法分类与「随从 / 效果」二级筛选。
- 英雄详情的内容与排版。

## 2. 视图切换

- 标题「卡牌图鉴」/「本局卡牌图鉴」右侧显示「随从 / 英雄」两态切换，始终有一项选中。
- 默认进入随从视图；每次打开图鉴重置为随从视图。
- 点击当前未选中的一项即切换视图；英雄集合为空时「英雄」项禁用。
- 各视图保留自己的筛选条件：切到英雄视图再切回随从视图时，时代、分类与二级筛选保持切换前的选择。
- 切换视图后网格回到第 1 页，并选中新视图筛选结果的首张。

## 3. 随从视图

- 保持现有行为：左侧分类目录含 13 个玩法与「中立」，不含「英雄」。
- 顶部居中显示时代章节栏；主体为左侧分类目录、卡面网格与右侧常驻详情。

## 4. 英雄视图

- 左侧不显示分类目录，主体只保留卡面网格与右侧常驻详情。
- 顶部居中显示英雄分类栏：「全部」+ 13 个玩法 + 「中立」，按玩法固定顺序排列。
- 英雄按自身玩法归入分类，不按关联玩法重复计入；「中立」为 `playstyle = neutral` 的英雄。
- 分类计数等于点下去能看到的英雄张数；没有英雄的分类仍显示并禁用。
- 选中分类后网格只列该分类的英雄；切换分类后回到第 1 页，选中结果首张。
- 英雄集合为空时不可进入英雄视图。

## 5. 状态

| 状态 | 表现 | 出口 |
| --- | --- | --- |
| 随从视图 / 英雄视图 | 当前项高亮，另一项可点 | 点击另一项 |
| 英雄集合为空 | 「英雄」项禁用，随从视图正常 | — |
| 英雄分类零计数 | 分类项显示但禁用 | 选择其它分类或「全部」 |
| 英雄分类结果为空 | 网格显示空态，详情显示占位 | 改选「全部」 |
| 本局英雄池缩小 | 只显示本局可用英雄，不可用分类禁用 | 返回对局 |

## 6. 验收

- 图鉴头部标题右侧存在「随从 / 英雄」切换，默认随从，点击可切换。
- 随从视图左侧目录不含「英雄」，时代栏与二级筛选行为不变。
- 英雄视图左侧目录隐藏，顶部居中显示英雄分类栏，含全部玩法与「中立」，零计数禁用。
- 英雄分类按自身玩法筛选，计数与筛出张数一致。
- 大厅 432 项与对局 198 项卡池范围不变。
