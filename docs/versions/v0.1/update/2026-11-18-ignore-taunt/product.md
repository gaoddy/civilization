# 移除最优攻击并新增无视嘲讽

> 状态：已确认
> 相对版本基线的增量：删除「最优攻击」的选目标逻辑，新增独立关键词「无视嘲讽」；现有 16 张带最优攻击的卡牌本轮不改数据，其最优攻击立即失去战斗效果；卡池迁移下一轮完成。

## 1. 范围

- 包含：攻击选目标规则、关键词词表、引擎对无视嘲讽的识别与授予能力、现有 `optimal_attack` 数据的过渡兼容、测试与生成物。
- 不包含：16 张卡牌与 5 个技能的文本/数据替换、卡牌攻防与星级调整、客户端界面改版、历史战斗回放的重算（回放按当时记录的动作重放，不重新选目标）。
- 替代关系：本需求替代[核心规则](../../product/rules/core-rules.md) §5.2 第 2 步的「最优攻击」分支与[关键词与机制](../../product/rules/keywords-and-mechanics.md) §1 的「最优攻击」行。
- 术语：**无视嘲讽**是新的通用关键词，数据 id `ignore_taunt`；**最优攻击**是被删除的旧关键词，数据 id `optimal_attack`，仅作为卡池过渡遗留 id 保留。

## 2. 选目标规则

按以下顺序执行：

1. **潜行**：被攻击方仍在潜行的随从不能被选中；若全部存活随从都在潜行，沿用现有兜底，攻击最左侧存活随从，保证战斗推进。
2. **无视嘲讽**：攻击者带「无视嘲讽」时，在敌方全部可选中随从中随机，不受嘲讽限制。
3. **嘲讽**：攻击者不带「无视嘲讽」且敌方存在可选中嘲讽随从时，只在嘲讽随从中随机。
4. **普通**：否则在敌方全部可选中随从中随机。

- 不再有「优先攻击可被击杀目标」这一层；任何关键词都不改变该优先级。

## 3. 无视嘲讽的口径

- 只影响攻击选目标，不影响伤害、反击、护盾、传染、剧毒、击杀归属与死亡结算。
- 不叠加；重复授予不产生额外效果；金色不额外触发。
- 学者可以携带，但学者攻击力为 0，实际不产生攻击目标选择。
- 通过随从自带、光环、战吼/技能授予、战斗开始时授予等任何来源获得时，都在当前战斗内按上述规则生效；时长沿用授予来源。
- 时代解锁与最小星级沿用最优攻击的「古典 / 3 星」；本轮没有卡牌使用该关键词，接入卡池时启用校验。

## 4. 过渡状态

| 项目 | 本轮 | 下一轮 |
| --- | --- | --- |
| 引擎选目标 | 按 §2 执行，`optimal_attack` 无特殊效果 | 不变 |
| 关键词表 | 删除最优攻击，新增无视嘲讽 | 不变 |
| 16 张卡数据 | 不改，仍登记 `optimal_attack` | 换成 `ignore_taunt` |
| 4 个授予技能 | 不改，仍授予 `optimal_attack`；授予后无效果 | 改为授予 `ignore_taunt` |
| 卡面文本与卡牌文档 | 不改 | 同步替换 |
| 时代解锁与最小星级校验 | 保持现状，不启用 `ignore_taunt` 校验 | 接入卡池后启用 |

- 过渡期内，带最优攻击的 16 张卡在战斗中视同没有该关键词；卡面仍显示「最优攻击」，与实际效果不一致，这是本轮已知且接受的中间状态。
- 历史回放按记录的动作重放，不重新选目标，不会因本需求改变结果。

## 5. 页面、状态与权限

- 不涉及页面、入口与交互改动；关键词继续按现有关键词枚举展示。
- 加载中、空、错误、无权限、离线与达到限额状态不适用：本需求不改变客户端操作、可见字段与断线重连行为。
- 角色与权限不适用：所有玩家按同一战斗规则结算，没有新增可见或可操作内容。

## 6. 影响

- 16 张卡在本轮立即变弱：不再优先击杀残血，也不能绕过嘲讽。
- 关键词折算值本轮按最优攻击的约 2 点登记；卡池迁移后按实际强度复核，平衡影响登记到[待确认事项](../../open-questions.md)。
- 战斗结果与随机流消耗会变化，固定种子基线需要重定。

## 7. 验收标准

1. 被攻击方有可选嘲讽、攻击者无「无视嘲讽」：攻击者只能攻击嘲讽随从。
2. 被攻击方有可选嘲讽、攻击者带「无视嘲讽」：可以攻击非嘲讽随从。
3. 攻击者带旧的「最优攻击」：不再优先攻击可被击杀目标，也不能绕过嘲讽，效果与没有该关键词一致。
4. 全部可选目标都在潜行：沿用最左侧兜底，不卡死。
5. 关键词表包含「无视嘲讽」、不再包含「最优攻击」。
6. 现有 16 张卡仍能加载、进入战斗与正常结算，数据文件不要求本轮修改。
7. 授予「无视嘲讽」的效果按授予时长生效，战斗结束按既有临时关键词规则清除。
8. 生成物与固定种子基线在改动后重新生成并通过校验。
