# 最优攻击卡池迁移为无视嘲讽

> 状态：已确认
> 相对版本基线的增量：把现有 16 张带「最优攻击」的卡牌与 5 个相关技能迁移到「无视嘲讽」；迁移完成后删除遗留 id `optimal_attack`。选目标规则与关键词词表已在本轮实现，本文件只保留尚未完成的卡池迁移。

## 1. 范围

- 包含：12 张随从的关键词替换、4 个授予技能与 1 个关键词技能的数据与文本替换、卡面文档与技能文档同步、卡牌索引更新、时代解锁与最小星级校验切换到 `ignore_taunt`、迁移后的平衡复核。
- 不包含：选目标规则、关键词词表、引擎能力（已实现）；卡牌攻击力、生命值、星级与时代调整；客户端界面改版。
- 术语：**无视嘲讽**是当前关键词，数据 id `ignore_taunt`；**最优攻击**是被替换的旧关键词，数据 id `optimal_attack`，迁移完成后不再存在。

## 2. 卡牌与技能迁移

- 12 张随从把 `keyword-optimal-attack` 换成 `keyword-ignore-taunt`：
  飞机、飞鱼、大白鲨、螳螂、巨脉蜻蜓、纳米机器人、内燃机、曲率飞船、机器狗、自动驾驶汽车、图灵机、X射线机。
- 4 个授予技能把 `keyword=optimal_attack` 换成 `keyword=ignore_taunt`，选择器、时长、费用与使用次数不变：
  特斯拉「交流电」、莱特兄弟「战斗最优攻击」、图灵「机械光环」、人工智能的效果牌。
- 关键词技能 `keyword-optimal-attack` 改名为 `keyword-ignore-taunt`，文本改为「无视嘲讽：攻击时无视敌方嘲讽」。
- 12 张随从的卡面关键词与效果文本、README 索引、技能列表同步替换；不调整任何数值。

## 3. 校验与清理

- 时代解锁与最小星级校验从 `optimal_attack` 切换到 `ignore_taunt`，保持「古典 / 3 星」。
- 关键词折算值按约 2 点登记。
- 迁移完成后，数据、脚本与文本中不再出现 `optimal_attack`；遗留兼容层一并删除。
- 数据生成、文档校验与固定种子基线在迁移后重新生成并通过。

## 4. 页面、状态与权限

- 不涉及页面、入口与交互改动；关键词继续按现有关键词枚举展示。
- 加载中、空、错误、无权限、离线与达到限额状态不适用。
- 角色与权限不适用：所有玩家按同一战斗规则结算。

## 5. 影响

- 迁移后卡面文本与实际效果重新一致。
- 16 张卡的强度低于旧「最优攻击」：不再优先击杀残血，只保留绕嘲讽；平衡影响已在[待确认事项](../../open-questions.md)登记。
- 战斗结果与随机流消耗可能变化，固定种子基线需要重新生成。

## 6. 验收标准

1. 12 张随从的数据与卡面只出现「无视嘲讽」，不再出现「最优攻击」。
2. 4 个授予技能授予 `ignore_taunt`，选择器、时长、费用与使用次数与原技能一致。
3. 关键词技能改名为 `keyword-ignore-taunt`，文本为「无视嘲讽：攻击时无视敌方嘲讽」。
4. 卡牌索引与技能列表不再列出最优攻击。
5. 数据、脚本与生成文本中不再出现 `optimal_attack`。
6. 时代解锁与最小星级校验按 `ignore_taunt` 的「古典 / 3 星」通过。
7. 生成物与固定种子基线重新生成并通过全部校验。
