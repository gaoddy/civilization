# 战斗无伤害僵局直接判平（产品）

> 状态：已确认（2026-11-23）
> 适用版本：v0.1
> 相对版本基线的增量：新增一种平局判定。战斗任意时刻，双方场上都有存活随从、但双方都不存在可能造成伤害的来源时，立即判平，不再打满 200 次行动后按生命、累计伤害与座位分胜负。

## 1. 定位与用户

面向对局中的全部玩家。双方只剩攻击力为 0 的随从、或只剩整场都无法出手的随从时，现有规则会让战斗无意义地推进到 200 次行动后按生命值分出胜者；本次让这类无伤害僵局直接以平局结束。

规模目标：本次不改变用户规模与容量目标，沿用项目事实（v0.1 小规模内测、房间制、服务端单实例）。

## 2. 范围

### 包含

- 新增「无伤害僵局」判定：战斗任意时刻满足条件即判平。
- 真实战与幽灵战采用同一口径。
- 判平后的战报、伤害、先手与七下西洋结算沿用既有平局规则。

### 不包含

- 不改变双方同回合清场已有的平局判定。
- 不取消 200 次行动上限：双方仍可能造成伤害、但打不出清场结果时，仍按生命 → 累计伤害 → 座位分胜负。
- 不改变单侧清场的胜负判定与伤害公式。
- 不新增玩家操作入口，不改变战斗演示的节奏常量。

## 3. 功能规则

1. **可能造成伤害的来源**：一方场上存在存活、未被限制为无法攻击、当前攻击力大于 0 的随从。
2. 本轮已经行动过的随从在下一轮恢复出手，仍算可能造成伤害的来源；只有整场战斗都无法出手（例如战斗开始前就已被效果限制为无法攻击）的随从不计为来源。
3. 依赖受伤、死亡、召唤、主动攻击或入场才会触发的效果（亡语、复生、播种、成长、召唤、直伤等），在双方都打不出伤害时不会触发，因此不把这类尚未触发的效果算作伤害来源。
4. **触发条件**：战斗任意时刻（包括开战瞬间），双方场上都有至少一个存活随从，且双方都不存在可能造成伤害的来源。
5. 满足触发条件时立即判平，此后不再产生新的战斗动作；判平前已经产生的动作保留在战报与演示中。
6. 判平结果与既有平局一致：双方都不受伤害、都不计为本场胜者；战报显示无胜者、伤害为 0；先手沿用上一场胜者。
7. 七下西洋按平局结算：当回合取棋盘占位数与空位数中的较大者累计。
8. 幽灵战同样适用：落单玩家与幽灵双方都不存在可能造成伤害的来源时判平；落单玩家不受伤害，幽灵不计为胜者。
9. 只有一方还有存活随从时按该方获胜结算，不判平。
10. 一方存在可能造成伤害的来源、另一方全是 0 攻随从或无法出手随从时，不判平，按既有规则推进到清场或行动上限。

## 4. 页面与交互

- 游戏页战斗演示：开战即满足条件时没有攻防动作，直接进入平局播报；战斗中满足条件时，已产生的动作正常播完，再进入平局播报。
- 战报与既有平局一致：显示无胜者、伤害为 0，保留双方战前/剩余阵容与已经发生的动作。
- 不新增按钮、提示或二次确认。
- 体验要求：条件满足的当拍即结束战斗，不再产生无意义动作；开战即僵局时不进入逐个随从的攻击演示。

## 5. 状态与边界

| 状态 | 表现 |
| --- | --- |
| 开战即僵局 | 不产生攻防动作，直接平局播报 |
| 战斗中进入僵局 | 已产生的动作正常播完，随后平局播报 |
| 单侧清场 | 按该侧获胜结算，不判平 |
| 双方仍可能造成伤害但打满 200 次行动 | 沿用既有规则，按生命 → 累计伤害 → 座位分胜负 |
| 断线重连 | 按同一战报续播，结果不变 |

无加载中、错误、无权限与离线专属状态：判平只由战斗现场决定，不依赖网络与权限。

## 6. 角色与权限

对局中的全部玩家可见、可观看；没有操作入口；淘汰与观战不改变判定。

## 7. 数据与字段

- 战报的胜者为空、伤害为 0，沿用既有平局字段与展示。
- 不新增客户端可见字段。

## 8. 验收标准

1. 双方开战阵容的攻击力全为 0：战斗立即结束为平局，没有攻防动作，双方不受伤害。
2. 双方交战后只剩 0 攻随从：剩余随从全为 0 攻时立即判平，不推进到 200 次行动。
3. 一方全是 0 攻随从、另一方有攻击力大于 0 且可得出手的随从：不判平，按既有规则推进到清场。
4. 双方随从攻击力大于 0、但整场都被限制为无法攻击：判平，不按生命值分胜负。
5. 幽灵战满足同等条件：判平，落单玩家不受伤害。
6. 判平当回合的七下西洋按平局取 `max(占位数, 空位数)`。
7. 断线重连后战报、动作序列与对局结果一致。
