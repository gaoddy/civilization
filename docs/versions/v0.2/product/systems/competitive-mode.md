# 比赛模式

> 依赖：[核心规则](../../../v0.1/product/rules/core-rules.md)、[模式](../../../v0.1/product/systems/modes.md)、[房间与邀请](../../../v0.1/product/systems/rooms-and-invites.md)、[联网与技术架构](../../../v0.1/technical/architecture/network-architecture.md)
> 状态：方案未实施

本文描述 v0.2 新增的比赛模式规则；不描述会战规则、具体实现与页面视觉。归属版本产品基线的系统规则。

## 1. 定位

- 把"运气"压到最低，让名次更多反映决策；
- 通过房间成局，不计分，作为练习对局；
- 房间创建时由房主选择会战或比赛模式，其余成局规则沿用[房间与邀请](../../../v0.1/product/systems/rooms-and-invites.md)。

## 2. 规则

**"无随机"不是另写一套规则，而是同一规则引擎上的两个开关**（保证 [设计总纲](../../../v0.1/product/overview/design-overview.md) §8 第 6 条成立）：

1. **固定种子**：房间创建时公开种子，所有随机（刷新内容、发现候选、攻击目标、匹配顺序）都由它推导；同一种子 + 同一意图序列必须复现同一局；
2. **效果替换表**：所有"随机目标/随机数值/随机召唤"的卡牌效果，替换为卡牌数据中的确定性版本；
3. **固定匹配顺序**：第 1 轮按座位号首尾配对，之后按胜者组规则固定，不随机；
4. **禁用场景**：场景固定为"陆地"或关闭；
5. **禁用随机类效果牌**：如布朗运动、达尔文的发现，按替换表执行；
6. **关闭成就**：比赛模式不启用局内成就，避免成就增益影响名次。

| 会战 | 比赛 |
| --- | --- |
| 随机种子 | 公开固定种子 |
| 随机目标 | 固定目标 / 玩家选择 |
| 随机发现 | 固定三选一池 |
| 场景随机 | 固定或关闭 |
| 匹配随机 | 固定配对规则 |

## 3. 验收标准

1. 同一房间种子与同一意图序列重放，事件序列与终局状态完全一致；
2. 所有随机类效果按卡牌数据中的确定性替换文本执行，无未替换项；
3. 比赛模式不触发任何局内成就；
4. 会战与比赛共用同一份规则代码，仅在种子与效果替换表上分支。
