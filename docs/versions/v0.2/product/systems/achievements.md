# 成就

> 依赖：[设计总纲](../../../../current/product/overview/design-overview.md)、[模式](../../../../current/product/systems/modes.md)、[核心规则](../../../../current/product/rules/core-rules.md)
> 状态：方案未实施（Steam 侧成就契约与映射已实现，见[当前发行渠道与账号](../../../../current/product/accounts-and-distribution.md) §4）

本文描述 v0.2 新增的局内成就系统与设计原则。归属版本产品基线的系统规则。

## 1. 数据

6 个成就的完整数据（事件、条件、次数、奖励与是否影响战力）以 `docs/versions/v0.2/product/content/achievements/` 的实体文档为准，索引见[成就索引](../content/achievements/README.md)，本文不重复列出。

成就的事件类型限定为：时代升级、关键词组合、成长触发、卡牌使用、三连合成。新增成就只能从这五类事件中选取。

**触发条件必须是状态机事件**：例如"图灵时刻"只看该随从由技能 `keyword` 派生出的关键词是否同时包含「无视嘲讽」与「连击」，不依赖任何叙事判定。

## 2. 启用方式

- 房主在创建房间时决定是否启用成就；v0.2 默认开启；

## 3. 成就的设计原则

1. **可判定**：每个条件都能写成"事件 + 计数"，不允许"表现良好"这类主观条件；
2. **小型增益**：单个成就的单局收益不超过 2 金币或 2 点属性；
3. **不制造滚雪球**：成就奖励不得反过来加速成就达成（例如"获得金币"不能用于完成另一个"获得金币"的成就）；
4. **每局最多触发 3 个**：避免一局内堆积过多奖励；
5. **不与付费挂钩**：成就只由对局行为触发。

## 4. 验收标准

1. 6 个成就全部可由对局事件触发并按实体文档结算；
2. 每局最多触发 3 个成就；
4. 成就奖励不影响战力以外的一致性，且不加速其他成就达成。
