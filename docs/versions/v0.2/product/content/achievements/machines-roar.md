# 机器轰鸣

## 条件

本局有「蒸汽机」进入战场

以任意途径进入战场为触发点：手牌打出、效果召唤、效果复制与战斗内召唤都算。招募内触发时减免作用于当回合；战斗内触发时留到下一次招募。费用减免不改变金币上限。

## 奖励

你的机械随从费用 −1（最低 1）：招募内触发当回合生效，战斗内触发下一次招募生效
