# v0.2

> 状态：规划中

本文是 v0.2 的版本入口，描述版本主题、相对 v0.1 的能力增量与文档导航；不重复 v0.1 产品基线。

## 主题

在 v0.1 的房间制对局之上加入自动匹配与天梯，并引入场景、赛季、商业化与大决战。

## 相对 v0.1 的增量

| 内容 | 范围 |
| --- | --- |
| 自动匹配 | 8 人按积分匹配，等待时间逐级放宽；房间局仍不计分 |
| 天梯 | 会战自动匹配局计分，动态积分差、8 段位、全服榜与好友榜 |
| 好友 | 新增好友榜与 2–4 人好友小队匹配 |
| 场景 | 8 个战场从扩展层转为默认开启 |
| 赛季 | 赛季周期、积分软重置与卡牌轮换 |
| 商业化 | 外观与英雄卡选择位；不卖战力 |
| 大决战 | 10 卡位模式从配置开关转为可玩模式 |
