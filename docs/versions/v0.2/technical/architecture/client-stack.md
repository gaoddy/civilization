# 客户端技术基线增量

> 状态：方案未实施
> 依赖：[v0.1 客户端技术基线](../../../v0.1/technical/architecture/client-stack.md)、[联网与技术架构](../../../v0.1/technical/architecture/network-architecture.md)

本文记录 v0.2 客户端相对 v0.1 的增量：移动端适配与两端验收；不重复 v0.1 已确定的引擎、语言与协议。

## 1. 目标平台

| 项 | 选择 | 说明 |
| --- | --- | --- |
| 桌面端 | 沿用 v0.1 | 不改动选型与运行边界 |
| 移动端 | 同一份 Godot 4 工程与协议 | 不维护第二套界面 |

## 2. 布局适配

- 桌面端与移动端共用同一份工程；横屏与竖屏在同一场景树内通过 Control 节点与容器适配，不维护两套界面。
- 移动端断点、目标设备、安全区与输入方式由 UI 设计确定；未确定事项见[待确认事项](../../open-questions.md)。
- 规则只在服务端运行、客户端不做本地预演的约束不变。

## 3. 两端验收

- 桌面端与移动端均可完成完整对局；
- 两端在会战、比赛与控制流上行为一致，差异只允许存在于布局与输入。
