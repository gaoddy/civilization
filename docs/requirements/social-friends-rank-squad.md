# 好友榜与好友小队

本文登记 R032（原 SOC-01）「好友榜与好友小队」需求；不描述接口、表结构与实现方案。

## 状态与实现版本

- 状态：已确认
- 实现版本：v0.3

## 背景与目标

产品文档已定义好友积分榜与好友小队规则，尚未实施。

## 需求规则与验收

- 好友内积分榜
- 2–4 人小队排队
- 队内分差 ≤400
- 按平均积分匹配
- 一局最多一个小队

验收：好友榜可查看；小队按平均分进入对局，分差与队伍数量限制生效。

## 排除项

- 不做战队与社区
