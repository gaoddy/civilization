# 愿望单

本文登记 R050（原 OPS-03）「愿望单」需求；不描述接口、表结构与实现方案。

## 状态与实现版本

- 状态：待确认
- 实现版本：待定

## 背景与目标

上线前愿望单目标 ≥30,000；首周销量约为愿望单的 10%–20%。当前愿望单数为 0 或未知。

## 需求规则与验收

- 上线前愿望单 ≥30,000
- 持续跟踪首周转化

验收：上线前愿望单达到目标，首周销量转化在预期区间。

## 排除项

- 不以买量替代自然愿望单
