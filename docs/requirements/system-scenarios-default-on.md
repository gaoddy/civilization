# 场景默认开启

本文登记「场景默认开启」需求；不描述接口、表结构与实现方案。

## 编号、状态与实现版本

- 编号：R-SYS-RULE-019
- 类型与模块：玩法与系统 / 规则与平衡
- 状态：已确认
- 实现版本：v0.3
- 历史编号：R019、SYS-01

## 背景与目标

版本路线把 8 个战场从扩展层转为默认开启；首版默认关闭。

## 需求规则与验收

- 8 个战场默认开启
- 每个战场可单独开关
- 关闭时行为与 v0.2 一致

验收：8 个战场默认可用，单独关闭后对局行为回到 v0.2 口径。
