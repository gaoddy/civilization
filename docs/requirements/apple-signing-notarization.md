## 背景与目标

macOS 产物需要 Developer ID 签名与公证后才能直接分发；相关账号与证书尚未准备。

## 需求规则与验收

- Apple Developer ID 与公证账号就绪
- macOS 签名证书配置
- 产物通过公证并可直接打开

验收：macOS 产物完成签名与公证，用户双击可打开且无安全提示阻断。
