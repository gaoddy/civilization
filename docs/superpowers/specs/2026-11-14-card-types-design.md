# 卡牌分为随从与效果 — 短设计

日期：2026-11-14
范围：`docs/` 数据模型与术语

## 意图

此前数据层只覆盖 120 张站场随从，30 张非站场牌只存在于 06 的表格里，没有 id、没有独立文档，也无法参与校验。玩家与程序都需要一个明确的类型判据：能不能站场。

## 决策

- 字段：`card_type`，取值 `随从` / `效果`（用户选定）。
- 随从牌：站场，必须有 `attack`、`health`；沿用 `era`、`subtype`、`keywords`、`is_scholar`、`source`。
- 效果牌：不站场，**不得有** `attack`、`health`；必须有 `cost`（0–4）与 `match_text`，星级与流派与随从共用字段。
- 30 张原「战术牌」全部迁入 `docs/data/cards/`，各获一个语义 id；「战术牌」术语全局改为「效果牌」。
- 效果牌与随从各自维护名称唯一性；`id` 在 150 张卡内全局唯一。

## 影响

| 文件 | 改动 |
| --- | --- |
| `docs/data/cards/*.md` | 120 张随从补 `card_type: 随从`；新增 30 张效果牌文档 |
| `docs/data/validate.py` | 按类型分支校验；总数 150；效果牌禁止数值字段 |
| `docs/05-卡牌规范与数据.md` | 字段规范、约束范围、数据总览、6.6 效果牌索引 |
| `docs/06-英雄与技能.md` | §3 改为效果牌索引；术语改名 |
| `00/02/03/08/09/10/README` | 「战术牌」改为「效果牌」；数量说明更新 |

## 非目标

- 不改任何数值、效果文本、星级、费用与流派。
- 不改英雄与英雄技能。

## 校验

`python3 docs/data/validate.py`：随从 120、效果牌 30、英雄 10；类型字段合法；效果牌无 `attack`/`health`；随从分布不变；05/06 索引覆盖全部实体文档。
