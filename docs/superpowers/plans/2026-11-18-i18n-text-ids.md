# 国际化：文本 id 与中文文本表 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让运行时只使用文本 id 与英文标识，所有玩家可见中文集中到 `client/text/zh_CN.csv`，新增语言不改业务代码。

**Architecture:** 产品文档仍是中文内容源；生成器把卡名、技能文本与枚举中文名写入 Godot CSV，Godot 导入为 `.translation`，客户端用 `tr()` / `TranslationServer.translate()` 取文本。规则标识、协议取值与文档 front matter 全部改英文 id，服务端只消费 id。

**Tech Stack:** Python 3（生成与校验）、Godot 4.7 GDScript（客户端与原生翻译）、Rust（规则引擎与协议）、make（统一入口）。

**Spec:** [docs/superpowers/specs/2026-11-18-i18n-text-ids-design.md](../specs/2026-11-18-i18n-text-ids-design.md)

## Global Constraints

- 工作区：`/Users/gaoddy/Projects/Civilization/.worktrees/feature-i18n-text-ids`，分支 `feature/i18n-text-ids`，基线 `develop`；所有读写在此目录完成。
- 只改本次范围：玩家可见文案、展示文本、规则标识、协议取值、相关文档与测试；不改卡牌数值、技能效果与产品规则。
- 运行时中文只允许出现在 `client/text/zh_CN.csv`；日志（`push_error`、`print`、`push_warning`）、测试失败信息、代码注释与产品文档正文可以保留中文。
- 标识必须匹配 `^[a-z][a-z0-9-]*$`；文本 id 用小写与点分隔，形如 `ui.<页面>.<元素>`、`error.<CODE>`、`enum.<组>.<id>`、`card.<id>.name`。
- CSV：UTF-8 无 BOM、LF 换行、表头 `keys,zh_CN`、按 key 排序、key 唯一；值中的换行写成 `\n`，反斜杠写成 `\\`。
- 生成文件不手改：`client/generated/`、`server/data/v0.1/`、`protocol/generated/`。
- 所有构建、生成、校验走 `make` 目标；Godot 入口先 `make client-import`。
- 提交信息用中文，沿用 `type(scope): 描述`；末尾追加 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。

## Review Focus

1. **未导入翻译资源**：Godot 未执行导入时 `tr()` 会显示内部 id。由 `client/tests/ui_smoke_text` 与 Makefile 的 `client-import` 依赖覆盖。
2. **漏键 / 漏错误码**：界面会静默显示 `error.X` 或实体 id。由 `tests/test_i18n.py` 的 key 覆盖、`ERROR_*` 枚举对账与服务端 `error.*` 字面量扫描覆盖。
3. **迁移残留中文标识**：服务端反序列化失败或界面直接显示中文。由 `test_i18n` 的生成数据 CJK 扫描、文档校验与 Rust 测试覆盖。

- [ ] **Step 4: 实现 `scripts/gen_text.py`**

签名与行为：

```python
ROOT = pathlib.Path(__file__).resolve().parent.parent
CSV_PATH = ROOT / "client" / "text" / "zh_CN.csv"

def load_existing(path: pathlib.Path) -> dict[str, str]
def generated_entries(root: pathlib.Path) -> dict[str, str]
def merge(existing: dict[str, str], generated: dict[str, str]) -> dict[str, str]
def build(root: pathlib.Path, existing_path: pathlib.Path = CSV_PATH) -> str
def write(root: pathlib.Path, path: pathlib.Path = CSV_PATH) -> None
def check(path: pathlib.Path = CSV_PATH) -> list[str]
```

- `generated_entries` 只生成内容 key：`card.<id>.name`、`card.<id>.match_text`（非空时）、`skill.<id>.name`（非空时）、`skill.<id>.text`、`skill.<id>.match_text`（非空时）、`token.<id>.name`。枚举 key 在 Task 2 加入。
- `load_existing` 用 `csv.reader`；文件不存在时返回空字典。读入后把值按 Godot CSV 规则反转义：`\n` → 真实换行、`\\` → 反斜杠（用 `_unescape` 从左到右扫描，避免二次解码）。
- `merge` 丢掉 existing 中落在 `GENERATED_PREFIXES` 的 key，以生成值为准；保留 `MANUAL_PREFIXES` 内的 key；其余前缀抛 `ValueError`。
- `build` 读取 `existing_path` 的人工 key，合并 `generated_entries(root)` 后输出 `keys,zh_CN` 表头与按 key 排序的行；值转义用 `_escape`：先 `\` → `\\`，再把真实换行 → `\n`；用 `csv.writer(..., lineterminator="\n")`。
- `write` 用 `build(root, path)` 生成文本并写入 `path`；`check` 比较 `path` 内容与 `build(ROOT, path)`，一致返回空列表，否则返回 `["client/text/zh_CN.csv"]`。
- `main(argv=None)` 支持 `--check` 与 `--output`，输出「文本表无漂移」/「文本漂移」风格的消息。

def test_no_cjk_runtime_literals(self):
    offenders = []
    for path in sorted((ROOT / "client").rglob("*.gd")):
        rel = path.relative_to(ROOT / "client").as_posix()
        if rel.startswith(("generated/", "tests/")):
            continue
        for number, line in enumerate(path.read_text(encoding="utf-8").splitlines(), 1):
            if re.search(r"\b(push_error|push_warning|print|printerr)\s*\(", line):
                continue
            for literal in _string_literals(_strip_comment(line)):
                if _CJK.search(literal):
                    offenders.append(f"{rel}:{number}: {literal}")
    self.assertEqual(offenders, [], "\n".join(offenders))

def test_all_error_codes_have_text(self):
    protocol = (ROOT / "client" / "generated" / "protocol.gd").read_text(encoding="utf-8")
    codes = re.findall(r'^const ERROR_[A-Z0-9_]+ := "([A-Z0-9_]+)"$', protocol, re.M)
    keys = _keys((ROOT / "client/text/zh_CN.csv").read_text(encoding="utf-8"))
    self.assertEqual([f"error.{code}" for code in codes if f"error.{code}" not in keys], [])

def test_server_error_ids_exist(self):
    keys = _keys((ROOT / "client/text/zh_CN.csv").read_text(encoding="utf-8"))
    missing = []
    for path in sorted((ROOT / "server" / "crates").rglob("*.rs")):
        for match in re.finditer(r'"(error\.[A-Za-z0-9_.]+)"', path.read_text(encoding="utf-8")):
            if match.group(1) not in keys:
                missing.append(f"{path.name}: {match.group(1)}")
    self.assertEqual(missing, [])

def test_tr_keys_exist(self):
    keys = set(_keys((ROOT / "client/text/zh_CN.csv").read_text(encoding="utf-8")))
    missing = []
    for path in sorted((ROOT / "client").rglob("*.gd")):
        rel = path.relative_to(ROOT / "client").as_posix()
        if rel.startswith(("generated/", "tests/")):
            continue
        text = path.read_text(encoding="utf-8")
        for key in re.findall(r'(?:tr|TranslationServer\.translate)\(\s*"([^"]+)"', text):

            if key not in keys:
