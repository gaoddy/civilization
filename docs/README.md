## 数据

| 目录 | 内容 | 数量 |
| --- | --- | --- |
| [cards/](data/cards) | 每张卡一个文档，文件名 = id；`card_type` 区分随从与效果 | 150 |
| [heroes/](data/heroes) | 每位英雄一个文档，文件名 = id | 10 |
| [validate.py](data/validate.py) | 标准库校验脚本 | — |

实体文档是唯一数据源：卡面、平衡工具、服务端校验都从这里读取。每个文档由 YAML front matter 承载字段、`## 属性` 表复述同一组字段、正文承载效果与设计说明；三处一致性由 [validate.py](data/validate.py) 交叉校验。字段规范见 [05 · 卡牌规范与数据](05-卡牌规范与数据.md) §1。

## 术语

- **时代**：玩家已升到的商店等级，1–5（史前到未来）。
- **星级**：随从的强度等级，1–6，与时代不是同一个概念。
- **流派**：6 个（人类/机械/生物/植物/病毒/学者），每局启用 5 个。
- **学者**：攻击力恒为 0、只提供加成的流派。
- **成长 / 繁衍**：两个核心机制，完整定义见 [03 · 关键词与机制](03-关键词与机制.md)。
- **装配 / 播种 / 进化**：机械/植物/生物三个流派的专属关键词，不按时代解锁，见 03 分册 §1.1。
- **陨落**：扩展层机制，定义见 [00 · 设计总纲](00-设计总纲.md) §6.9。
