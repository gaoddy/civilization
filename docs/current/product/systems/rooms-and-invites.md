# 房间与邀请

> 依赖：[核心规则](../rules/core-rules.md)、[模式](modes.md)、[好友](friends.md)、[联网与技术架构](../../technical/architecture/network-architecture.md)
> 状态：已实现（2026-11-19）

本文描述 v0.1 的成局方式：创建房间、房间码加入、好友邀请加入，以及房间内的准备、开局、房主管理、结算后离开、退出与断线规则；不描述自动匹配（v0.2）、技术实现与页面视觉。归属已实现产品状态的系统规则。

## 1. 定位与范围

- v0.1 不提供自动匹配与公开房间列表；所有对局通过创建房间、房间码加入或好友邀请成局。
- 房间局不计入天梯；v0.1 没有积分、段位与排行榜。
- 房间支持会战模式；v0.1 建房不提供场景/陨落开关，两者固定关闭，扩展层留到后续版本。
- 页面与视觉见 UI 设计文档，本文只定义规则与状态。

## 2. 创建房间

- 登录后可创建房间，创建者成为房主。
- 创建时不提供场景/陨落开关；首版两者固定关闭。
- 房间创建后生成 6 位房间码，字符集为大写字母与数字并排除易混字符 `0`、`O`、`1`、`I`，房主可复制分享。
- 房间容量为 8 人；房间人数不足 8 人时不能开局。
- 房主可以解散房间；解散后所有成员回到大厅并收到「房间已解散」提示，房间码立即失效。

## 3. 加入房间

| 方式 | 规则 |
| --- | --- |
| 房间码 | 输入完整的 6 位房间码加入；房间码错误、房间已满或对局已开始时加入失败 |
| 好友邀请 | 收到好友邀请后点击接受加入；邀请 60 秒内未响应自动失效 |

- 加入成功后进入房间等待区，显示当前人数与各成员准备状态。
- 房间满 8 人后不再接受加入。
- 对局已经开始时，新玩家不能加入；对局结束后房间恢复到可加入状态。
- 首版不做公开房间列表、随机加入与推荐房间。

## 4. 准备与开局

- 每位成员（含房主）在等待区点击准备。
- 8 人全部准备后由服务端自动开局，不设房主「开始」操作；人数不足或有人未准备时保持等待。
- 开局后房间进入对局状态，未准备的成员不能留在房间。
- 房主开局前可以移除其他成员，不能移除自己；被移除的成员立即回到大厅并收到「已被房主移出房间」提示，房间码不变。
- 房主离开房间时，房主身份转移给座位号最小的剩余成员；最后一名成员离开后房间销毁、房间码失效。

## 5. 房间内对局

- 会战模式按[核心规则](../rules/core-rules.md)与[模式](modes.md)结算。
- 房间局不改变积分、段位与排行榜；结算页只展示本局名次与对局数据。
- 对局结束时服务端立即销毁房间：所有成员同时离座，房间与房间码失效，不保留等待区。结算页只展示本局结果，点「确定」只做客户端导航并回到大厅。
- v0.1 不提供从结算页返回房间等待区的入口；原房间码不可再加入，要再玩需重新建房、凭新房间码加入或接受邀请。
- 结算页不依赖房间继续存在，也不显示房间状态提示；结算页断线后重连只回大厅，不补发上一局结果。
- 首版不做观战；对局中的空位不补入新玩家，v0.1 也不做 AI 托管。

## 6. 断线与退出

- 断线后可在对局结束前重连，重连回到原座位并恢复当前状态。
- 断线后座位保留至对局结束，玩家重连后回到原座位；v0.1 不做 AI 托管，托管移到 v0.2。
- 主动退出对局：已淘汰的玩家保留原淘汰名次；仍未淘汰的玩家按当时存活人数结算（第一次退出为第 8 名，之后依次为第 7、第 6 名，依此类推）。退出后立即离开房间并停止接收该局消息，对局继续；仅剩 1 名未淘汰玩家时立即结束。房间局不计分，因此不涉及积分变化。
- 断线不算主动退出；重连回到原座位并恢复当前状态。
- 服务器维护或对局异常中断时，该局作废，玩家回到主界面。

## 7. 状态与边界

| 场景 | 表现 |
| --- | --- |
| 未登录 | 创建与加入房间不可用，提示先登录 |
| 房间码错误 | 提示房间不存在，停留在输入页 |
| 房间已满 | 加入失败，提示房间已满 |
| 对局已开始 | 加入失败，提示对局已开始 |
| 邀请 60 秒未响应 | 邀请自动失效 |
| 房主解散房间 | 所有成员回到大厅并提示原因，房间码立即失效 |
| 被房主移除 | 回到大厅并提示原因；房间码仍可用，其余成员继续等待 |
| 房主离开 | 房主转移给座位号最小的剩余成员；最后一人离开后房间销毁 |
| 人数不足 8 人 | 不能开局，房主可继续等待或解散 |
| 对局结束 | 房间立即销毁，房间码失效；结算页展示本局结果，点「确定」仅导航回大厅 |
| 对局中主动退出 | 按当时存活人数结算名次后离开，对局继续；仅剩 1 名未淘汰玩家时立即结束 |
| 断线 | 显示重连中；座位保留至对局结束（v0.1 不托管） |

## 8. 首版不做

- 不做自动匹配、公开房间列表、随机加入与快速开始。
- 不做跨房间邀请链接与二维码。
- 不做观战、赛事、战队与语音。
- 不做对局中移除成员、AI 托管与空位补人。
- 不做场景、陨落、英雄坐镇与大决战的建房开关与规则实现。
- 不做房间局积分、段位与排行榜。

## 9. 验收标准

1. 登录后可以创建房间并得到 6 位房间码。
2. 输入正确的房间码可以加入房间；错误房间码、已满房间与已开局房间加入失败。
3. 好友邀请 60 秒未响应后自动失效。
4. 8 人全部准备后服务端自动开局；缺人或有人未准备时不能开局。
5. 房主可移除指定成员与解散房间；被移除者回大厅且房间码仍可用，解散后所有成员回大厅且房间码失效。
6. 房主离开后房主身份转移给座位号最小的剩余成员；最后一人离开后房间销毁。
7. 对局结束时房间立即销毁、房间码失效；结算页只提供「确定」，点击后回到大厅。
8. 未淘汰者主动退出按当时存活人数结算名次，对局继续；仅剩 1 名未淘汰玩家时立即结束。
9. 断线后座位保留至对局结束，重连后回到原座位；v0.1 不进入托管。
10. 房间局结算页不展示积分与段位变化；建房不提供场景/陨落开关。
