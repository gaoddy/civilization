# 卡片容器

> 状态：已实现
> 入口：`UIControls.card_panel(variant)`，`client/ui/controls.gd`
> 样式来源：`UITheme.panel_style(variant)`，`client/ui/theme.gd`

## 用途

统一区块、卡片与占位槽的背景、描边、圆角与内边距。

## 变体

| 变体 | 表现 | 用途 |
| --- | --- | --- |
| `surface` | 面板底色 + 常规描边 + 12 内边距 | 区块面板：左栏积分榜、图鉴常驻详情与房间面板 |
| `row` | 面板底色 + 8 内边距 | 紧凑行：座位行 |
| `raised` | 提亮底色 + 12 内边距 | 弹层与独立卡片 |
| `raised-tight` | 提亮底色 + 8 内边距 | 紧凑独立卡片（非卡面容器） |
| `raised-flush` | 提亮底色 + 1px 描边内缩、无内容内边距 | 卡面容器：随从卡、商店槽、手牌卡、战斗只读卡与图鉴卡面 |
| `bare` | 透明、无描边、无内边距 | 仅作布局容器：招募与战斗组合、商店面板（出售落点静息态） |
| `accent-bare` | 金色 12% 底 + 金色 2px 描边、无内边距 | 出售落点悬停态 |
| `cover-info` | 半透明下沉底 + 无描边 + 上圆角 0、下圆角 12 + 6 内边距 | 卡面底部信息区 |
| `sunken` | 下沉底色 | 预留，当前页面未使用 |
| `accent` / `accent-row` | 金色 12% 底 + 金色描边 | 本人席位高亮、图鉴分类目录选中 |
| `success` / `danger` | 状态色 12% 底 + 状态色描边 | 预留，当前页面未使用 |
| `transparent` | 无底色无描边 | 仅作布局容器 |

卡面容器只留 1px 描边：封面用带卡面圆角的面板绘制，卡面美术向内收 3px，方形美术的四角落在卡片圆角以内；底部信息区仍是 `cover-info` 的 6px 内边距。

## 属性与事件

- 只接受变体字符串，不接受任意色值；需要新外观时在 `UITheme.panel_style` 增加变体。
- 无事件；内容由调用方作为子节点放入。
- 工厂会给除 `cover-info` 以外的变体叠一层 [框体材质](frame-material.md)：边框叠在内容内边距以内，不改变面板布局。

## 禁用场景

- 不用卡片容器实现布局层级；层级由容器嵌套与间距表达。
- 不在页面里覆盖容器的 `panel` 样式。

## 使用者

- 对局页全部区块与卡片。

## 卡面与详情中的玩法与分类

卡片容器之上的内容由按场景拆分的卡面组件（`CardFaceBase` 与 `ShopCardFace`、`HandCardFace`、`BoardCardFace`、`GalleryCardFace`）与 `DetailLayer` 构造，分类展示口径如下：

- 卡面：封面取首条玩法色压暗（`UITheme.playstyle_cover`）；底部信息区的类型位显示全部玩法名（`playstyle_text`，走 `enum.playstyle.<id>`，多项用「、」分隔，缺失显示「未定」），完整类型由详情面板给出。
- 商店卡详情：依次为名称、类型、科学分类（完整路径，缺失显示「未定」）、玩法、关联分类（只含 `prey:` / `host:`，为空时省略）、费用、原始数值、时代、技能文本与不可购买原因。
- 随从详情：名称、科学分类、玩法、关联分类、技能介绍，再接攻击/生命的分层六行。
- 英雄详情：名称、介绍、玩法、关联分类与英雄技能文本；英雄卡不含科学分类、时代、费用与原始数值。
