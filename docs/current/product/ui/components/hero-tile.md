# 英雄小卡

> 状态：已实现
> 入口：`UI.hero_tile(hero_id, width)`，`client/ui/ui.gd`

## 用途

展示一名英雄：头像块、名字、玩法、最多两行技能摘要。

## 属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `hero_id` | `String` | 英雄卡 id；空串表示未选英雄 |
| `width` | `int` | 卡片最小宽度，默认 150 |

## 变体与状态

- 无变体。`hero_id` 为空时显示「未选英雄」、中性描边与「?」头像。
- 描边颜色随英雄玩法取值，见 [tokens.md](../tokens.md#6-玩法色)。
- 技能摘要超过两行时省略；完整文本在页面数据中另行展示。

## 事件

无。卡片只做呈现，不响应点击，选中状态由页面另行表达。

## 禁用场景

- 不用于随从、法术或非英雄卡。
- 不承载准备、存活等状态；这些状态由页面用文本或颜色另行标注。

## 使用者

- 当前无页面使用（预留）：房间页候选英雄卡为 `RoomHeroCard`（`client/scenes/room_hero_card.gd`），对局页英雄卡为 `GameHeroCard`（64×84）。
