# 头像块

> 状态：已实现
> 入口：`Avatar.create(hero_id, size)`，`client/ui/avatar.gd`

## 用途

在没有图片资源的前提下表示一名英雄：玩法色描边的圆角块，中间是名字首字。

## 属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `hero_id` | `String` | 英雄卡 id；空串显示「?」与中性色 |
| `size` | `int` | 边长，取 `avatar-sm` / `avatar-md` / `avatar-lg` 度量或页面给定值 |

## 变体与状态

- 无变体；尺寸、描边与文字颜色随入参和玩法色变化。
- 背景为玩法色压暗、描边为玩法色、文字为玩法色提亮。

## 事件

无。

## 禁用场景

- 不用于非英雄对象（随从、法术）。
- 不表达准备、淘汰、托管等状态，避免颜色语义冲突；状态用文本标记。

## 使用者

- 左栏座位行（边长按行高与左栏内宽解算，布局前回退 `avatar-rail` = 44 / 手机 40）：血量条叠在头像底部内侧，不额外占用行高。
- 座位行的名次角标叠在左上角，由页面另行添加，头像本身不承担名次信息或血量。
- 对局页的售货员与战斗对手头像使用页面私有的 `GamePortrait`（64×64，可带名字条），不使用本构件。
- 战斗英雄条随改版删除，不再使用头像。
