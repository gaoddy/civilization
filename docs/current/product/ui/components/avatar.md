# 头像块

> 状态：已实现
> 入口：`UI.avatar(hero_id, size)`，`client/ui/ui.gd`

## 用途

在没有图片资源的前提下表示一名英雄：部落色描边的圆角块，中间是名字首字。

## 属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `hero_id` | `String` | 英雄卡 id；空串显示「?」与中性色 |
| `size` | `int` | 边长，取 `avatar-sm` / `avatar-md` / `avatar-lg` 度量或页面给定值 |

## 变体与状态

- 无变体；尺寸、描边与文字颜色随入参和部落色变化。
- 背景为部落色压暗、描边为部落色、文字为部落色提亮。

## 事件

无。

## 禁用场景

- 不用于非英雄对象（随从、法术）。
- 不表达准备、淘汰、托管等状态，避免颜色语义冲突；状态用文本标记。

## 使用者

- 英雄小卡、积分榜座位行、对手小卡、战斗英雄条。
