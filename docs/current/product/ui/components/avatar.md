# 头像块

> 状态：已实现
> 入口：`Avatar.create(hero_id, size)`，`client/ui/avatar.gd`

## 用途

表示一名英雄的方形头像：继承 [头像框](avatar-frame.md) 的圆角裁切与叠在头像之上的描边。有头像纹理时按 cover 铺满并收进圆角，否则用玩法色封面 + 名字首字表示。

## 属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `hero_id` | `String` | 英雄卡 id；空串显示「?」与中性色 |
| `size` | `int` | 边长，取 `avatar-sm` / `avatar-md` / `avatar-lg` 度量或页面给定值 |

## 变体与状态

- 无变体；尺寸、描边与文字颜色随入参和玩法色变化。
- 封面为玩法色压暗、描边为玩法色 2px、文字为玩法色提亮。
- 头像素材按 `STRETCH_KEEP_ASPECT_COVERED` 铺满，四角由框的 `radius-md` 圆角裁切；裁切层同时绘制玩法色封面，无素材时不会透出背景。
- 节点名保持 `Avatar`，裁切层、圆角描边与首字由 `AvatarFrame` 提供。

## 事件

无。

## 禁用场景

- 不用于非英雄对象（随从、法术）。
- 不表达准备、淘汰、托管等状态，避免颜色语义冲突；状态用文本标记。

## 使用者

- 左栏座位行（边长按行高与左栏内宽解算，布局前回退 `avatar-rail` = 44 / 手机 40）：头像为圆角方形，血量条叠在头像底部内侧，不额外占用行高。
- 座位行的名次角标叠在头像内左上角，圆形深色半透明底、白色数字，由页面另行添加；头像本身不承担名次信息或血量。
- 对局页的售货员、战斗对手与战斗开场头像使用页面私有的 `GamePortrait`（64×64 圆角头像块，同样基于 [头像框](avatar-frame.md)，可带名字条与贴图）。
- 战斗英雄条随改版删除，不再使用头像。
