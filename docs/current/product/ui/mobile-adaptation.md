# 移动端适配（iOS）

> 状态：已实现
> 代码：`client/autoload/screen_profile.gd`、`client/ui/safe_area.gd`；实现细节见[客户端技术现状](../../technical/client.md) §9

本文记录 iOS 端（iPhone 与 iPad）已实现的产品表现：屏幕方向、缩放基准、触控映射、安全区与命中尺寸。桌面端规则见[交互约定](interactions.md)，不在此重复。

## 1. 平台与方向

- iOS 端与 macOS 桌面端共用同一套页面、规则与服务端；不做移动端独立版本。
- 固定横屏，支持左横与右横；不提供竖屏布局，旋转设备不重排页面。
- Android 不在当前范围。

## 2. 缩放基准

- iPhone 以 960×540 逻辑视口等比缩放，iPad 与桌面以 1280×720；两种基准都保持 16:9。
- 页面结构、信息层级与操作顺序与桌面一致，只随可用尺寸换行与收缩，不隐藏功能。

## 3. 触控映射

| 桌面操作 | iOS 操作 |
| --- | --- |
| 悬停查看卡牌与座位详情 | 长按 450ms 显示，抬手或点击空白关闭；单击仍执行原有操作 |
| 左键点击 | 单指点击 |
| `Esc` 返回 | 页面常驻返回按钮 |
| 键盘输入 | 点击输入框调起系统键盘 |
| 拖拽出牌、上阵与卖出 | 单指拖拽；拖回原位或拖到无效区域取消 |

- 按下后移动超过阈值即按拖拽处理，不再触发长按详情。
- 详情覆盖层打开、待选浮层或战报浮层存在时，长按不显示详情，与桌面悬停的阻塞规则一致。

## 4. 安全区与键盘

- 刘海、灵动岛、Home 指示条与圆角安全区不遮挡可点击控件与关键文本；等比缩放的留白已覆盖的边不再重复留白。
- 键盘弹出时，输入页底部让出键盘高度（取键盘与安全区的较大值，不叠加）；失焦后恢复。
- 登录、大厅房间码与好友搜索的输入框在键盘弹出期间保持可见。

## 5. 命中尺寸

- 主要操作控件（按钮、卡面、座位行、手牌）命中区域不小于 44×44 逻辑点。
- 行内小控件（翻页、冻结、返回、关闭）不小于 32×32 逻辑点。
- 命中区域放大只调整控件最小高度，不改变页面结构；相邻控件不产生误触。

## 6. 图鉴的小屏布局

- iPhone 基准下，图鉴目录宽度收窄、常驻详情宽度收窄、卡面网格由 5 列改为 4 列；每页仍为 40 张，滚动查看。
- iPad 与桌面保持原有目录、详情宽度与 5 列网格。

## 7. 状态与边界

- 启动、加载、空态、错误提示与断线重连表现与桌面一致。
- 切到后台再回前台按现有断线重连规则处理。
- iOS 端不请求相机、定位、通知与通讯录权限；首次连接局域网服务器时由系统提示本地网络权限。
- 交付形态为开发签名真机包，不做 App Store 分发、TestFlight 与公证。
