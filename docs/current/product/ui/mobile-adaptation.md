# 移动端适配（iOS）

> 状态：已实现
> 代码：`client/autoload/screen_profile.gd`、`client/ui/safe_area.gd`；实现细节见[客户端技术现状](../../technical/client.md) §9

本文记录 iOS 端（iPhone 与 iPad）已实现的产品表现：屏幕方向、缩放基准、触控映射、安全区与命中尺寸。桌面端规则见[交互约定](interactions.md)，不在此重复。

## 1. 平台与方向

- iOS 端与 macOS 桌面端共用同一套页面、规则与服务端；不做移动端独立版本。
- 固定横屏，支持左横与右横；不提供竖屏布局，旋转设备不重排页面。
- Android 不在当前范围。

## 2. 缩放基准

- 页面内容固定 16:9 居中等比缩放（contain）：高度取 `min(视口高, 视口宽 ÷ 16 × 9)`，宽度按比例，受限的一侧贴满、另一侧留背景；内容始终完整显示、不裁切。iPhone 以 960×540、iPad 与桌面以 1280×720 为设计基准。
- 背景铺满整个可视区域（等比裁切，不变形），内容框之外的区域露出背景：iPhone 横屏约 19.5:9，比 16:9 更宽，左右露出背景；iPad 强制横屏为 4:3，内容只占高度的 75%，上下各露出约 12.5% 背景；桌面拖成 16:10 时内容占高度 90%，上下各露出约 5%。安全区落在背景带内的边记 0，不重复留白。
- 页面结构、信息层级与操作顺序与桌面一致，只随可用尺寸换行与收缩，不隐藏功能；桌面窗口拖动缩放同样只改变背景露出范围，内容保持 16:9 居中。

## 3. 触控映射

| 桌面操作 | iOS 操作 |
| --- | --- |
| 悬停查看卡牌与座位详情 | 长按 450ms 显示，抬手或点击空白关闭；单击仍执行原有操作 |
| 左键点击 | 单指点击 |
| `Esc` 返回 | 页面常驻返回按钮 |
| 键盘输入 | 点击输入框调起系统键盘 |
| 拖拽购买、出牌、上阵与卖出 | 单指拖拽；拖回原位或拖到无效区域取消 |
| 按住技能按钮 / 战吼待选拖出选目标箭头 | 同一手势：按住拖出，弧线跟随手指；抬手落在候选上生效，落在其它位置取消或放弃 |

- 按下后移动超过阈值即按拖拽处理，不再触发长按详情。
- 目标待选瞄准中、详情覆盖层打开、发现/进化浮层或战报浮层存在时，长按不显示详情，与桌面悬停的阻塞规则一致。

## 4. 安全区与键盘

- 刘海、灵动岛、Home 指示条与圆角安全区不遮挡可点击控件与关键文本；安全区只在该边被内容框覆盖时生效，落在背景带内的边记 0，不重复留白。
- 页面背景铺满整个可视区域，包括安全区占用的边；内容框固定 16:9 居中，安全区只约束内容控件，Home 指示条区域不露出底色空条。
- 键盘弹出时，输入页底部让出键盘越过内容框底边的高度（先与背景带抵消，再取与安全区的较大值，不叠加）；失焦后恢复。
- 登录、大厅房间码与好友搜索的输入框在键盘弹出期间保持可见。

## 5. 命中尺寸

- 主要操作控件（按钮、卡面、座位行、手牌）命中区域不小于 44×44 逻辑点。
- 对局页左栏为容纳 8 席且不滚动，座位行在 iPhone 下是边长约 57 画布单位的正方形（约 41–45pt），点击目标为整个座位框，行间只留 2 单位间距，避免相邻座位误触。
- 行内小控件（冻结、返回、关闭）不小于 32×32 逻辑点。
- 命中区域放大只调整控件最小高度，不改变页面结构；相邻控件不产生误触。

## 6. 小屏布局

- 对局页在 iPhone 基准下收紧页边距、顶部工具条、商店操作行、河道与卡面尺寸（卡面 70×91，保持桌面 112:146 的卡形，只缩尺寸不改比例），舞台的纵向顺序与桌面一致；手牌、英雄行与棋盘均完整可见，不出现滚动或裁切。商店与棋盘卡不显示技能介绍，完整文本由长按详情给出；手牌保留介绍，受卡面高度限制只显示 1 行 8px 并省略，移动端暂不在手牌卡面展开完整文本。
- 左栏积分榜的 8 个座位行是正方形可选框（行距 2），边长取左栏内宽与人均可用高度的较小值并按可用高度等比缩小（手机约 57，桌面受左栏内宽限制为 64），头像铺满框内（边长 = 行边长 − 4），血量条 4 叠在头像底部内侧；8 席一屏放下，含底部安全区与 Home 指示条偏移时也不出现滑动，不使用滚动容器。桌面与 iPad 同样按边长排列并垂直居中，不再均分行高。
- 大厅在 iPhone 基准下把创建与加入房间收在中央面板，好友入口固定在左下角、卡牌图鉴固定在右下角；好友列表与最近队友在浮层内部滚动，主页不需要滚动即可看到全部入口。
- 图鉴在 iPhone 基准下，随从视图不再显示左侧目录，改由主体工具栏「分类：<当前分类>」按钮打开两列分类面板（宽 360，覆盖网格，不挤压布局）；「全部 / 随从 / 效果」二级筛选常驻工具栏。
- iPhone 网格为 6 列、列距 `space-md`；常驻详情收窄到 176，预览 128×167；头部时代栏、工具栏、网格与详情均在 960×540 内容框内，无纵向溢出。
- iPad 与桌面为 6 列、列距 `space-lg`，详情 280、预览 200×261；随从视图保留左侧目录。
- 全部设备取消分页按钮，改为滚动加载：桌面与 iPad 每批 18 张，iPhone 每批 12 张；滚到底部追加下一批，底部显示已加载张数与提示。

## 7. 状态与边界

- 启动、加载、空态、错误提示与断线重连表现与桌面一致。
- 切到后台再回前台按现有断线重连规则处理。
- iOS 端不请求相机、定位、通知与通讯录权限；首次连接局域网服务器时由系统提示本地网络权限。
- 交付形态为开发签名真机包，不做 App Store 分发、TestFlight 与公证。
