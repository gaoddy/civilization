# 图标

> 状态：已实现
> 入口：`client/ui/icons.gd`（`Icons`）
> 使用：`Icons.draw(canvas, icon, rect, color, width)`

图标由代码绘制矢量路径，不引入图片或字体资源；调用方只在 `_draw()` 内调用。

## 1. 绘制约定

| 项 | 规则 |
| --- | --- |
| 网格 | 所有图标在 24×24 网格上定义，按 `rect` 等比映射并居中，不拉伸变形 |
| 粗细 | `width` 以网格单位传入，默认 2；映射后最小 1 像素 |
| 颜色 | 由调用方传入，图标自身不带颜色语义；禁用、激活等状态由调用方换色 |
| 未知图标 | 不绘制、不报错，缺失时界面不出现占位符 |
| 落点 | `Icons` 只画路径，不建节点、不发信号；角标与点击由组件负责 |

## 2. 图标清单

| 图标 | 语义 | 形状 | 使用场景 |
| --- | --- | --- | --- |
| `upgrade` | 升级时代 | 竖轴加人字箭头 | 商店操作行「升级时代」按钮 |
| `reroll` | 刷新商店 | 约 300° 圆弧加箭头头部 | 商店操作行「刷新」按钮 |
| `freeze` | 冻结商店 | 三条主轴加端点短枝的雪花 | 商店操作行「冻结」按钮 |
| `hero_power` | 英雄主动技能 | 收腰四角星，实心 | 英雄行主动技能按钮 |
| `passive_skill` | 英雄被动技能 | 外环加实心圆心的同心圆 | 英雄行被动技能标记 |

## 3. 使用规则

- 页面与组件不内联图标路径，新增图标先登记到本文件并在 `Icons.draw` 中实现。
- 图标按钮的费用与次数角标不是图标，由组件用 `font-micro` 文本绘制。
- 选目标弧线、候选角标、命中描边与无效叉号不是图标，由[技能瞄准层](components/aim-layer.md)在自身 `_draw()` 中绘制，不进 `Icons`。
- 图标按钮的尺寸取 `shop-icon-size`，图标区域在按钮内居中。
