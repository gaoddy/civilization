# 通用交互

> 状态：已实现
> 代码：`client/ui/ui.gd`、`client/ui/theme.gd`、`client/scenes/game.gd`

## 1. 控件状态

| 状态 | 表现 | 规则 |
| --- | --- | --- |
| 默认 | `color-surface-raised` 底、`color-border` 描边 | `UI.styled_button` 统一设置 |
| 悬停 | 底色提亮、描边转为 `color-border-strong` | 只改变视觉，不改变可用性 |
| 按下 | 底色压暗 | 松开后发出一次操作 |
| 聚焦 | 描边转为 `color-accent` | 键盘 `Tab` 可遍历主要操作 |
| 禁用 | 底色退回 `color-surface`、文本转 `color-text-muted` | 禁用原因写入 `tooltip_text`，不只置灰 |

- 主操作（结束招募）使用 `primary` 变体，其余使用 `default`；卡内次要操作（出售、左右移位）使用 `micro` 变体。
- 禁用原因取 `affordances` 的 `disabledReason`，经 `UI.error_text` 转为中文后放入 tooltip。

## 2. 操作反馈

- 操作发出后不等待本地确认，界面以下一条服务端视图为准；视图未变化前按钮保持原状态。
- 发送失败（未连接）时状态行显示「未连接，操作未发出」，不静默丢弃。
- 服务端错误在状态行显示固定中文文案，协议 `message` 只进 tooltip；错误去向由 `UI.error_route` 决定：认证类回登录并清会话，`NOT_IN_ROOM` / `ROOM_NOT_FOUND` 回大厅并清房间，其余留在当前页面。

## 3. 弹层

| 弹层 | 触发 | 出口 |
| --- | --- | --- |
| 发现 / 进化选择 | `self.pendingChoices` 非空 | 点选一项发出 `ChooseDiscover` |
| 目标选择 | 需要目标的操作未带目标；或服务端回 `NO_VALID_TARGET` | 选己方随从、可选「不指定目标」、「取消」 |

- 弹层使用全屏遮罩与居中卡片，同一时刻只显示一个。
- 视图过期、倒计时归零或已结束招募时关闭弹层且不再弹出，避免用上一回合的操作。

## 4. 倒计时

- 顶栏金色胶囊显示「剩余 N 秒」，每 0.25 秒按 `phaseDeadline` 重算。
- 归零后结束招募、刷新、升时代、购买、出牌、出售、重排一并禁用，只等服务端推进阶段。

## 5. 动效与无障碍

- 当前没有动画与过渡；界面在每次视图更新时整体重建，避免状态叠加。
- 所有操作控件都有中文文本；主要操作可用键盘完成，焦点可见。
- 界面不依赖位图与图标资源，文字本身承载全部语义。
