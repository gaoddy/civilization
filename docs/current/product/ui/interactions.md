# 通用交互

> 状态：已实现
> 代码：`client/ui/controls.gd`、`client/ui/navigation.gd`、`client/ui/wording.gd`、`client/ui/theme.gd`、`client/pages/game/game.gd`、`client/ui/card_gallery.gd`

本文记录桌面端已实现的通用交互；iOS 端的横屏、缩放、长按与命中尺寸差异见[移动端适配](mobile-adaptation.md)。

## 1. 控件状态

| 状态 | 表现 | 规则 |
| --- | --- | --- |
| 默认 | `color-surface-raised` 底、`color-border` 描边 | `UIControls.styled_button` 统一设置 |
| 悬停 | 底色提亮、描边转为 `color-border-strong` | 只改变视觉，不改变可用性 |
| 按下 | 底色压暗 | 松开后发出一次操作 |
| 聚焦 | 描边转为 `color-accent` | 键盘 `Tab` 可遍历主要操作 |
| 禁用 | 底色退回 `color-surface`、文本转 `color-text-muted` | 禁用原因写入 `tooltip_text`，不只置灰 |

- 主操作（倒计时悬停后翻出的「结束招募」）使用 `primary` 变体，其余使用 `default`；棋盘随从卡不放卡内按钮，换位与出售由拖拽完成。
- 禁用原因取 `affordances` 的 `disabledReason`，经 `UIWording.error_text` 转为中文后放入 tooltip。

## 2. 操作反馈

- 操作发出后不等待本地确认，界面以下一条服务端视图为准；视图未变化前按钮保持原状态。
- 发送失败（未连接）时顶部工具条的状态文本显示「未连接，操作未发出」，不静默丢弃。
- 服务端错误在顶部工具条的状态文本显示固定中文文案，协议 `message` 只进 tooltip；错误去向由 `UINavigation.error_route` 决定：认证类回登录并清会话，`NOT_IN_ROOM` / `ROOM_NOT_FOUND` 回大厅并清房间，其余留在当前页面。

## 3. 弹层

| 弹层 | 触发 | 出口 |
| --- | --- | --- |
| 发现 / 进化选择 | `self.pendingChoices` 非空且队首不是目标待选 | 点击一排卡面或选项块中的一项发出 `ChooseDiscover` |

- 选择浮层使用全屏遮罩与居中一排：发现显示与手牌同尺寸的卡面，进化显示同尺寸选项块；同一时刻只显示一个。
- 选目标不再使用弹层：英雄技能与随从战吼都改为从技能按钮或入场随从拉出弧线，松手生效，见[技能瞄准层](components/aim-layer.md)与 §3.1；发现与进化选择仍使用全屏浮层，点击即选中。
- 候选为空时不产生目标待选：效果牌按不可打出处理，需要目标的主动技能按钮禁用并给出 `NO_VALID_TARGET` 原因。
- 视图过期、倒计时归零、已结束招募或不在招募阶段时关闭弹层且不再弹出，避免用上一回合的操作；跨回合保留的发现/进化待选不会盖在战斗演示上。

## 3.1 拖拽操作

- 手牌只能拖拽出牌，点击手牌不产生任何意图。
- 三种卡（手牌、棋盘随从、商店）的拖拽预览都保持指针按下时在卡上的位置：卡片跟着指针移动，预览不从左上角起算。
- 拖拽期间不显示任何卡的悬停详情：购买经过自己棋盘、出售经过商店卡都不弹出介绍；松手或取消后指针移入卡片才恢复。
- 商店卡只能拖拽购买：拖到贴底手牌带（含已有手牌卡上）松手发出 `BuyMinion{slot}`；点击商店卡不产生意图。拖起后原卡隐藏、原位留同尺寸空白（与棋盘随从卡一致），松手或取消后恢复。不可购买的商店卡不能起手；拖到其它区域静默取消。
- 随从牌落在棋盘上：落点决定插入下标（落在某张随从卡上即插到该卡之前，落在卡片之间或末尾空白则按指针与各卡中心的相对位置取下标），原下标及其右侧随从依次右移；棋盘已满时不接受，容量与「随从 x/y」提示以服务端下发的上限为准。
- 随从牌拖拽期间棋盘实时预览插入位：指针在棋盘内移动时，在插入下标处放同尺寸透明占位，其余随从实时让位；棋盘已满、指针在棋盘外或拖拽的是效果牌时不显示占位。落点与松手规则不因预览改变。
- 需要目标的效果牌只能在服务端下发的候选上松手提交：候选可位于我方棋盘、手牌或商店，落点候选即目标。落在非候选位置（棋盘空白、手牌空白、商店空白、棋盘外）一律退回手牌，不发意图。拖动过程中显示与技能相同的弧线、候选金色角标与命中描边，落点规则不变。
- 需要目标的效果牌候选为空时不可打出，拖拽不开始；不需要目标的效果牌可落在棋盘任意处。
- 选目标手势（英雄技能与战吼待选）统一用「按住拖出」：
  - 主动技能需要目标且候选非空：按住该技能的按钮进入瞄准，指针离开按钮后弧线从按钮连到指针；全部候选显示金色角标，指针命中候选时该卡加金色呼吸描边。松手在候选上以该候选发出 `UseHeroPower`；松手在非候选处或按 `Esc` 取消，不发意图、不扣金币、不消耗次数。技能不需要目标时保持点击即释放，不进入瞄准；候选为空时该技能按钮禁用。一个英雄有多个主动技能时各自一个按钮、各自计次，互不影响。
  - 战吼目标待选：随从入场后不弹列表，候选常驻金色角标；按住任意位置开始瞄准，弧线从入场随从指向指针，松手在候选上发出 `ChooseTarget`。松手在非候选处或按 `Esc` 视为放弃，发出 `AbandonTarget`，随从离场、牌回到原手牌位置、战吼不结算。
  - 瞄准期间不打开任何浮层，不显示卡牌悬停详情，也不改变商店、棋盘与手牌的可操作状态；其它招募操作由服务端待选门控禁用。
- 棋盘随从卡本身也支持拖拽，且卡片内不再有「出售 / ← / →」按钮：
  - 拖到棋盘内：拖起后原卡隐藏、原位置不留占位框；指针移动时插入位由透明占位承载，其余随从实时让位。松手按「移除后被拖随从剩余序列中的插入下标」发 `RearrangeBoard`，落回原位不发意图。
  - 拖到商店：可出售随从进入商店面板时面板金色描边，面板右上角显示「松手出售 +N 金」（普通 1、金色 3）；松手发 `SellMinion`。不可出售随从与手牌拖到商店静默取消。
- 其它落点（空白、棋盘外、需要目标却落在空白处）静默取消：没有提示，也不发意图；拖拽经过这类无效落点时指针显示禁止光标，松手后卡牌留在手牌。棋盘行空白仍属于可放置区域。
- 视图过期、倒计时归零、已结束招募、目标待选、未连接或该手牌不可打出时，拖拽根本不开始。
- 拖拽途中若视图重建、换回合、进入战斗或断线，松手也不会发出意图；已开始的棋盘卡预览会恢复原顺序与可见性。

## 3.2 战斗演示

- 招募结束进入战斗演示：双方随从按下发动作逐步更新，动作步长 320 毫秒，播完后再停留 2 秒横幅。
- 战斗行只显示存活随从：阵亡的随从立刻从行内消失；带「复生」的随从复生后在原相对位置重新出现。
- 双方随从行与结果横幅在整场演示中固定占位：一方随从全部阵亡后，该行仍保留原有高度与位置，行内只留空白，不显示提示文案；横幅出现时只填充预留区域，上下两行不移动。
- 演示期间手牌行照常显示当前手牌但只读（拖拽不开始、点击无效）；我方棋盘由战斗视图的「我方随从」行代替。
- 商店、刷新、升时代、冻结、主动技能与结束招募在演示期间隐藏；被动技能标记只读，保持可见。
- 演示没有跳过或加速入口，只有播完才进入下一步。
- 演示中重连按服务端 `phaseDeadline` 反推进度续播，已播动作不重播。
- 战报只属于刚结束的这一场：回合号与当前回合不一致时不显示，进入下一回合招募时清空，没有本回合战报的座位（未配对、已出局）不会重播上一场。

## 3.3 座位与战报

- 左栏每个座位行整行可点击：点击在行右侧展开该玩家参与过的战报浮层，浮层可覆盖中央舞台；再次点击同一行收起，同一时刻只展开一行。
- 展开状态按 `playerId` 记住，视图刷新并整块重建后仍是同一座位；该玩家不在新视图里时自动收起。
- 战报条目来自 `view.combatLog`，按 `participantIds` 过滤；文案固定为「第 N 回合 · 对手名 · 胜/负/平 · 伤害 X」，平局无胜者时输出「平」。幽灵战的对手写「幽灵（名字）」，`ghostId` 为空时只写「幽灵」；伤害为 0 时省略伤害段。
- 没有条目的座位展开后显示「无战报」，不显示空块。
- 已淘汰座位整行压暗，但名次角标与血条保留，仍可点击展开战报。
- 座位行悬停时显示座位详情（名字、英雄、生命当前/上限、时代、随从数、状态、招募状态），面板挂在左栏外侧并夹紧在视口内。

## 4. 倒计时

- 招募河道 `RecruitRiver` 右端的 `RecruitTimerLabel` 以金色胶囊显示「剩余 N 秒」，每帧按 `phaseDeadline` 更新；页面另外每 0.25 秒复核一次过期门控。归零后显示「等待结算」。
- 招募阶段悬停倒计时区域即翻成「结束招募」按钮，移出恢复倒计时；点击只发一次 `EndRecruit`。归零后不再翻转。
- 归零后结束招募、刷新、升时代、购买、出牌、出售、换位一并禁用，只等服务端推进阶段。

## 5. 动效与无障碍

- 页面结构在每次视图更新时整体重建，避免状态叠加；仅战斗演示、牌桌演出与技能瞄准层单独逐帧更新。
- 选目标弧线与流动光点按固定节奏绘制；Godot 4 读不到系统「减少动态效果」设置，无法按系统偏好降级。
- 所有操作控件都有中文文本；主要操作可用键盘完成，焦点可见。
- 界面不依赖位图与图标资源，文字本身承载全部语义。

## 6. 图鉴浏览

- 入口：大厅「卡牌图鉴」进入整页；对局顶部工具条右侧的「图鉴」以全屏覆盖层打开，不切换场景，拖拽、待选与战斗演示状态保留。
- 视图切换：标题右侧只显示一个当前视图按钮（「随从」或「英雄」），点击切到另一视图并同步按钮文字；默认随从，英雄集合为空时按钮禁用。
- 筛选三维交叉：随从视图为时代章节栏单选「全部 + 7 时代」、分类目录单选「全部 + 13 个玩法」、选中分类下再选「全部 / 随从 / 效果」；任一维的计数按另外两维换算，零计数项禁用（置灰、不可点），当前选中项不禁用。卡牌按全部 `play:` 归属归入分类，「全部」按唯一卡牌 id 计数。
- 分类目录含 13 个玩法、不含「中立」，按玩法固定顺序排列；效果牌与英雄不作为顶层分类，效果牌通过「随从 / 效果」二级筛选查看；切换顶层分类时二级筛选回到「全部」。
- 英雄视图隐藏左侧目录与时代章节栏，顶部改为英雄分类栏：「全部」+ 13 个玩法，按英雄全部 `play:` 归属计数，带多条归属的英雄在多个分类中同时出现，没有英雄的分类显示但禁用；选中分类后网格只列该分类的英雄。
- 切换视图保留各视图的筛选条件；切换筛选或视图都回到首批并滚回顶部。
- 网格改为滚动加载：桌面与 iPad 每批 18 张，手机每批 12 张；滚到接近底部自动追加下一批，底部显示「已显示 N / M 张 · 继续下滑加载 / 已全部加载」，不再有上一页 / 下一页。
- 触屏在网格任意位置（含卡面）按住拖动即滚动；按下后位移超过 12 像素按滚动处理，不切换详情，轻点才选中。
- 手机随从视图点工具栏「分类：<当前分类>」打开两列分类面板，点分类项、点面板外、再点按钮或按 `Esc` 收起；面板覆盖网格与详情，不改变选中。
- 点击卡面即选中并更新右侧常驻详情；详情只读、可纵向滚动，不是弹层，不需要关闭。详情顶部显示卡面美术大图，无美术时显示玩法色 + 首字占位。
- 返回：大厅页「返回大厅」；对局覆盖层「返回对局」。两处都支持 `Esc`，且只关闭最上层的图鉴。
- 对局的选择浮层可见时，图鉴随下一次视图刷新自动收起，不与之叠加。
- 视图切换、顶部筛选栏与目录按钮可用 `Tab` 聚焦、键盘激活；其它交互与第 1 节的控件状态一致。
