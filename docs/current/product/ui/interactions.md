# 通用交互

> 状态：已实现
> 代码：`client/ui/ui.gd`、`client/ui/theme.gd`、`client/scenes/game.gd`、`client/scenes/card_gallery.gd`

本文记录桌面端已实现的通用交互；iOS 端的横屏、缩放、长按与命中尺寸差异见[移动端适配](mobile-adaptation.md)。

## 1. 控件状态

| 状态 | 表现 | 规则 |
| --- | --- | --- |
| 默认 | `color-surface-raised` 底、`color-border` 描边 | `UI.styled_button` 统一设置 |
| 悬停 | 底色提亮、描边转为 `color-border-strong` | 只改变视觉，不改变可用性 |
| 按下 | 底色压暗 | 松开后发出一次操作 |
| 聚焦 | 描边转为 `color-accent` | 键盘 `Tab` 可遍历主要操作 |
| 禁用 | 底色退回 `color-surface`、文本转 `color-text-muted` | 禁用原因写入 `tooltip_text`，不只置灰 |

- 主操作（倒计时悬停后翻出的「结束招募」）使用 `primary` 变体，其余使用 `default`；棋盘随从卡不放卡内按钮，换位与出售由拖拽完成。
- 禁用原因取 `affordances` 的 `disabledReason`，经 `UI.error_text` 转为中文后放入 tooltip。

## 2. 操作反馈

- 操作发出后不等待本地确认，界面以下一条服务端视图为准；视图未变化前按钮保持原状态。
- 发送失败（未连接）时顶部工具条的状态文本显示「未连接，操作未发出」，不静默丢弃。
- 服务端错误在顶部工具条的状态文本显示固定中文文案，协议 `message` 只进 tooltip；错误去向由 `UI.error_route` 决定：认证类回登录并清会话，`NOT_IN_ROOM` / `ROOM_NOT_FOUND` 回大厅并清房间，其余留在当前页面。

## 3. 弹层

| 弹层 | 触发 | 出口 |
| --- | --- | --- |
| 发现 / 进化选择 | `self.pendingChoices` 非空 | 点选一项发出 `ChooseDiscover` |
| 战吼目标待选 | `self.pendingChoices` 头部 `kind` 为 `target` | 只列服务端下发的候选（按棋盘/手牌/商店分组），高亮触发者；没有「不指定目标」与「取消」 |
| 英雄技能目标选择 | `self.heroPower.requiresTarget` 为真且候选非空 | 只列服务端下发的候选；可「取消」，取消不发意图、不扣金币与次数 |

- 弹层使用全屏遮罩与居中卡片，同一时刻只显示一个；服务端目标待选优先于客户端发起的英雄技能浮层。
- 候选为空时不显示空浮层：效果牌按不可打出处理，英雄技能按钮禁用并给出 `NO_VALID_TARGET` 原因。
- 视图过期、倒计时归零、已结束招募或不在招募阶段时关闭弹层且不再弹出，避免用上一回合的操作；跨回合保留的发现/进化待选不会盖在战斗演示上。

## 3.1 拖拽操作

- 手牌只能拖拽出牌，点击手牌不产生任何意图。
- 随从牌落在棋盘上：落点决定插入下标（落在某张随从卡上即插到该卡之前，落在卡片之间或末尾空白则按指针与各卡中心的相对位置取下标），原下标及其右侧随从依次右移；棋盘已满时不接受，容量与「随从 x/y」提示以服务端下发的上限为准。
- 需要目标的效果牌只能在服务端下发的候选上松手提交：候选可位于我方棋盘、手牌或商店，落点候选即目标。落在非候选位置（棋盘空白、手牌空白、商店空槽、棋盘外）一律退回手牌，不发意图。
- 需要目标的效果牌候选为空时不可打出，拖拽不开始；不需要目标的效果牌可落在棋盘任意处。
- 棋盘随从卡本身也支持拖拽，且卡片内不再有「出售 / ← / →」按钮：
  - 拖到棋盘内：拖起后原卡隐藏、原位置不留占位框；指针移动时插入位由透明占位承载，其余随从实时让位。松手按「移除后被拖随从剩余序列中的插入下标」发 `RearrangeBoard`，落回原位不发意图。
  - 拖到商店：可出售随从进入商店面板时面板金色描边，面板右上角显示「松手出售 +N 金」（普通 1、金色 3）；松手发 `SellMinion`。不可出售随从与手牌拖到商店静默取消。
- 其它落点（空白、棋盘外、需要目标却落在空白处）静默取消：没有提示，也不发意图；拖拽经过这类无效落点时指针显示禁止光标，松手后卡牌留在手牌。空位仍属于可放置区域。
- 视图过期、倒计时归零、已结束招募、目标待选、未连接或该手牌不可打出时，拖拽根本不开始。
- 拖拽途中若视图重建、换回合、进入战斗或断线，松手也不会发出意图；已开始的棋盘卡预览会恢复原顺序与可见性。

## 3.2 战斗演示

- 招募结束进入战斗演示：双方随从按下发动作逐步更新，动作步长 320 毫秒，播完后再停留 2 秒横幅。
- 战斗行只显示存活随从：阵亡的随从立刻从行内消失；带「复生」的随从复生后在原相对位置重新出现。
- 双方随从行与结果横幅在整场演示中固定占位：一方随从全部阵亡后，该行仍保留原有高度与位置，行内只留空白，不显示提示文案；横幅出现时只填充预留区域，上下两行不移动。
- 演示期间手牌行照常显示当前手牌但只读（拖拽不开始、点击无效）；我方棋盘由战斗视图的「我方随从」行代替。
- 商店、刷新、升时代、冻结、英雄技能与结束招募在演示期间隐藏。
- 演示没有跳过或加速入口，只有播完才进入下一步。
- 演示中重连按服务端 `phaseDeadline` 反推进度续播，已播动作不重播。
- 战报只属于刚结束的这一场：回合号与当前回合不一致时不显示，进入下一回合招募时清空，没有本回合战报的座位（未配对、已出局）不会重播上一场。

## 3.3 座位与战报

- 左栏每个座位行整行可点击：点击在行右侧展开该玩家参与过的战报浮层，浮层可覆盖中央舞台；再次点击同一行收起，同一时刻只展开一行。
- 展开状态按 `playerId` 记住，视图刷新并整块重建后仍是同一座位；该玩家不在新视图里时自动收起。
- 战报条目来自 `view.combatLog`，按 `participantIds` 过滤；文案固定为「第 N 回合 · 对手名 · 胜/负/平 · 伤害 X」，平局无胜者时输出「平」。幽灵战的对手写「幽灵（名字）」，`ghostId` 为空时只写「幽灵」；伤害为 0 时省略伤害段。
- 没有条目的座位展开后显示「无战报」，不显示空块。
- 已淘汰座位整行压暗，但名次角标与血条保留，仍可点击展开战报。
- 座位行悬停时显示座位详情（名字、英雄、生命当前/上限、时代、随从数、状态、招募状态），面板挂在左栏外侧并夹紧在视口内。

## 4. 倒计时

- 招募河道 `RecruitRiver` 右端的 `RecruitTimerLabel` 以金色胶囊显示「剩余 N 秒」，每帧按 `phaseDeadline` 更新；页面另外每 0.25 秒复核一次过期门控。归零后显示「等待结算」。
- 招募阶段悬停倒计时区域即翻成「结束招募」按钮，移出恢复倒计时；点击只发一次 `EndRecruit`。归零后不再翻转。
- 归零后结束招募、刷新、升时代、购买、出牌、出售、换位一并禁用，只等服务端推进阶段。

## 5. 动效与无障碍

- 当前没有动画与过渡；界面在每次视图更新时整体重建，避免状态叠加。
- 所有操作控件都有中文文本；主要操作可用键盘完成，焦点可见。
- 界面不依赖位图与图标资源，文字本身承载全部语义。

## 6. 图鉴浏览

- 入口：大厅「卡牌图鉴」进入整页；对局顶部工具条右侧的「图鉴」以全屏覆盖层打开，不切换场景，拖拽、待选与战斗演示状态保留。
- 筛选两维交叉：时代章节栏单选「全部 + 7 时代」，分类目录单选「全部 + 8 界」；任一维的计数按另一维换算，零计数项禁用（置灰、不可点），当前选中项不禁用。
- 切换筛选回到第 1 页并清空滚动位置；当前选中卡不在结果内时自动改选结果首张，结果为空时网格显示「没有符合条件的卡牌」、详情显示占位提示。
- 分页每页 40 张（5 列），上一页 / 下一页在首页与末页分别禁用；切换页只重建当前页卡面。
- 点击卡面即选中并更新右侧常驻详情；详情只读、可纵向滚动，不是弹层，不需要关闭。
- 返回：大厅页「返回大厅」；对局覆盖层「返回对局」。两处都支持 `Esc`，且只关闭最上层的图鉴。
- 对局的选择浮层可见时，图鉴随下一次视图刷新自动收起，不与之叠加。
- 章节栏与目录按钮可用 `Tab` 聚焦、键盘激活；其它交互与第 1 节的控件状态一致。
