# 推演

## 属性

| 属性 | 值 |
| --- | --- |
| id | activate-friendly-growth-twice |
| 关键词 | 无 |
| 模板 | activate-growth-single |
| 费用 | 1 |
| 每回合次数 | 1 |

## 效果

使一个友方随从获得两次成长

## 设计说明

定位：主动成长技能，把一次成长变成两点属性。
作用对象：己方一个随从；场上没有友方随从时不可用。
