# combat-random-enemy-damage-3

## 属性

| 属性 | 值 |
| --- | --- |
| id | combat-random-enemy-damage-3 |
| 关键词 | 无 |
| 模板 | combatstart-damage-random-nocomma |

## 效果

战斗开始时对随机一个敌方随从造成 3 点伤害

## 设计说明

定位：战斗开场的随机伤害，可能拆掉一个低血随从或打掉护盾。
口径：目标在战斗开始时随机确定，随机流属于确定性状态的一部分。
