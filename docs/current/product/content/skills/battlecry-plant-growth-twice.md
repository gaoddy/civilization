# battlecry-plant-growth-twice

## 属性

| 属性 | 值 |
| --- | --- |
| id | battlecry-plant-growth-twice |
| 关键词 | 战吼 |
| 模板 | on-play-battlecry-growth-single-ps |

## 效果

战吼：使一个友方植物随从获得两次成长

## 设计说明

定位：植物流的定向双成长，入场时由玩家指定目标。
口径：目标必须是己方植物随从；无可选目标时战吼不结算。
