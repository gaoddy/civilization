# 应用图标

> 状态：已实现
> 成品：`client/icon.png`（1024×1024、RGB、无 alpha）
> 源文件：`client/icon.svg`（矢量，`viewBox` 1024）
> 画面基线与验收：见[图片素材索引](image-asset-index.md) §2.5

## 1. 构图

- 深色底 `#121925`（`color-surface-raised`）铺满画布，金色 `#f0c66b`（`color-accent`）单色前景。
- 主形是一枚断开的纪年环，断口朝右上，断口内悬一颗四角星。断环本身读作 C（Civilization 的首字母）。
- 符号外接框约 816×816，四周各留约 104 安全边，落在 iOS 圆角蒙版的 80% 安全区内。
- 无文字、无渐变、无描边、无投影、无细线；缩到 32px 仍读作「C + 点」。

## 2. 导出

1. 以 `client/icon.svg` 为唯一源，渲染 1024×1024 PNG。
2. 去掉 alpha 通道后覆盖 `client/icon.png`：

```bash
ffmpeg -y -i icon-rgba.png -pix_fmt rgb24 client/icon.png
```

3. `project.godot` 的 `config/icon` 不变，仍指向 `res://icon.png`；macOS 与 iOS 图标由 Godot 从这张图缩放生成。
4. 应用图标不在 `make asset-compress` 范围内，替换后直接重跑导出。

## 3. 验收

- 64×64 主屏缩略下能认出断环与星；32×32 仍能读出 C 形开口；16×16 允许星退化为点，环形必须成立。
- 单色版成立：黑色符号放在白底、白色符号放在 `#070a0f` 底都不丢失轮廓。
- 深色壁纸与商店列表缩略下逐一看过；满幅无空白、无透明边缘、无文字。

## 5. 未采用方向

同期出过两版矢量稿，保留为改版备选，未进入仓库：

- **六边之核**：六边形晶格环包围核心，16px 最稳，但六边形在科技类标识中过于常见。
- **纪元螺旋**：等距螺旋，时代推进语义直接，但 16px 内圈会糊，且需把描边转成填充轮廓。

改版时优先在当前断环结构上调整断口角度、环宽与星的大小，不重新引入细节层次。
