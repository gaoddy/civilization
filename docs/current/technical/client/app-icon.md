# 应用图标

> 状态：已实现
> 成品：`client/icon.png`（1024×1024、RGB、无 alpha）
> 源文件：`client/icon.svg`（矢量，`viewBox` 1024）
> 画面基线与验收：见[图片素材索引](image-asset-index.md) §2.5

## 1. 构图

- 深色圆角背景：径向渐变 `#1c2635`（中心）→ `#080c12`（边缘），色相取 `color-surface-raised` 系。
- 主形是一枚断开的纪年环，断口朝右上（-45°，张开 60°），断口内悬一颗四角星。断环本身读作 C（Civilization 的首字母）。
- 环内嵌一张旅行者金唱片盘面，取封面上的识别元素：同心音槽、脉冲星图、氢原子符号、播放示意图、二进制刻线与中心孔。盘面比环内径小 88，两者之间留暗色间隙，断环仍是最外层的框。
- 盘面材质：暖铜径向渐变打底，20 圈音槽按「暗槽 + 紧邻外侧亮棱」成对刻画，左上叠一片模糊柔光与低强度颗粒，盘缘左上受光、右下压暗并压出一圈收尾槽；图形用「暗底偏移 + 亮面」两遍描线做出蚀刻感。
- 环带外径 368、内径 288（1024 网格），盘面半径 200，星半径 76、位于半径 312 处。符号外接框约 776×776，四周各留约 124 安全边，落在 iOS 圆角蒙版的 80% 安全区内。
- 无文字。渐变与投影只用于材质与层次，不承载语义。

## 2. 导出

1. 以 `client/icon.svg` 为唯一源，渲染 1024×1024 PNG。
2. 去掉 alpha 通道后覆盖 `client/icon.png`：

```bash
ffmpeg -y -i icon-rgba.png -pix_fmt rgb24 client/icon.png
```

3. `project.godot` 的 `config/icon` 不变，仍指向 `res://icon.png`；macOS 与 iOS 图标由 Godot 从这张图缩放生成。
4. 应用图标不在 `make asset-compress` 范围内，替换后直接重跑导出。

## 3. 验收

- 64×64 主屏缩略下能认出断环、盘面与星；32×32 仍能读出 C 形开口与盘面的圆。
- 盘面细节（音槽、脉冲星图、氢原子符号、播放示意图、刻线）在 64 以下允许糊成金色纹理，但不能让整体变成一块金色圆饼；环与盘之间必须留出暗色分离。
- 深色壁纸与商店列表缩略下逐一看过；满幅无空白、无透明边缘、无文字。
- 单色版不再适用：本版带渐变与阴影，商店与导出渠道统一使用彩色源图，不再提供单色剪影。

## 5. 未采用方向

同期出过若干备选，保留为改版参考，未进入仓库：

- **六边之核**：六边形晶格环包围核心，16px 最稳，但六边形在科技类标识中过于常见。
- **纪元螺旋**：等距螺旋，时代推进语义直接，但 16px 内圈会糊，且需把描边转成填充轮廓。
- **大盘唱片**：盘面放大到 206 并整体提亮，最接近真唱片，但盘与环明度接近，32px 下容易连成一块。
- **抛光金属板**：斜向拉丝反光 + 明暗相间音槽 + 斜面边。盘面最亮最干净，但更像金盘而不是唱片。
- **币面浮雕**：粗脊凹版音槽 + 下沉中心标签 + 双层币边。最厚重、最像实物铜盘，但与外环明度差过大，小尺寸盘面偏闷。

改版时优先在当前断环结构上调整断口角度、环宽、盘径与星的大小；盘面元素只增删不重排。
