## 2. 逐图说明

### 2.1 软件背景

**页面位置**：`UIControls.background()` 创建 `PageBackground`，位于 `ContentFrame` 之外，铺满整个视口；登录、大厅、房间、对局、图鉴、结算、排行榜、账号、个人资料共 9 个页面共用同一张。16:9 设备上几乎完全被内容框遮住，只在超宽、4:3 与 iPhone 刘海侧露出为背景带。

**画面目的**：给所有页面一个统一的近黑底，让 16:9 内容框像浮在同一张桌面上；背景带不能有可辨认主体，避免被裁切后在部分设备上出现半个图形。

**构图**：底色 `#070a0f`，中心椭圆提亮（`#2b3a52` → `#18212f` 渐隐），叠加 ±2 级灰度纸张颗粒。无图形、无文字、无方向性结构。

**重新生成**：由 `scripts/gen_ui_assets.py` 确定性生成，重跑字节一致；颜色与颗粒强度是该脚本的 `BASE`、`GLOW_INNER`、`GLOW_MID`、`NOISE_LEVEL` 常量。改用 AI 出图时保持三条：512×512、无主体、任意裁切都成立。

### 2.1.1 页面专属两层背景

**页面位置**：每个页面的 `PageBackground`（整窗 cover 的外层氛围图）与 `PageSurface`（设计画布内的 16:9 结构框架图）；取图入口见 [纹理登记册](textures.md) §1.1 与 §1.2。

**画面目的**：外层给页面身份、在超宽与 4:3 窗口的内容框外可见；内层给出该页的分区结构，让顶栏、侧栏、主区与底栏在视觉上成区。

**视觉方向**：科学星图——深靛海图底、细经纬网格、黄铜金与青色细线、罗盘与星座点缀，低对比，不压内容。

**外层构图**：512×512，均匀分布的微弱星点与星座线，四周亮度一致；无主体、无边框、无罗盘、无方向性结构，任意位置与比例裁切都成立。

**内层构图**：精确 1280×720（大厅与对局的手机档位 960×540），分区边界按该页真实控件矩形绘制，整张拉伸不裁切；不写文字、不画控件、不放高对比主体。

| 页面 | 外层母题 | 内层分区 |
| --- | --- | --- |
| 登录 | 晨星与薄雾 | 中央 34% 宽竖框 + 顶部横饰 |
| 大厅 | 北极星 | 左 66% 大框 + 右 28% 四段 + 底 6% 操作条 |
| 房间等待区 | 猎户座 | 顶部状态条 + 4×2 座位矩阵 + 底部操作条 |
| 对局 | 天狼星与猎犬座 | 左座位栏 + 顶工具条 + 商店/选秀带/棋盘/英雄/手牌五段（手机档位另出 960×540） |
| 结算 | 天秤座 | 中央 60% 宽竖框，内部分头/身/尾三段 |
| 卡牌图鉴 | 天琴座 | 顶部 6% 工具条 + 整块网格区 |

**重新生成**：外层与内层均用 EvoLink `doubao-seedream-5.5` 出图（外层 1:1 2K、内层 16:9 2K），提示词写死上述分区比例，原文与筛选规则见[页面背景出图记录](page-background-prompts.md)；出图后按目标尺寸缩放并人工筛选，不合格重出。AI 出图不可确定性复现，成品图即真源，同名覆盖后执行 `make asset-compress` 与 `make client-import`。内层图重出后用 `make ui-wireframe PAGE=<页面>` 的实测矩形核对分区，偏移超过约 2% 时重新出图或在提示词中调整比例。

### 2.2 对局分区背景（桌面）

**页面位置**：对局页 `PageSurface`，随 `ContentRoot` 缩放到 1280×720 内容框，桌面与 iPad 档位使用（`game.gd::_page_texture()`）。铺法是整张拉伸（`STRETCH_SCALE`），不 cover、不 contain，底图坐标与页面画布坐标一一对应。

**画面目的**：把一局对局的纵向分区画在底图上，让左栏、中央舞台与底部区域在视觉上各自成区；控件与卡面叠在上面，底图只提供结构线与氛围。

**构图**（自上而下，百分比为该图纵向位置）：

- 顶部窄横条 2.1–8.4%：细金双线，中央一枚小八角徽记，衬托 `GameTools`
- 左缘竖栏 1.3–8.7%：细金双框内串一排圆形罗盘徽记，衬托 `PlayersPanel`
- 上部大区（商店）8.4–35.7%：开阔星图，无分隔
- 窄隔离带 35.7–40.3%：一行小徽记与星点，对应 `RecruitRiver`
- 棋盘带 42.0–62.9%：双线描边的大框 + 锚形纹，左侧另有约 10.5–71% 宽的装饰框
- 英雄带 63.6–75.3%：63.6–68.5% 一条徽记横带，71.6% 一条细线
- 手牌带 76.4–97.9%：开阔星图，左下与底边有罗盘纹
- 分隔线：横贯细金线，中央一枚小徽章

**重新生成**：必须精确 1280×720；分区边界位置不可移动，否则会与页面上的分区错位。不写文字、不放高对比主体。手机版是重新布局的同构版本，不能由本图裁切或缩放得到。

### 2.3 对局分区背景（手机）

**页面位置**：同 2.2，仅 iPhone 档位（`ScreenProfile.device_kind()` 为 `DEVICE_PHONE`）使用，铺满 960×540 内容框，同样是整张拉伸。

**画面目的**：与桌面版承担同一套分区框架，按 960×540 重新排布比例，保证手机档位的控件仍落在对应区域内。

**构图**：顶部窄横条 1.5–6.3%（中央小八角徽记）、左缘竖栏 1.2–4.4%（罗盘徽记列）、商店大区 6.3–42.4%、窄隔离带 42.4–48.4%、棋盘带 48.4–65.1%（双线框 + 左侧装饰框）、英雄带 69.7–81.2%、手牌带 81.2–98.4%；元素与桌面版一一对应，纵向按 540 重排、横向按 960 收窄。

**重新生成**：必须精确 960×540，与桌面版同批出图、各自出图；不通过裁切或缩放桌面版替代，否则分区会与手机档位布局错位。

### 2.4 大厅主视觉

**页面位置**：大厅页左栏（左右栏 7:3 中的左栏），由 `LobbyHallImage` 占满标题与操作区之间的剩余高度，按 cover 等比铺满并左右裁切。

**画面目的**：大厅的视觉主场，用「文明史长廊」把时代、科技与对局的卡牌主题串起来；它是页面里面积最大的单张插画，其余界面元素都在它之上或身旁。

**构图**：纵深大厅，拱顶星空，两侧墙面是时代与科技壁画，长桌与烛台居中偏下，尽头彩窗透光；整体仍是深墨底 + 黄铜金，扁平带渐变，无文字。

**裁切约束**：cover 铺满 7:3 左栏时，左右两边各被裁掉约一成；主体与关键细节不要贴左右各 10% 的边缘。上下随栏高裁切，视线重心放在中部。1600×1000 是出图尺寸，不是显示尺寸。

### 2.5 应用图标

**页面位置**：`project.godot` 的 `config/icon` 指向 `res://icon.png`，只用于导出：macOS 与 iOS 的应用图标、主屏图标由 Godot 从这张图缩放生成；游戏内不渲染。

**画面目的**：桌面与移动端主屏上的唯一识别图，需在 64×64 仍能认出「断环、盘面与星」。

**出图方式**：矢量源 `client/icon.svg` 渲染 1024×1024 后去 alpha，覆盖 `client/icon.png` 并随源提交；不再走 AI 出图。导出步骤与版本记录见[应用图标](app-icon.md)。

**设计原则**（出图与验收共用）：

1. **识别性优先**：唯一外框主形是断开的纪年环，断口内一颗四角星；断环读作 C。环占画面不小于 70%，64×64 缩略下盘面细节可糊成金色纹理，环的开口与盘面的圆必须成立。
2. **层次分明**：环最亮、盘面次之、底最暗，三段明度拉开；细线只作纹理，缩小后不能吃掉轮廓。允许金属渐变、投影与细线，用来出材质，不用来出语义。
3. **无文字**：图标内不出现产品名、缩写或标语。
4. **平台规范**：不自行绘制圆角、描边或投影，蒙版由系统裁切；正方形满幅、四边不留空白、无透明边缘。
5. **品牌一致**：颜色取自 UITheme 语义颜色令牌（`color-bg` `#070a0f`、`color-surface-raised` `#121925`、`color-accent` `#f0c66b`、`color-accent-strong` `#b98a2f`、`color-star` `#ffe089`、`color-plate-ring` `#6d4a18`）；渐变与阴影只在令牌之间的金色与深蓝上提亮、压暗，不引入令牌之外的色相。
6. **真实场景验证**：在 64×64 主屏缩略、深色壁纸与商店列表缩略尺寸下逐一确认。

**画面基线**：`#1c2635` → `#080c12` 的径向渐变铺满画幅。断环外径 368、内径 288（1024 网格），在右上（-45°）断开 60°，断口两端为径向直切；环面用金色渐变，外侧高光、内侧压暗，环上七条径向刻度。断口中心、半径 312 处一颗半径 76 的四角星。环内一张半径 200 的暖铜唱片盘面，比环内径小 88 以留出暗色间隙：20 圈音槽按「暗槽 + 外侧亮棱」成对刻画，左上叠模糊柔光与低强度颗粒，盘缘左上受光、右下压暗并压出一圈收尾槽，盘上有脉冲星图、氢原子符号、播放示意图、七条二进制刻线与中心孔，图形用「暗底偏移 + 亮面」两遍描线做蚀刻感。符号外接框约 776×776，四周各留约 124 安全边。无文字。

**出图记录**：矢量源 `client/icon.svg`，2026-11-26 重做为金唱片版；版本与未采用方向见[应用图标](app-icon.md)。

**出图要求**：1024×1024 正方形、RGB（无 alpha）、满幅无空白、无文字；符号落在 80% 安全区内，缩小时环的开口仍成立。重出后按下方渠道表导出，iOS 营销图标不复用带 alpha 的图。

**各渠道图标**

客户端包内的 macOS、iOS 与 Android 应用图标由 Godot 从 `client/icon.png` 缩放生成；`client/export_presets.cfg` 的 `launcher_icons/main_192x192`、`adaptive_foreground_432x432`、`adaptive_background_432x432`、`adaptive_monochrome_432x432` 为空，Android 未配置自适应图标层。商店后台图标需另行导出，不进入客户端包。

| 渠道 | 素材 | 尺寸 | 格式 | 仓库现状 |
| --- | --- | --- | --- | --- |
| iOS | App Store 营销图标 | 1024×1024 | PNG，无 alpha 通道 | 源图已是 RGB（无 alpha），可直接使用 |

| Android | 传统 launcher 图标 | 192×192 | PNG | 由 `client/icon.png` 缩放生成 |

| Android | Google Play 商店图标 | 512×512 | 32-bit PNG（允许 alpha，≤1024KB） | 待 [Google Play 发布配置](../../../requirements/google-play-release.md) |

- Steam Shortcut Icon 传 PNG 时由 Steam 自动转 ICO；macOS 还需单独提供 ICNS，否则快捷方式使用默认 Steam 图标。

## 4. 整包重新生成

1. 程序化背景图重跑脚本：`python3 scripts/gen_ui_assets.py`；应用图标按 §2.5 以 `client/icon.svg` 重新渲染，同名覆盖 `client/icon.png`。
2. 三张插画按第 2 节逐张出图，同名覆盖原文件；对局两张必须同批出图并各自保持档位尺寸。
3. 覆盖后按 [纹理登记册](textures.md) §4 的替换流程执行：`make asset-compress` → `make client-import`；应用图标不在压缩范围内，替换后直接重跑导出。
4. 运行 `make data-check`，确认纹理登记与实际资源一致。
