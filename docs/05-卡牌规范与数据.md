# 05 · 卡牌规范与数据

> 编号：05

## 1. 字段规范

每张卡一个文档：`docs/data/cards/<id>.md`，文件名等于 `id`。文档由 YAML front matter 与正文组成；front matter 只使用 `key: 标量` 与 `keywords: [词 1, 词 2]` 两种形式。

卡牌分两类：**随从牌**（`card_type: 随从`）能站场，必须有初始攻击力与生命值；**效果牌**（`card_type: 效果`）不站场，不得有攻击力与生命值。

| 字段 | 类型 | 取值域 | 说明 |
| --- | --- | --- | --- |
| `id` | 字符串 | 语义 slug | 全局唯一；匹配 `^[a-z][a-z0-9_]*$`；必须等于文件名；中文名用拼音，外国人名与国际通用术语用英文；不含时代前缀，时代由 `era` 字段表达 |
| `card_type` | 枚举 | 随从 / 效果 | 随从站场，效果不站场 |
| `name` | 字符串 | 同一类型内唯一 | 卡名；优先使用素材原名 |
| `tribe` | 枚举 | 人类 / 机械 / 生物 / 植物 / 病毒 / 学者 | 6 个流派之一 |
| `subtype` | 字符串 | 自由 | **仅随从**；学科或类别，供英雄技能引用 |
| `level` | 整数 | 1–6 | 星级，不是时代 |
| `era` | 枚举 | 史前 / 原始 / 封建 / 现代 / 未来 | **仅随从**；题材归属 |
| `attack` | 整数 | ≥0 | **仅随从，必填**；学者必须为 0 |
| `health` | 整数 | ≥1 | **仅随从，必填**；学者取同星级区间上浮 30% |
| `keywords` | 列表 | `[]` 或 13 个关键词的任意组合 | **仅随从**；不得出现其他词 |
| `is_scholar` | 布尔 | `true` / `false` | **仅随从**；与 `tribe=学者` 必须一致 |
| `source` | 枚举 | `素材` / `新增` | **仅随从**；标明是否沿用原始笔记的卡名 |
| `cost` | 整数 | 0–4 | **仅效果，必填**；购买费用，独立于星级 |
| `match_text` | 字符串 | 自由 | **仅效果，必填**；比赛模式下的确定性替换，与原效果相同写「同左」 |

**正文约定**：一级标题为卡名；`## 属性` 用表格复述 front matter 的字段，供直接阅读；`## 效果` 写效果文本，无效果写「无」。属性表与 front matter 必须一致，由 §5 的校验脚本交叉核对。

**编码约定**：front matter 一行一个字段，列表元素用英文逗号分隔；正文只使用中文标点（，、；：）。

## 2. 数值与关键词约束

以下约束作用于随从牌；效果牌只校验星级与费用。

1. 攻击力与生命值必须落在 08 分册的星级区间内；
2. 学者的 `attack` 必须为 0，生命值取区间上浮 30%；
3. 关键词只能来自 13 词表；**通用 10 词**必须符合 03 分册 §7 的时代解锁关系（史前只有繁衍/战吼/亡语，原始才有成长，封建才出现嘲讽/连击，现代才有最优攻击/传染，未来才有护盾/复生），**流派专属 3 词不参与时代解锁**（03 §1.1）；`光环` 不是关键词，持续效果写在 `text` 中；
   - 流派专属词必须与流派一致：`装配` 只能在机械卡、`播种` 只能在植物卡、`进化` 只能在生物卡；
4. 关键词折算后，`攻击力 + 生命值 + 折算` 不得超过同星级白板总和 + 4；
5. 同名卡只允许出现一次（三连靠份数，不靠重名）；该唯一性约束**按卡牌类型分别作用于随从池与效果牌池**，英雄技能使用独立命名空间。

## 5. 校验规则与命令

每次修改卡牌或英雄文档后必须运行：

```bash
python3 docs/data/validate.py
```

校验覆盖：文档数量、`card_type` 合法、文件名与 `id` 一致、`id` 唯一、`id` 格式、枚举字段合法、随从必有 `attack`/`health` 且效果牌不得有、学者攻击为 0 且与流派一致、随从时代/流派/星级分布、关键词白名单与流派专属词越界、星级数值区间与超模上限、效果牌星级与费用、英雄数量与费用、**每份文档的属性表与其 front matter 一致**。

期望：末行输出 `随从 120 张、效果牌 30 张、英雄 10 位，校验通过`，退出码 0；否则逐条打印违规并以退出码 1 结束。

## 7. 待决问题

- "新增"卡占比 58%，是否需要在文案层面补足"科学史出处"，避免玩家觉得是凑数卡？倾向给每张新增卡写一句来源说明，放在卡牌详情页。
